## Responsive

가능한 옵션: `'size' | 'css'`

`xs`, `sm`, `md`, `lg` 를 이용해 반응형 대응을 할 수 있습니다.

<Markdown>
{`
\`\`\`tsx
import { Avatar } from '@wanteddev/wds';

const Component = () => {
return (
<AvatarGroup
size="xsmall"
lg={{ size: 'small' }} >
<Avatar size="xsmall" lg={{ size: 'small' }} />
</AvatarGroup>
);
};
\`\`\`
`}

</Markdown>
