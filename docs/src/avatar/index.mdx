## Responsive

가능한 옵션: `'size' | 'css'`

`xs`, `sm`, `md`, `lg` 를 이용해 반응형 대응을 할 수 있습니다.

{`

size="small"
lg={{ size: 'large' }}
/>
);
};
\`\`\`
