# Scroll Area

`ScrollArea` 는 레이아웃을 깨지게 하지 않는 inner scroll 영역을 생성합니다.

<Canvas>
	<Story of={Stories.Basic} />
</Canvas>

## Horizontal

가로 스크롤만 사용하려면 `scrollbars="horizontal"` 을 추가합니다.

<Canvas>
	<Story of={Stories.Horizontal} />
</Canvas>


## Vertical

세로 스크롤만 사용하려면 `scrollbars="vertical"` 을 추가합니다.

<Canvas>
	<Story of={Stories.Vertical} />
</Canvas>


## Type

스크롤을 표시하는 유형을 결정할 수 있습니다.
`"auto" | "scroll" | "always" | "hover"`


### Hover (default)

overflow 영역을 넘어간 경우에 마우스 오버를 했을 때 스크롤바를 표시합니다.

<Canvas>
	<Story of={Stories.Hover} />
</Canvas>

### Scroll

overflow 영역을 넘어간 경우에 스크롤을 할 때 스크롤바를 표시합니다.

<Canvas>
	<Story of={Stories.Scroll} />
</Canvas>

### Auto

overflow 영역을 넘어간 경우에 항상 스크롤바를 표시합니다.

<Canvas>
	<Story of={Stories.Auto} />
</Canvas>

### Always

항상 스크롤바 영역을 표시합니다.
스크롤바 영역에 background color가 지정되어 있지 않아 사실상 auto와 동일합니다.

<Canvas>
	<Story of={Stories.Always} />
</Canvas>
