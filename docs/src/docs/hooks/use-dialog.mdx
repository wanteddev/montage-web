# useDialog

Dialog 컴포넌트를 `Promise<'confirm' | 'cancel'>` 형태로 사용할 수 있습니다.

## 활용

<Demo code={`import { useDialog, Button, DialogActionAreaButton } from '@wanteddev/wds';

const Demo = () => {
  const dialog = useDialog();

  const handleClick = async () => {
    const result = await dialog({
      title: '제목',
      content: '설명',
      confirm: <DialogActionAreaButton>확인</DialogActionAreaButton>,
      cancel: <DialogActionAreaButton variant="assistive">취소</DialogActionAreaButton>,
    });

    alert('결과: ' + result);
  };

  return (
    <Button onClick={handleClick}>클릭</Button>
  )
}

export default Demo;`}
/>

## Examples

### Reverse

확인과 취소 버튼 위치를 변경합니다.

<Demo code={`import { useDialog, Button, DialogActionAreaButton } from '@wanteddev/wds';

      direction: 'reverse'

  };

export default Demo;`}
/>

### Prevent Event

`e.preventDefault` 를 이용하면 클릭 액션을 막을 수 있습니다.

<Demo code={`import { useDialog, Button, DialogActionAreaButton } from '@wanteddev/wds';

const Demo = () => {
  const dialog = useDialog();

  const handleClick = async () => {
    const result = await dialog({
      title: '제목',
      content: '내용',
      confirm: <DialogActionAreaButton onClick={e => e.preventDefault()}>확인</DialogActionAreaButton>,
      cancel: <DialogActionAreaButton variant="assistive">취소</DialogActionAreaButton>,
    });

    alert('결과: ' + result);
  };

  return (
    <Button onClick={handleClick}>클릭</Button>
  )
}

export default Demo;`}
/>
