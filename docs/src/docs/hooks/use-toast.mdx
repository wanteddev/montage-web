# useToast

토스트는 프로세스에 대한 간단한 메시지를 제공할 때 사용되며, 일정 시간이 지난 후 사라집니다.

`RegionConfig` 컴포넌트를 활용하여 노출되는 위치를 조정할 수 있습니다.

## 활용

- 사용자가 한 행동에 대한 피드백을 화면 하단에 보여줍니다.
- 액션을 위한 버튼을 포함하지 않습니다.
- 가독성을 위해 메시지가 2줄 이상 넘지 않도록 작성합니다.

<Demo code={`import { useToast, Button } from '@wanteddev/wds';

const Demo = () => {
  const toast = useToast();

  const handleClick = () => {
    toast({
      variant: 'normal',
      content: '메시지에 마침표를 찍어요.',
    });
  };

  return (
    <Button onClick={handleClick}>클릭</Button>
  )
}

export default Demo;`}
/>

{ name: 'variant', types: '\"normal\" | \"warning\" | \"success\" | undefined', defaultValue: 'normal' },

## Example

<Demo code={`import { FlexBox, useToast, Button } from '@wanteddev/wds';
import { IconCircleFill } from '@wanteddev/wds-icon';

const Demo = () => {
  const toast = useToast();

  const handleClick = (variant = 'normal') => () => {
    toast({
      variant,
      content: '메시지에 마침표를 찍어요.',
      icon: <IconCircleFill sx={theme => ({ color: theme.palette.accent.cyan })} />
    });
  };

  return (
    <FlexBox gap="8px">
      <Button onClick={handleClick()}>normal</Button>
      <Button onClick={handleClick('success')}>success</Button>
      <Button onClick={handleClick('warning')}>warning</Button>
      <Button onClick={handleClick('custom')}>custom</Button>
    </FlexBox>
  )
}

export default Demo;`}
/>
