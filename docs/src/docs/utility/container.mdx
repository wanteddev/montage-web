# Container

콘텐츠 컨테이너 영역에 대한 스타일을 다룹니다.

헤더와 페이지 컨테이너에서 사용합니다.

## containerStyle

`containerStyle()(theme)` 로 사용합니다.

`containerStyle(true)(theme)` true를 인자로 넣을 경우 xl breakpoint에서도 대응합니다.

### Css Prop

```tsx
import { css } from '@emotion/react';
import { containerStyle } from '@wanteddev/wds';

import type { Theme } from '@emotion/react';

const Component = () => {
	return (
		<div
			css={containerStyle()}
		/>
	)
}
```

### Css 내부에서 사용

```ts
import { css } from '@emotion/react';
import { addOpacity } from '@wanteddev/wds';

import type { Theme } from '@emotion/react';

export const exampleStyle = (theme: Theme) => css`
  \$\{containerStyle()(theme)\}
`;
```
