# IconButton

인터랙션이 포함된 아이콘에 사용합니다.

## 활용

<Demo code={`import { IconButton } from '@wanteddev/wds';
import { IconPlus } from '@wanteddev/wds-icon';

const Demo = () => {
  return (
    <IconButton>
      <IconPlus />
    </IconButton>
  )
}

export default Demo;`}
/>

## Props

`as` Prop 으로 `Link` 등으로 활용할 수 있습니다.

<PropsTable component="IconButton" />

## Variant

### Normal

- 아이콘을 버튼으로 사용합니다.

<Demo code={`import { IconButton } from '@wanteddev/wds';
import { IconPlus } from '@wanteddev/wds-icon';

const Demo = () => {
  return (
    <IconButton variant=\"normal\">
      <IconPlus />
    </IconButton>
  )
}

export default Demo;`}
/>

### Background

- 하위 레이어와 구분할 때 사용합니다.

<Demo code={`import { IconButton } from '@wanteddev/wds';

  return (
    <IconButton variant=\"background\">

/>
