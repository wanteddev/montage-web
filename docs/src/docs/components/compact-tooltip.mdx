# CompactTooltip

행동 사이에서 안내할 내용이 있을 때 사용합니다.

## 활용

- 한 줄 이내의 간단한 내용을 표시할 때 사용합니다.
- 요소에 둘 때 쉽게 조합해 쓸 수 있습니다.

<Demo code={`import { CompactTooltip, CompactTooltipTrigger, CompactTooltipContent, Button } from '@wanteddev/wds';

const Demo = () => {
  return (
    <CompactTooltip>
      <CompactTooltipTrigger>
        <Button>마우스 호버</Button>
      </CompactTooltipTrigger>
      <CompactTooltipContent>
        내용
      </CompactTooltipContent>
    </CompactTooltip>
  )
}

export default Demo;`}
/>

### TooltipGroup

TooltipGroup을 사용하면 여러 개의 Tooltip을 그룹으로 묶어 자연스럽게 전환할 수 있습니다.

<Demo code={`import { FlexBox, TooltipGroup, CompactTooltip, CompactTooltipTrigger, CompactTooltipContent, IconButton } from '@wanteddev/wds';
import { IconCopy, IconTrash, IconRefresh } from '@wanteddev/wds-icon';

const Demo = () => {
  return (
    <FlexBox gap="10px">
      <TooltipGroup>
        <CompactTooltip>
          <CompactTooltipTrigger>
            <IconButton>
              <IconCopy />
            </IconButton>
          </CompactTooltipTrigger>
          <CompactTooltipContent shortcut="⌘C">
            복사
          </CompactTooltipContent>
        </CompactTooltip>
        <CompactTooltip>
          <CompactTooltipTrigger>
            <IconButton>
              <IconTrash />
            </IconButton>
          </CompactTooltipTrigger>
          <CompactTooltipContent shortcut="⌘⌫">
            삭제
          </CompactTooltipContent>
        </CompactTooltip>
        <CompactTooltip>
          <CompactTooltipTrigger>
            <IconButton>
              <IconRefresh />
            </IconButton>
          </CompactTooltipTrigger>
          <CompactTooltipContent shortcut="⌘R">
            새로고침
          </CompactTooltipContent>
        </CompactTooltip>
      </TooltipGroup>
    </FlexBox>
  );
};

export default Demo;`}
/>
