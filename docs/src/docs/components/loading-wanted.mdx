## Size

- width와 height를 size로 지정할 수 있어요.
- css의 width, height 속성과 동일한 값을 사용합니다.

<Demo code={`import { LoadingWanted, FlexBox } from '@wanteddev/wds';

const Demo = () => {
  return (
    <FlexBox alignItems="center">
      <LoadingWanted size="50px" />
      <LoadingWanted size="1em" />
    </FlexBox>
  );
}

export default Demo;`}
/>
