# NestedCheckbox

컨트롤 요소로 Checkbox를 조합해 쓰고자 할 때 사용합니다.

## 활용

- 낮은 위계로 활성화 여부를 제어할 때 사용합니다.
- `Checkbox` 와 활용법이 동일합니다.

<Demo code={`import { NestedCheckbox } from '@wanteddev/wds';

const Demo = () => {
  return (
    <NestedCheckbox />
  )
}

export default Demo;`}
/>
