# Checkbox

컨트롤 요소로 Checkbox를 조합해 쓰고자 할 때 사용합니다.

## 활용

- 보통 위계로 활성화 여부를 제어할 때 사용합니다.

<Demo code={`import { Checkbox } from '@wanteddev/wds';

const Demo = () => {
  return (
    <Checkbox />
  )
}

export default Demo;`}
/>

## Props

`bold` 옵션은 `input ~ label` 요소에 적용됩니다.

<PropsTable component="Checkbox" />

## Example

### Label

`size` 옵션과 `tight` 옵션, `FormField` 등을 활용하여 조합해요.

`size=normal` 일 때는 Label에 padding-y 1px 혹은 alignItems center로 정렬을 맞춰요.

<Demo code={`import { FlexBox, Checkbox, FormField, FormControl, FormLabel } from '@wanteddev/wds';

const Demo = () => {
  return (
    <FlexBox flexDirection="column" gap="8px">
      <FormField flexDirection="row" gap="8px">
        <FormControl>
          <Checkbox size="small" />
        </FormControl>
        <FormLabel>Size=Small, Tight=False</FormLabel>
      </FormField>

      <FormField flexDirection="row" gap="8px">
        <FormControl>
          <Checkbox size="small" tight />
        </FormControl>
        <FormLabel>Size=Small, Tight=True</FormLabel>
      </FormField>

      <FormField flexDirection="row" gap="8px">
        <FormControl>
          <Checkbox size="medium" />
        </FormControl>
        <FormLabel sx={{ padding: '1px 0px' }}>Size=Medium, Tight=False</FormLabel>
      </FormField>

      <FormField flexDirection="row" gap="8px">
        <FormControl>
          <Checkbox size="medium" tight />
        </FormControl>
        <FormLabel sx={{ padding: '1px 0px' }}>Size=Medium, Tight=True</FormLabel>
      </FormField>
    </FlexBox>
  )
}

export default Demo;`}
/>

### Indeterminate

<Demo code={`import { Button, FlexBox, Checkbox, FormField, FormControl, FormLabel, FormErrorMessage } from '@wanteddev/wds';
import { useForm, Controller } from 'react-hook-form';

const items = [
  {
    id: "develop",
    label: "개발",
  },
  {
    id: "design",
    label: "디자인",
  },
];

const Demo = () => {
  const form = useForm({
    defaultValues: {
      selected: ['develop'],
    },
  });

  const totalLength = items.length;

  return (
    <FlexBox
      as="form"
      flexDirection="column"
      gap="20px"
    >
      <Controller
        control={form.control}
        name="selected"
        render={({ formState }) => (
          <FormField>
            <FormLabel>관심 분야</FormLabel>

            <Controller
              control={form.control}
              name="selected"
              render={({ field }) => {
                return (
                  <FormField
                    flexDirection="row"
                    gap="8px"
                  >
                    <FormControl>
                      <Checkbox
                        {...field}
                        checked={field.value.length === totalLength}
                        indeterminate={field.value.length > 0 && field.value.length < totalLength}
                        onCheckedChange={(checked) => {
                          return checked
                            ? field.onChange(items.map(({ id }) => id))
                            : field.onChange([]);
                        }}
                      />
                    </FormControl>
                    <FormLabel sx={{ padding: '1px 0px' }}>전체 선택</FormLabel>
                  </FormField>
                );
              }}
            />

            {items.map((item) => (
              <Controller
                key={item.id}
                control={form.control}
                name="selected"
                render={({ field }) => {
                  return (
                    <FormField
                      key={item.id}
                      flexDirection="row"
                      gap="8px"
                      sx={{ marginLeft: 20 }}
                    >
                      <FormControl>
                        <Checkbox
                          {...field}
                          checked={field.value.includes(item.id)}
                          onCheckedChange={(checked) => {
                            return checked
                              ? field.onChange([...field.value, item.id])
                              : field.onChange(
                                  field.value.filter(
                                    (value) => value !== item.id
                                  )
                                );
                          }}
                        />
                      </FormControl>
                      <FormLabel sx={{ padding: '1px 0px' }}>{item.label}</FormLabel>
                    </FormField>
                  );
                }}
              />
            ))}
          </FormField>
        )}
      />
    </FlexBox>
  )
}

export default Demo;`}
/>

### Form

<Demo code={`import { Button, FlexBox, Checkbox, FormField, FormControl, FormLabel, FormErrorMessage } from '@wanteddev/wds';
import { useForm, Controller } from 'react-hook-form';

const Demo = () => {
  const form = useForm();

  return (
    <FlexBox
      as="form"
      flexDirection="column"
      gap="20px"
      onSubmit={form.handleSubmit((v) => alert(JSON.stringify(v)))}
    >
      <Controller
        control={form.control}
        name="checked"
        rules={{
          required: {
            value: true,
            message: "필수 값입니다.",
          },
        }}
        render={({ field, formState }) => (
          <FormField>
            <FlexBox gap="8px">
              <FormControl>
                <Checkbox
                  {...field}
                  checked={field.value}
                  onCheckedChange={field.onChange}
                />
              </FormControl>
              <FormLabel sx={{ padding: '1px 0px' }}>체크박스</FormLabel>
            </FlexBox>

            <FormErrorMessage>{formState.errors.checked?.message}</FormErrorMessage>
          </FormField>
        )}
      />

      <Button type="submit">제출</Button>
    </FlexBox>
  )
}

export default Demo;`}
/>
