# Empty State

- 콘텐츠가 빈 상태일 때 사용자의 이해를 돕기 위해 사용합니다.
- 이미지를 추가할 땐 `EmptyStateImage`로 감싸주세요.

<Demo code={`import { EmptyState, EmptyStateImage, EmptyStateContent, EmptyStateText, EmptyStateButton, FlexBox, ImageLoader } from '@wanteddev/wds';

const Demo = () => {
  return (
    <FlexBox justifyContent="center">
      <EmptyState>
        <EmptyStateImage>
          <ImageLoader
            quality={90}
            width="500px"
            src="https://static.wanted.co.kr/images/company/79/elpzxpmgh94xesrf__1080_790.png"
            alt="Wanted Company Image"
          />
        </EmptyStateImage>
        <EmptyStateContent>
          <EmptyStateText
            heading="타이틀이 들어가요." 
            description={
              <>
                상황에 대한 설명이 들어가요.
                <br />
                설명은 최대 두 줄로 작성해요.
              </>
            }
          />
          <EmptyStateButton>텍스트</EmptyStateButton>
        </EmptyStateContent>
      </EmptyState>
    </FlexBox>
  )
}

export default Demo;`}
/>

## Components

아래와 같이 조합하여 사용합니다.

```tsx
<EmptyState>
  <EmptyStateImage />
  <EmptyStateContent>
    <EmptyStateText />
    <EmptyStateButton />
  </EmptyStateContent>
</EmptyState>
```
