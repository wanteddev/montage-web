# Empty State

콘텐츠가 빈 상태일 때 사용자의 이해를 돕기 위해 사용합니다.

<Demo code={`import { EmptyState, EmptyStateContent, EmptyStateText, EmptyStateButton, FlexBox } from '@wanteddev/wds';

const Demo = () => {
  return (
    <FlexBox justifyContent="center">
      <EmptyState>
        <EmptyStateContent>
          <EmptyStateText
            heading="타이틀이 들어가요." 
            description={
              <>
                상황에 대한 설명이 들어가요.
                <br />
                설명은 최대 두 줄로 작성해요.
              </>
            }
          />
          <EmptyStateButton>텍스트</EmptyStateButton>
        </EmptyStateContent>
      </EmptyState>
    </FlexBox>
  )
}

export default Demo;`}
/>

## Components

아래와 같이 조합하여 사용합니다.

```tsx
<EmptyState>
  <EmptyStateImage />
  <EmptyStateContent>
    <EmptyStateText />
    <EmptyStateButton />
  </EmptyStateContent>
</EmptyState>
```
