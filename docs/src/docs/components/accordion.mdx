# Accordion

- 내용을 최소화하거나 펼칠 때 사용합니다.
- AccordionSummary의 rightContent를 교체할 때는 `AccordionSummaryContent`로 감싸서 사용합니다.

## 활용

<Demo code={`import { Accordion, AccordionSummary, AccordionDetails, AccordionDescription } from '@wanteddev/wds';

const Demo = () => {
  return (
    <Accordion>
      <AccordionSummary>
        제목
      </AccordionSummary>
      <AccordionDetails>
        <AccordionDescription>
          제목에 대한 상세 내용을 입력해주세요.<br />
          긴 컨텐츠라면 접은 상태를 기본 값으로 사용하세요.
        </AccordionDescription>
      </AccordionDetails>
    </Accordion>
  )
}

export default Demo;`}
/>

## Components

아래와 같이 조합하여 사용합니다.

```tsx
<Accordion>
  <AccordionSummary>
    제목
  </AccordionSummary>
  <AccordionDetails>
    <AccordionDescription>
      내용
    </AccordionDescription>
  </AccordionDetails>
</Accordion>
```

### RightContent

- AccordionSummary의 기본 rightContent를 교체할 수 있어요.
- rightContent가 a 태그이거나 클릭 이벤트가 있는 경우 `e.stopPropagation` 을 통해 아코디언이 열리고 닫히는 동작을 막을 수 있어요.

<Demo code={`import { Accordion, AccordionSummary, AccordionDetails, AccordionDescription, AccordionSummaryContent, IconButton } from '@wanteddev/wds';
import { IconCircleCheckFill, IconChevronDown, IconArrowRight, IconCaretDown } from '@wanteddev/wds-icon';
import { useState } from 'react';

const Demo = () => {
  const [expandedCheckAccordion, setExpandedCheckAccordion] = useState(false);

  return (
    <div>
      <Accordion disabled>
        <AccordionSummary>
          Disabled, true
        </AccordionSummary>
        <AccordionDetails>
          <AccordionDescription>
            제목에 대한 상세 내용을 입력해주세요.<br />
            긴 컨텐츠라면 접은 상태를 기본 값으로 사용하세요.
          </AccordionDescription>
        </AccordionDetails>
      </Accordion>

      <Accordion>
        <AccordionSummary
          rightContent={
            <AccordionSummaryContent variant="icon">
              <IconCaretDown />
            </AccordionSummaryContent>
          }
        >
          RightContent, Icon<br />
        </AccordionSummary>
        <AccordionDetails>
          <AccordionDescription>
            제목에 대한 상세 내용을 입력해주세요.<br />
            긴 컨텐츠라면 접은 상태를 기본 값으로 사용하세요.
          </AccordionDescription>
        </AccordionDetails>
      </Accordion>

      <Accordion
        expanded={expandedCheckAccordion}
        onChange={setExpandedCheckAccordion}
      >
        <AccordionSummary
          rightContent={
            <AccordionSummaryContent
              variant="icon"
              disableExpandIconAnimation
            >
              <IconCircleCheckFill 
                sx={(theme) => ({
                  color: expandedCheckAccordion 
                    ? theme.palette.primary.normal 
                    : theme.palette.label.alternative,
                })}
              />
            </AccordionSummaryContent>
          }
        >
          RightContent, Icon<br />
          DisableExpandIconAnimation, true
        </AccordionSummary>
        <AccordionDetails>
          <AccordionDescription>
            제목에 대한 상세 내용을 입력해주세요.<br />
            긴 컨텐츠라면 접은 상태를 기본 값으로 사용하세요.
          </AccordionDescription>
        </AccordionDetails>
      </Accordion>
      
      <Accordion>
        <AccordionSummary
          rightContent={
            <AccordionSummaryContent variant="icon-button">
              <IconButton>
                <IconChevronDown
                  sx={(theme) => ({
                    color: theme.palette.label.normal,
                  })}
                />
              </IconButton>
            </AccordionSummaryContent>
          }
        >
          RightContent, IconButton
        </AccordionSummary>
        <AccordionDetails>
          <AccordionDescription>
            제목에 대한 상세 내용을 입력해주세요.<br />
            긴 컨텐츠라면 접은 상태를 기본 값으로 사용하세요.
          </AccordionDescription>
        </AccordionDetails>
      </Accordion>

      <Accordion>
        <AccordionSummary
          rightContent={
            <AccordionSummaryContent
              variant="icon-button"
              disableExpandIconAnimation
            >
              <IconButton
                as="a"
                href="https://www.wanted.co.kr"
                target="_blank"
                onClick={(e) => {
                  e.stopPropagation();
                }}
              >
                <IconArrowRight />
              </IconButton>
            </AccordionSummaryContent>
          }
        >
          RightContent, IconButton<br />
          DisableExpandIconAnimation, true<br />
          rightContent onClick
        </AccordionSummary>
        <AccordionDetails>
          <AccordionDescription>
            제목에 대한 상세 내용을 입력해주세요.<br />
            긴 컨텐츠라면 접은 상태를 기본 값으로 사용하세요.
          </AccordionDescription>
        </AccordionDetails>
      </Accordion>
    </div>
  )
}

export default Demo;`}
/>
