# ChipFilter

필터 리스트에 사용합니다.

## 활용

- 일반적으로 칩을 누르면 화면이 이동해요.

<Demo code={`import { ChipFilter } from '@wanteddev/wds';

const Demo = () => {
  return (
    <ChipFilter>
      Chip Action
    </ChipFilter>
  );
}

export default Demo;`}
/>

### TextNumber

      <ChipFilter textNumber={3} active>직무</ChipFilter>
