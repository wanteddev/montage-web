# Card

- 일반적인 상황에서 정보를 묶어 표시할 때 사용합니다.
- leftContent, rightContent에 요소를 추가 할 때는 `CardThumbnailContent` 로 감싸주세요.

<Demo code={`import { FlexBox, Card, CardThumbnail, CardTitle, CardCaption, CardContent, CardThumbnailContent } from '@wanteddev/wds';
import { IconBookmark, IconBookmarkFill } from '@wanteddev/wds-icon';
import { useState } from 'react';

const Demo = () => {
  const [isBookmarked, setIsBookmarked] = useState(false);

  const handleThumbnailIconClick = () => {
    if (!isBookmarked) {
      alert('북마크에 저장되었습니다.');
    }
    setIsBookmarked((prevIsBookmarked) => !prevIsBookmarked);
  }

  return (
    <Card width="240px" as="a" href="https://wanted.co.kr" target="_blank" sx={{ margin: 'auto' }}>
      <CardThumbnail
        src="https://static.wanted.co.kr/images/company/79/elpzxpmgh94xesrf__1080_790.png"
        alt="Wanted Company Image"
        width="240px"
        quality={95}
        overlay
        leftContent={
          <CardThumbnailContent variant="text">
            캡션
          </CardThumbnailContent>
        }
        rightContent={
          <CardThumbnailContent variant="icon" onClick={handleThumbnailIconClick}>
            {isBookmarked 
              ? <IconBookmarkFill sx={(theme) => ({ color: theme.palette.primary.normal })} /> 
              : <IconBookmark />
            }
          </CardThumbnailContent>
        }
      />
      <CardContent>
        <CardTitle>제목</CardTitle>
        <CardCaption>캡션</CardCaption>
      </CardContent>
    </Card>
  );
}

export default Demo;`}
/>

## Components

아래와 같이 조합하여 사용합니다.

```tsx
<Card>
  <CardThumbnail />
  <CardContent>
    <CardExtraContent/>
    <CardTitle />
    <CardCaption />
    <CardExtraContent />
  </CardContent>
</Card>
```

## Examples

### Width

- `width`를 지정할 수 있고, 지정하지 않으면 100%의 너비를 사용해요.
- ResponsiveProps를 사용하여 해당 breakpoint 이상일 때 width를 사용할 수 있어요.

<Demo code={`import { FlexBox, Card, CardThumbnail, CardTitle, CardCaption, CardContent, CardExtraContent, ContentBadge } from '@wanteddev/wds';

const Demo = () => {
  return (
    <Card sm={{ width: '240px' }} sx={{ margin: 'auto' }}>
      <CardThumbnail showFallback width="240px" />
      <CardContent>
        <CardTitle>제목</CardTitle>
        <CardCaption>(min-width: 768px), width: 240px</CardCaption>
      </CardContent>
    </Card>
  );
}

export default Demo;`}
/>

`platform`에 따라 글자 크기, `CardThumbnail`의 비율이 달라요.

<Demo code={`import { FlexBox, Card, CardThumbnail, CardTitle, CardCaption, CardContent, CardThumbnailContent } from '@wanteddev/wds';
import { IconBookmark } from '@wanteddev/wds-icon';

const Demo = () => {
  return (
    <FlexBox gap="24px" justifyContent="center">
      <Card width="240px">

          leftContent={
            <CardThumbnailContent variant="text">
              캡션

        <CardContent>

          showFallback

          leftContent={
            <CardThumbnailContent variant="text">
              캡션
            </CardThumbnailContent>
          }
          rightContent={
            <CardThumbnailContent variant="icon">
              <IconBookmark />
            </CardThumbnailContent>

        />
        <CardContent>
          <CardTitle>platform: mobile</CardTitle>
          <CardCaption>캡션</CardCaption>

/>

- ResponsiveProps를 사용하여 해당 breakpoint 이상일 때 platform을 지정할 수 있어요.
- `width`와 조합해서 사용할 수 있어요.

<Demo code={`import { FlexBox, Card, CardThumbnail, CardTitle, CardCaption, CardContent, CardThumbnailContent } from '@wanteddev/wds';
import { IconBookmark } from '@wanteddev/wds-icon';

const Demo = () => {
  return (
    <Card platform="mobile" sm={{ width: '240px', platform: 'desktop' }} sx={{ margin: 'auto' }}>
      <CardThumbnail
        showFallback
        width="240px"
        overlay
        leftContent={
          <CardThumbnailContent variant="text">
            캡션
          </CardThumbnailContent>
        }
        rightContent={
          <CardThumbnailContent variant="icon">
            <IconBookmark />
          </CardThumbnailContent>
        }
      />
      <CardContent>
        <CardTitle>제목</CardTitle>
        <CardCaption>(min-width: 768px), width: 240px</CardCaption>
        <CardCaption>(min-width: 768px), platform: desktop</CardCaption>
      </CardContent>
    </Card>
  );
}

export default Demo;`}
/>

### Top Content, Bottom Content

- `CardExtraContent`의 `position`을 조정하여 top, bottom에 콘텐츠를 추가할 수 있어요.
- 뱃지나 부가적인 내용을 추가할 때 사용해요.

<Demo code={`import { FlexBox, Card, CardThumbnail, CardTitle, CardCaption, CardContent, CardExtraContent, ContentBadge } from '@wanteddev/wds';

const Demo = () => {
  return (
    <FlexBox gap="24px" justifyContent="center">
      <Card width="240px">
        <CardThumbnail showFallback width="240px" />
        <CardContent>
          <CardExtraContent position="top" variant="badge">
            {new Array(3).fill(0).map((_, i) => (
              <ContentBadge key={i} color="neutral">텍스트</ContentBadge>
            ))}
          </CardExtraContent>
          <CardTitle>제목</CardTitle>
          <CardCaption>캡션</CardCaption>
        </CardContent>
      </Card>
      <Card width="240px">
        <CardThumbnail showFallback width="240px" />
        <CardContent>
          <CardTitle>제목</CardTitle>
          <CardCaption>캡션</CardCaption>
          <CardExtraContent position="bottom" variant="badge">
            {new Array(3).fill(0).map((_, i) => (
              <ContentBadge key={i} color="neutral">텍스트</ContentBadge>
            ))}
          </CardExtraContent>
        </CardContent>
      </Card>
    </FlexBox>
  );
}

export default Demo;`}
/>
