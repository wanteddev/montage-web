# ProgressTrackerDesktop

데스크톱에서 내비게이션 하단에 번호를 통해 단계별 진행 상황을 표시합니다.

## 활용

- 번호가 매겨진 단계로 진행 상황을 전달합니다.
- 클릭 또는 터치할 수 없는 요소로 사용합니다.
- 단계 편집이 가능한 곳에는 쓰지 않습니다.

<Demo code={`import { ProgressTrackerDesktop, ProgressTrackerDesktopItem } from '@wanteddev/wds';

const Demo = () => {
  return (
    <ProgressTrackerDesktop value="1">
      <ProgressTrackerDesktopItem value="0" />
      <ProgressTrackerDesktopItem value="1" />
      <ProgressTrackerDesktopItem value="2" />
    </ProgressTrackerDesktop>
  );
}

export default Demo;`}
/>

## Label

`label`, `completedLabel` prop을 통해 라벨을 주입할 수 있습니다.

<Demo code={`import { ProgressTrackerDesktop, ProgressTrackerDesktopItem } from '@wanteddev/wds';

const Demo = () => {
  return (
    <ProgressTrackerDesktop direction="vertical" value="1">
      <ProgressTrackerDesktopItem label="단계" completedLabel="완료" value="0" />
      <ProgressTrackerDesktopItem label="단계" completedLabel="완료" value="1" />
      <ProgressTrackerDesktopItem label="단계" completedLabel="완료" value="2" />
    </ProgressTrackerDesktop>
  );
}

export default Demo;`}
/>
