# Menu

사용자가 클릭하거나 호버할 시 여러 옵션들을 선택할 수 있습니다.

## 활용

- `Menu`의 값은 `MenuItem`의 variant에 따라 달라져요.
  - normal, radio, variant를 선택하면 값이 문자열이 됩니다.
  - checkbox variant를 선택하면 값은 문자열 배열이 됩니다.
- `MenuBottom`의 leftContent, rightContent에 요소를 추가 할 때는 `MenuBottomContent`로 감싸서 사용합니다.

<Demo code={`import { Button, Menu, MenuTrigger, IconButton, TextButton, ContentBadge, Button, MenuContent, MenuBottom, MenuBottomContent, MenuGroup, MenuItem, ListText, ChipFilter, MenuList } from '@wanteddev/wds';

const Demo = () => {
  return (
    <Menu onValueChange={(value) => console.log(value)}>
      <MenuTrigger>
        <Button>Click me</Button>

          }

      </MenuContent>
    </Menu>
  )
}

export default Demo;`}
/>

## Components

아래와 같이 조합하여 사용합니다.

```tsx
<Menu>
  <MenuTrigger>
    <Button>텍스트</Button>
  </MenuTrigger>

  <MenuContent>
    <MenuList>  
      <MenuGroup>
        <MenuItem>
          아이템1
        </MenuItem>
        <MenuItem>
          아이템2
        </MenuItem>
      </MenuGroup>
      <MenuGroup>
        <MenuItem>
          아이템3
        </MenuItem>
        <MenuItem>
          아이템4
        </MenuItem>
      </MenuGroup>
    </MenuList>

    <MenuBottom />
  </MenuContent>
</Menu>
```
