# Menu

## Components

아래와 같이 조합하여 사용합니다.

```tsx
<Menu>
  <MenuTrigger>
    클릭
  </MenuTrigger>

  <MenuContent> // List return, RadioGroup & 키보드 이벤트 처리
    <MenuGroup title="그룹1">
      <MenuItem variant="radio" value="man"> // variant랑 value만 받고, 내부적으로 string or string[] state를 변경함
        Man
      </MenuItem>
    </MenuGroup>
    <MenuGroup title="그룹2">
      <MenuItem variant="radio" value="woman">
        Woman
      </MenuItem>
    </MenuGroup>
  </MenuContent>
</Menu>
```
