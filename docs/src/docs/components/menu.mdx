# Menu

사용자가 클릭하거나 호버할 시 여러 옵션들을 선택할 수 있습니다.

## 활용

- `Menu`의 값은 `MenuItem`의 variant에 따라 달라져요.
  - normal, radio, variant를 선택하면 value는 문자열이고, checkbox variant를 선택하면 value는 Array\<value\> 입니다.
- `MenuItem` 의 leadingContent, trailingContent에 요소를 추가 할 때는 `MenuItemContent`로 감싸서 사용합니다.
- `MenuActionArea`의 leadingContent, trailingContent에 요소를 추가 할 때는 `MenuActionAreaContent`로 감싸서 사용합니다.

<Demo code={`import { Button, Menu, MenuTrigger, MenuContent, MenuActionArea, MenuActionAreaContent, MenuGroup, MenuItem, MenuList } from '@wanteddev/wds';
import { IconRefresh } from '@wanteddev/wds-icon';

const Demo = () => {
  return (
    <Menu onValueChange={(value) => console.log(value)}>
      <MenuTrigger>
        <Button>Click me</Button>
      </MenuTrigger>

      <MenuContent>
        <MenuList>
          <MenuGroup title="그룹1">
            <MenuItem variant="radio" value="item1">
              아이템1
            </MenuItem>
            <MenuItem variant="radio" value="item2">
              아이템2
            </MenuItem>
            <MenuItem variant="radio" value="item3">
              아이템3
            </MenuItem>
          </MenuGroup>
          <MenuGroup title="그룹2">
            <MenuItem variant="radio" value="item4">
              아이템4
            </MenuItem>
            <MenuItem variant="radio" value="item5">
              아이템5
            </MenuItem>
            <MenuItem variant="radio" value="item6">
              아이템6
            </MenuItem>
          </MenuGroup>
          <MenuGroup title="그룹3">
            <MenuItem variant="radio" value="item7">
              아이템7
            </MenuItem>
            <MenuItem variant="radio" value="item8">
              아이템8
            </MenuItem>
            <MenuItem variant="radio" value="item9">
              아이템9
            </MenuItem>
          </MenuGroup>
        </MenuList>

        <MenuActionArea
          leadingContent={
            <MenuActionAreaContent variant="button">
              <Button
                variant="outlined"
                color="assistive"
                iconOnly
                size="small"
              >
                <IconRefresh />
              </Button> 
            </MenuActionAreaContent>
          }
          trailingContent={
            <MenuActionAreaContent variant="button">
              <Button size="small">
                텍스트
              </Button>
            </MenuActionAreaContent>
          }
        />
      </MenuContent>
    </Menu>
  )
}

export default Demo;`}
/>

## Components

아래와 같이 조합하여 사용합니다.

```tsx
<Menu>
  <MenuTrigger>
    <Button>텍스트</Button>
  </MenuTrigger>

  <MenuContent>
    <MenuList>  
      <MenuGroup>
        <MenuItem>
          아이템1
        </MenuItem>
        <MenuItem>
          아이템2
        </MenuItem>
      </MenuGroup>
      <MenuGroup>
        <MenuItem>
          아이템3
        </MenuItem>
        <MenuItem>
          아이템4
        </MenuItem>
      </MenuGroup>
    </MenuList>

    <MenuActionArea />
  </MenuContent>
</Menu>
```
