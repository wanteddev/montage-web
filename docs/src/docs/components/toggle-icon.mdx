# ToggleIcon

아이콘으로 활성화 여부를 제어할 때 사용합니다.

## 활용

<Demo code={`import { ToggleIcon } from '@wanteddev/wds';
import { IconHeart } from '@wanteddev/wds-icon';

const Demo = () => {
  return (
    <ToggleIcon>
      <IconHeart />
    </ToggleIcon>
  )
}

export default Demo;`}
/>

## Props

`as` Prop 으로 `Link` 등으로 활용할 수 있습니다.

<PropsTable component="ToggleIcon" />

## Examples

active 상태를 통해 색상, 아이콘 등을 자유롭게 변경할 수 있습니다.

<Demo code={`import { useState } from 'react';
import { ToggleIcon } from '@wanteddev/wds';
import { IconHeart, IconHeartFill } from '@wanteddev/wds-icon';

const Demo = () => {
  const [active, setActive] = useState(false);

  return (
    <ToggleIcon active={active} onActiveChange={setActive} activeColor="palette.status.negative">
      {active ? <IconHeartFill /> : <IconHeart />}
    </ToggleIcon>
  )
}

export default Demo;`}
/>
