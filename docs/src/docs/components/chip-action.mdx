# ChipAction

동작을 설정하거나 실행합니다.(e.g. 화면 이동, 추가, 삭제)

## 활용

- Chip은 반응적이므로 콘텐츠의 특성에 따라 다른 동작을 제공해야 합니다.
- Chip의 텍스트에 말 줄임표(...) 사용을 지양합니다.
- Chip의 텍스트에 ‘#’을 붙이지 않아요.

<Demo code={`import { ChipAction } from '@wanteddev/wds';

const Demo = () => {
  return (
    <ChipAction>
      Chip Action
    </ChipAction>
  );
}

export default Demo;`}
/>
