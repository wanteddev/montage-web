# Tab

Tab은 사용자 인터페이스에서 여러 콘텐츠를 하나의 화면 내에서 구분하여 표시할 수 있는 컴포넌트입니다.

## 활용

- Top Navigation과 함께 사용하여 스크롤 시 Sticky되어 될 수 있습니다.
- 3개 이하의 Tab에서 Label이 길어질 시 `resize="fill"` 옵션을 사용하여 시각 보정을 할 수 있습니다.
- 화면을 분할하여 정보를 제공하는 모든 컴포넌트 요소 중 가장 상위 레벨을 갖고 있습니다.
- Label은 가급적 5자 이하의 명사 사용을 권장하며 5자를 넘을 시 Compact 타입을 사용하여 시각 보정을 할 수 있습니다.

## Components

Tab 은 여러 컴포넌트를 조합해서 사용합니다.

기본 구성은 아래와 같습니다.

```tsx
<Tab>
  <TabList>
    <TabListItem />
    <TabListItem />
    <TabListItem />
  </TabList>

  <TabPannel />
  <TabPannel />
  <TabPannel />
</Tab>
```

### TabPanel

`TabPanel` 은 성능 최적화를 위해 마운트 모드를 설정할 수 있습니다.

- `only-active` 는 활성화 상태일 때만 렌더링 되며 상태가 변경되는 경우 언마운트 됩니다.
- `force-mount` 는 활성화 상태일 때 렌더링 되며 상태가 변경되는 경우 언마운트되지 않고 숨김 처리 됩니다.
- `always` 는 항상 렌더링 되어 있으며 상태가 변경되는 경우 언마운트되지 않고 숨김 처리 됩니다.
