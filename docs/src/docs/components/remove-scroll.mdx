# RemoveScroll

`RemoveScroll` 은 children 혹은 `shards` 에 포함된 요소 외의
모든 스크롤을 비활성화하고, 언마운트시 다시 스크롤 가능하게 합니다.

Modal 등에서 사용하고 있으며 일반적으로는 사용하지 않고 시스템 컴포넌트를 제작할 때 사용합니다.
