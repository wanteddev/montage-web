# Thumbnail

작은 이미지의 형식으로 구성되며, 이를 통해 콘텐츠 및 제품의 내용을 추론할 수 있게 도와주는 역할을 담당합니다.

## 활용

- 화면을 탐색할 때 해당 콘텐츠들에 대한 빠른 이해와 색인을 도와줍니다.
- 일반적으로 카드 컴포넌트의 이미지 영역에 사용합니다.
- Width 값을 설정하면 비율에 맞게 Height 값이 조절됩니다.
- 세로가 긴 Portrait 옵션이 있습니다.
- 이미지에 Rounded Square 형태를 사용하려면 R 값은 4로 적용합니다.

<Demo code={`import { Thumbnail } from '@wanteddev/wds';

const Demo = () => {
  return (
    <Thumbnail
      src="https://static.wanted.co.kr/images/company/79/elpzxpmgh94xesrf__1080_790.png"
      alt="Wanted Company Image"
      width="200px"
      quality={95}
    />
  )
}

export default Demo;`}
/>

## Usage

### 이미지 깨짐 방지

이미지 깨짐을 방지하기 위해서 `quality` 와 `width` 를 적절하게 조절합니다.

혹은 `disableOptimize` 를 사용합니다.

<Demo code={`import { FlexBox, Thumbnail } from '@wanteddev/wds';

const Demo = () => {
  return (
    <FlexBox>
      <Thumbnail
        src="https://static.wanted.co.kr/images/company/79/elpzxpmgh94xesrf__1080_790.png"
        alt="Wanted Company Image"
        width="400px"
        quality={95}
        sx={{ width: '200px' }}
      />
      <Thumbnail
        src="https://static.wanted.co.kr/images/company/79/elpzxpmgh94xesrf__1080_790.png"
        alt="Wanted Company Image"
        width="200px"
        disableOptimize
      />
    </FlexBox>
  )
}

export default Demo;`}
/>

### Responsive

`srcset`, `sizes` 속성을 통해 브라우저 첫 접속 시 `mediaQuery` 에 따라 사진 사이즈를 조절할 수 있습니다.

또한 단순 스타일로도 반응형 대응을 할 수 있습니다.

<Demo code={`import { Thumbnail, getOptimizedImageSource, useMedia } from '@wanteddev/wds';

const Demo = () => {
  const { breakpoint, respondTo } = useMedia();

  return (
    <Thumbnail
      src="https://static.wanted.co.kr/images/company/79/elpzxpmgh94xesrf__1080_790.png"
      quality={90}
      width="400px"
      alt="Wanted Company Image"
      srcSet={\`\$\{getOptimizedImageSource({
        src: 'https://static.wanted.co.kr/images/company/79/elpzxpmgh94xesrf__1080_790.png',
        width: '200px',
        quality: 90
      })\} 200w, \$\{getOptimizedImageSource({
        src: 'https://static.wanted.co.kr/images/company/79/elpzxpmgh94xesrf__1080_790.png',
        width: '400px',
        quality: 90
      })\} 400w\`}
      sizes="(max-width: 767px) 200px, 400px"
      sx={{
        width: '200px',
        [respondTo(breakpoint.sm)]: {
          width: '100px'
        }
      }}
    />
  )
}

export default Demo;`}
/>
