# FloatingAction

주요하나 필수적이지 않은 행동을 표시할 때 사용합니다.

## 활용

- 행동을 표시하기에는 내비게이션에 영역이 충분하지 않거나, 밖으로 강조가 필요한 경우에 사용해요.

<Demo code={`import { FloatingAction } from '@wanteddev/wds';
import { IconPencil } from '@wanteddev/wds-icon';

const Demo = () => {
  return (
    <FloatingAction>
      <IconPencil />
    </FloatingAction>
  )
}

export default Demo;`}
/>


## Props

`as` Prop 으로 `Link` 등으로 활용할 수 있습니다.
