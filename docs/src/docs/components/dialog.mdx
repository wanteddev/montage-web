# Dialog

## 활용

- 유저에게 중요한 액션을 실행할지 다시 한 번 묻고 싶을 때 사용해요.
- Promise 형태로 사용하려면 [useDialog](../hooks/use-dialog) 훅을 사용해요.

<Demo code={`import { FlexBox, Button, Typography, Dialog, DialogContainer, DialogContent, DialogHeading, DialogDescription, DialogActionArea, DialogActionAreaButton, DialogTrigger } from '@wanteddev/wds';
import { useState } from 'react';

const Demo = () => {
  const [open, setOpen] = useState(false);
  const [result, setResult] = useState<string | null>(null);

  const handleOpen = () => {
    setOpen(true);
  }

  return (
    <FlexBox flexDirection="column" gap="16px">
      <Typography>{result}</Typography>

      <Dialog open={open} onOpenChange={setOpen}>
        <DialogTrigger>
          <Button onClick={handleOpen}>열기</Button>
        </DialogTrigger>

        <DialogContainer onDismiss={() => setResult('Dismissed')}>
          <DialogContent>
            <DialogHeading>제목</DialogHeading>
            <DialogDescription>설명</DialogDescription>
          </DialogContent>
          <DialogActionArea>
            <DialogActionAreaButton variant="normal" onClick={() => setResult('Confirm')}>
              확인
            </DialogActionAreaButton>
            <DialogActionAreaButton variant="assistive" onClick={() => setResult('Cancel')}>
              취소
            </DialogActionAreaButton>
            <DialogActionAreaButton variant="negative" onClick={() => setResult('Negative')}>
              삭제
            </DialogActionAreaButton>
          </DialogActionArea>
        </DialogContainer>
      </Dialog>
    </FlexBox>
  )
}

export default Demo;`}
/>

## Components

Dialog 는 여러 컴포넌트를 조합해서 사용합니다.

`DialogTrigger` 는 선택적으로 사용할 수 있습니다.

기본 구성은 아래와 같습니다.

```tsx
<Dialog>
  <DialogTrigger>
    <Button>열기</Button>
  </DialogTrigger>

  <DialogContainer>
    <DialogContent>
      <DialogHeading />
      <DialogDescription />
    </DialogContent>

    <DialogActionArea>
      <DialogActionAreaButton />
    </DialogActionArea>
  </DialogContainer>
</Dialog>
```
