# Snackbar

## 활용

- 간단한 메시지와 상호작용을 안내할 때 사용해요.
- [useSnackbar](../hooks/use-snackbar) 훅을 사용하면 더 간편하게 사용할 수 있어요.

<Demo code={`import { FlexBox, Snackbar, SnackbarContent, SnackbarHeading, SnackbarDescription, SnackbarAction } from '@wanteddev/wds';

const Demo = () => {
  return (
    <FlexBox justifyContent="center">
      <Snackbar open disablePortal disableAnimation>
        <SnackbarContent>
          <SnackbarHeading>메시지에 마침표를 찍어요.</SnackbarHeading>
          <SnackbarDescription>설명은 필요할 때만 써요.</SnackbarDescription>
        </SnackbarContent>

        <SnackbarAction>확인</SnackbarAction>
      </Snackbar>
    </FlexBox>
  )
}

export default Demo;`}
/>

## Components

Toast 는 여러 컴포넌트를 조합해서 사용합니다.

기본 구성은 아래와 같습니다.

```tsx
<Snackbar>
  <SnackbarContent extraContent={<SnackbarExtraContent />}>
    <SnackbarHeading />
    <SnackbarDescription />
  </SnackbarContent>

  <SnackbarAction />
</Snackbar>
```

## Examples

### Extra Content

`SnackbarContent` 의 `extraContent` 속성으로 추가적인 컨텐츠를 추가할 수 있어요.

<Demo code={`import { FlexBox, Snackbar, SnackbarContent, SnackbarHeading, SnackbarDescription, SnackbarExtraContent } from '@wanteddev/wds';
import { IconBlank } from '@wanteddev/wds-icon';

const Demo = () => {
  return (
    <FlexBox justifyContent="center">
      <Snackbar open disablePortal disableAnimation>
        <SnackbarContent
          extraContent={(
            <SnackbarExtraContent>
              <IconBlank />
            </SnackbarExtraContent>
          )}
        >
          <SnackbarHeading>메시지에 마침표를 찍어요.</SnackbarHeading>
          <SnackbarDescription>설명은 필요할 때만 써요.</SnackbarDescription>
        </SnackbarContent>
      </Snackbar>
    </FlexBox>
  )
}

export default Demo;`}
/>
