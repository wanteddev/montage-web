# ActionArea

## 활용

- 액션 영역을 구성할 때 사용합니다.
- 내부 간격을 조정할 때는 `--wds-action-area-margin-x`, `--wds-action-area-margin-y`, `--wds--action-area-extra-content-margin` 을 사용해주세요.
- 스크롤에 따라 sticky 옵션을 prop 으로 조정해요.
- 모달 내부에서 사용할 경우에는 별도의 추가 처리가 필요하지 않아요. (sticky, 간격)
- `ActionAreaButton` 의 버튼 variant를 교체할 수 있어요.
  - buttonVariant, buttonColor, textButtonVariant

<Demo code={`import {
  ActionArea,
  ActionAreaButton,
} from '@wanteddev/wds';

const Demo = () => {
  return (
    <ActionArea>
      <ActionAreaButton>
        액션
      </ActionAreaButton>
    </ActionArea>
  )
}

export default Demo;`}
/>
