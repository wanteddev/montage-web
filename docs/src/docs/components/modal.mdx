# Modal

## 활용

- Modal Overlay를 표시합니다.
- `huge` 사이즈는 560px를 초과해서 사용하고 싶을 때 활용해요.
  - 640, 720, 800 같이 80px 단위로 끊어서 사용해요.
- `ModalNavigation` 에서 leftContent, rightContent 에는 `ModalNavigationButton`, `ModalClose` 를 사용합니다.
- `ModalContainer`, `ModalNavigation`, `ModalContent`, `ActionArea` 의 위계를 변경해서는 안됩니다.

<Demo code={`import { useState } from 'react';
import {
  Button,
  Modal,
  ActionArea,
  ActionAreaButton,
  ModalContainer,
  ModalContent,
  ModalContentItem,
  ModalDescription,
  ModalHeading,
  ModalNavigation,
  ModalSummary,
} from '@wanteddev/wds';

const Demo = () => {
  const [show, setShow] = useState(false);

  return (
    <>
      <Modal
        open={show}
        onOpenChange={setShow}
      >
        <ModalContainer variant="popup">
          <ModalNavigation>
            제목
          </ModalNavigation>

          <ModalContent>
            <ModalContentItem>
              <ModalHeading>Heading</ModalHeading>
              <ModalSummary>Summary</ModalSummary>
              <ModalDescription>Description</ModalDescription>
            </ModalContentItem>
          </ModalContent>

          <ActionArea>
            <ActionAreaButton>
              액션
            </ActionAreaButton>
          </ActionArea>
        </ModalContainer>
      </Modal>

      <Button onClick={() => setShow(true)}>Click me</Button>
    </>
  )
}

export default Demo;`}
/>

## Components

Modal 은 여러 컴포넌트를 조합해서 사용합니다.

기본 구성은 아래와 같습니다.

```tsx
<Modal>
  <ModalContainer>
    <ModalNavigation />

    <ModalContent>
      <ModalContentItem>
        <ModalHeading />
        <ModalSummary />
        <ModalDescription />
      </ModalContentItem>
    </ModalContent>

    <ActionArea>
      <ActionAreaButton />
    </ActionArea>
  </ModalContainer>
</Modal>
```

## Examples

### Handle

`variant="bottom"` 일 때 드래그로 숨기고 열 수 있는 옵션을 사용할 수 있습니다.

<Demo code={`import { useState } from 'react';
import {
  Button,
  Modal,
  ActionArea,
  ActionAreaButton,
  ModalContainer,
  ModalContent,
  ModalContentItem,
  ModalDescription,
  ModalHeading,
  ModalNavigation,
  ModalSummary,
} from '@wanteddev/wds';

const Demo = () => {
  const [show, setShow] = useState(false);

  return (
    <>
      <Modal
        open={show}
        onOpenChange={setShow}
      >
        <ModalContainer variant="bottom" handle>
          <ModalNavigation>
            제목
          </ModalNavigation>

          <ModalContent>
            <ModalContentItem>
              <ModalHeading>Heading</ModalHeading>
              <ModalSummary>Summary</ModalSummary>
              <ModalDescription>Description</ModalDescription>
            </ModalContentItem>
          </ModalContent>

          <ActionArea>
            <ActionAreaButton>
              액션
            </ActionAreaButton>

      <Button onClick={() => setShow(true)}>Click me</Button>

  )

export default Demo;`}
/>

또한 `onVisibilityChange` prop 을 사용하면 아래로 숨김 처리 되지 않고 바로 닫히게 구성할 수 있습니다.

<Demo code={`import { useState } from 'react';
import {
  Button,
  Modal,
  ActionArea,
  ActionAreaButton,
  ModalContainer,
  ModalContent,
  ModalContentItem,
  ModalDescription,
  ModalHeading,
  ModalNavigation,
  ModalSummary,
} from '@wanteddev/wds';

const Demo = () => {
  const [show, setShow] = useState(false);

  return (
    <>
      <Modal
        open={show}
        onOpenChange={setShow}
        onVisibilityChange={(visibility) => {
          if (visibility === 'hidden') {
            setShow(false)
          }
        }}
      >
        <ModalContainer variant="bottom" handle>
          <ModalNavigation>
            제목
          </ModalNavigation>

          <ModalContent>
            <ModalContentItem>
              <ModalHeading>Heading</ModalHeading>
              <ModalSummary>Summary</ModalSummary>
              <ModalDescription>Description</ModalDescription>
            </ModalContentItem>
          </ModalContent>

          <ActionArea>
            <ActionAreaButton>
              액션
            </ActionAreaButton>
          </ActionArea>
        </ModalContainer>
      </Modal>

      <Button onClick={() => setShow(true)}>Click me</Button>
    </>
  )
}

export default Demo;`}
/>

### Form

<Demo code={`import { useState } from 'react';
import {
  Button,
  Modal,
  ActionArea,
  ActionAreaButton,
  ModalContainer,
  ModalContent,
  ModalContentItem,
  ModalNavigation,
  TextInput,
  FlexBox,
  TextInput,
  FormField,
  FormControl,
  FormLabel,
  FormErrorMessage,
  FormMessage,
} from '@wanteddev/wds';
import { useForm, Controller } from 'react-hook-form';

const Demo = () => {
  const [show, setShow] = useState(false);
  const form = useForm({ defaultValues: { test: '' } });

  return (
    <>
      <Modal
        open={show}
        onOpenChange={setShow}
      >
        <ModalContainer variant="popup">
          <FlexBox
            as="form"
            flex="1"
            flexDirection="column"
            onSubmit={form.handleSubmit((v) => alert(JSON.stringify(v)))}
          >
            <ModalNavigation
              variant="emphasized"
            >
              제목
            </ModalNavigation>

            <ModalContent>
              <ModalContentItem>
                <Controller
                  control={form.control}
                  name="test"
                  rules={{
                    required: {
                      value: true,
                      message: '필수 값입니다.'
                    }
                  }}
                  render={({ field, formState }) => (
                    <FormField>
                      <FormLabel>라벨</FormLabel>

                      <FormControl>
                        <TextInput {...field} width="300px" placeholder="값을 입력하세요." invalid={Boolean(formState.errors.test)} />
                      </FormControl>

                      <FormMessage>설명</FormMessage>
                      <FormErrorMessage>{formState.errors.test?.message}</FormErrorMessage>
                    </FormField>
                  )} />
              </ModalContentItem>
            </ModalContent>

            <ActionArea>
              <ActionAreaButton type="submit">
                액션
              </ActionAreaButton>
            </ActionArea>
          </FlexBox>
        </ModalContainer>
      </Modal>

      <Button onClick={() => setShow(true)}>Click me</Button>
    </>
  )
}

export default Demo;`}
/>
