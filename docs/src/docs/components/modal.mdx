# Modal

## 활용

- Modal Overlay를 표시합니다.
- padding 등을 커스텀 할 땐 css 변수를 활용해주세요.
- `ModalNavigation` 에서 leftButton, rightButton 에는 `ModalNavigationAction`, `ModalClose` 를 사용합니다.
- `ModalContainer`, `ModalNavigation`, `ModalContent`, `ActionArea` 의 위계를 변경해서는 안됩니다.

<Demo code={`import { useState } from 'react';
import {
  Button,
  Modal,
  ActionArea,
  ActionAreaButton,
  ModalContainer,
  ModalContent,
  ModalContentItem,
  ModalDescription,
  ModalHeading,
  ModalNavigation,
  ModalSummary,
} from '@wanteddev/wds';

const Demo = () => {
  const [show, setShow] = useState(false);

  return (
    <>
      <Modal
        open={show}
        onOpenChange={setShow}
      >
        <ModalContainer size="large" variant="popup">
          <ModalNavigation>
            제목
          </ModalNavigation>

          <ModalContent>
            <ModalContentItem>
              <ModalHeading>Heading</ModalHeading>
              <ModalSummary>Summary</ModalSummary>
              <ModalDescription>Description</ModalDescription>
            </ModalContentItem>
          </ModalContent>

          <ActionArea>
            <ActionAreaButton>
              액션
            </ActionAreaButton>
          </ActionArea>
        </ModalContainer>
      </Modal>

      <Button onClick={() => setShow(true)}>Click me</Button>
    </>
  )
}

export default Demo;`}
/>

## Components

Modal 은 여러 컴포넌트를 조합해서 사용합니다.

기본 구성은 아래와 같습니다.

```tsx
<Modal>
  <ModalContainer>
    <ModalNavigation />

    <ModalContent>
      <ModalContentItem>
        <ModalHeading />
        <ModalSummary />
        <ModalDescription />
      </ModalContentItem>
    </ModalContent>

    <ActionArea>
      <ActionAreaButton />
    </ActionArea>
  </ModalContainer>
</Modal>
```

## Examples

### Form

<Demo code={`import { useState } from 'react';
import {
  Button,
  Modal,
  ActionArea,
  ActionAreaButton,
  ModalContainer,
  ModalContent,
  ModalContentItem,
  ModalNavigation,
  TextField,
  FlexBox,
  TextField,
  Form,
  FormField,
  FormItem,
  FormControl,
  FormLabel,
  FormErrorMessage,
  FormDescription,
} from '@wanteddev/wds';
import { useForm } from 'react-hook-form';

const Demo = () => {
  const [show, setShow] = useState(false);
  const form = useForm({ defaultValues: { test: '' } });

  return (
    <>
      <Modal
        open={show}
        onOpenChange={setShow}
      >
        <ModalContainer size="normal-fixed" variant="popup">
          <Form {...form}>
            <FlexBox
              as="form"
              flex="1"
              flexDirection="column"
              onSubmit={form.handleSubmit}
            >
              <ModalNavigation
                variant="emphasized"
              >
                제목
              </ModalNavigation>

              <ModalContent padding paddingInfo>
                <ModalContentItem>
                  <FormField
                    control={form.control}
                    name="test"
                    rules={{
                      required: {
                        value: true,
                        message: '필수 값입니다.'
                      }
                    }}
                    render={({ field }) => (
                      <FormItem>
                        <FormLabel>라벨</FormLabel>

                        <FormControl>
                          <TextField {...field} width="300px" placeholder="값을 입력하세요." />
                        </FormControl>

                        <FormDescription>설명</FormDescription>
                        <FormErrorMessage />
                      </FormItem>
                    )} />
                </ModalContentItem>
              </ModalContent>

              <ActionArea>
                <ActionAreaButton type="submit">
                  액션
                </ActionAreaButton>
              </ActionArea>
            </FlexBox>
          </Form>
        </ModalContainer>
      </Modal>

      <Button onClick={() => setShow(true)}>Click me</Button>
    </>
  )
}

export default Demo;`}
/>

### Left/Right Button

꼭 `ModalNavigationAction` 혹은 `ModalClose` 로 사용해주세요.

rightButton 을 표시하지 않고 싶다면 `rightButton={null}` 을 사용합니다.
