# Modal

Modal Overlay를 표시합니다.

> 주의! 중첩 모달을 사용할 경우 `<Modal />` 하위 컴포넌트에서 `<Modal />` 을 사용하지 마세요.
> 내부에서 Context를 사용하기 때문에 올바르게 동작하지 않을 수 있습니다.

## 활용

<Demo code={`import { useState } from 'react';
import {
  Button,
  Modal,
  ModalActionArea,
  ModalActionButton,
  ModalContainer,
  ModalContent,
  ModalContentItem,
  ModalDescription,
  ModalHeading,
  ModalNavigation,
  ModalSummary,
} from '@wanteddev/wds';

const Demo = () => {
  const [show, setShow] = useState(false);

  return (
    <>
      <Modal
        open={show}
        onOpenChange={setShow}
      >
        <ModalContainer size="large" variant="popup">
          <ModalNavigation variant="compact">
            Title
          </ModalNavigation>

          <ModalContent>
            <ModalContentItem>
              <ModalHeading>Heading</ModalHeading>
              <ModalSummary>Summary</ModalSummary>
              <ModalDescription>Description</ModalDescription>
            </ModalContentItem>
          </ModalContent>

          <ModalActionArea>
            <ModalActionButton>
              액션
            </ModalActionButton>
          </ModalActionArea>
        </ModalContainer>
      </Modal>

      <Button onClick={() => setShow(true)}>Click me</Button>
    </>
  )
}

export default Demo;`}
/>

## Components

Modal 은 여러 컴포넌트를 조합해서 사용합니다.

기본 구성은 아래와 같습니다.

```tsx
<Modal>
  <ModalContainer>
    <ModalNavigation />

    <ModalContent>
      <ModalContentItem>
        <ModalHeading />
        <ModalSummary />
        <ModalDescription />
      </ModalContentItem>
    </ModalContent>

    <ModalActionArea>
      <ModalActionButton />
    </ModalActionArea>
  </ModalContainer>
</Modal>
```
