# Fallback View

- 콘텐츠가 빈 상태일 때 사용자의 이해를 돕기 위해 사용합니다.
- 이미지를 추가할 땐 `FallbackViewImage`로 감싸주세요.

<Demo code={`import { FallbackView, FallbackViewImage, FallbackViewContent, FallbackViewText, FallbackViewButton } from '@wanteddev/wds';

const Demo = () => {
  return (
    <FallbackView sx={{ margin: 'auto' }}>
      <FallbackViewImage>
        <img
          src="https://static.wanted.co.kr/images/company/79/elpzxpmgh94xesrf__1080_790.png"
          alt="Wanted Company Image"
        />
      </FallbackViewImage>
      <FallbackViewContent>
        <FallbackViewText
          title="타이틀이 들어가요." 
          description={
            <>
              상황에 대한 설명이 들어가요.
              <br />
              설명은 최대 두 줄로 작성해요.
            </>
          }
        />
        <FallbackViewButton>텍스트</FallbackViewButton>
      </FallbackViewContent>
    </FallbackView>
  )
}

export default Demo;`}
/>

## Components

아래와 같이 조합하여 사용합니다.

```tsx
<FallbackView>
  <FallbackViewImage>
    <img />
  </FallbackViewImage>

  <FallbackViewContent>
    <FallbackViewText />

    <FallbackViewButton />
  </FallbackViewContent>
</FallbackView>
```

ResponsiveProps를 사용하여 해당 breakpoint 이상일 때 `platform`을 지정할 수 있어요.

<Demo code={`import { FallbackView, FallbackViewContent, FallbackViewText, FallbackViewButton, FlexBox, FallbackViewImage } from '@wanteddev/wds';

const Demo = () => {
  return (
    <FallbackView 
      platform="mobile" 
      sm={{ platform: "desktop" }} 
      sx={{ margin: 'auto' }}
    >
      <FallbackViewImage>
        <img
          src="https://static.wanted.co.kr/images/company/79/elpzxpmgh94xesrf__1080_790.png"
          alt="Wanted Company Image"
        />
      </FallbackViewImage>      
      <FallbackViewContent>
        <FallbackViewText
          title="타이틀이 들어가요." 
          description={
            <>
              (min-width: 768px), platform: desktop
              <br />
              (max-width: 767px), platform: mobile
            </>
          }
        />
        <FallbackViewButton>텍스트</FallbackViewButton>
      </FallbackViewContent>
    </FallbackView>
  )
}

export default Demo;`}
/>
