# SegmentedControl

Segmented Control은 짧은 범위의 옵션이나 상태를 전환하는 데 사용됩니다.<br/>
2~3가지의 선택 항목 중 하나를 선택하는 경우에 적합하며, 선택된 옵션에 따라 즉각적인 변화를 제공합니다.

## 활용

- 3개 이하의 동등한 선택지 중 하나를 선택하거나 같은 맥락 안에서 뷰의 전환 등의 역할을 수행할 때 적합한 컴포넌트입니다.
- 사용 레벨은 Solid, Outlined 순으로 UX 설계시 상황과 위계에 맞춰 활용할 수 있습니다.
- 기본적으로 모바일에서 최대 3개까지 세그먼트 활용을 권장합니다. 단, 상황에 따라서 최대 6개까지 세그먼트를 활용할 수 있습니다.
- Label은 5자 이하의 명사 사용을 권장합니다.

<Demo code={`import {
  SegmentedControl,
  SegmentedControlItem,
} from '@wanteddev/wds';
import { IconColumn, IconList } from '@wanteddev/wds-icon';

const Demo = () => {
  return (
    <SegmentedControl defaultValue="0">
      <SegmentedControlItem value="0" leadingContent={<IconColumn />}>
        Board
      </SegmentedControlItem>
     <SegmentedControlItem value="1" leadingContent={<IconList />}>
        List
      </SegmentedControlItem>
    </SegmentedControl>
  )
}

export default Demo;`}
/>
