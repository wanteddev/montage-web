# Form

form 구조 및 접근성 처리를 다룹니다.
각 컴포넌트별 활용법은 `TextField`, `TextArea`, `Checkbox`, `Radio` 등을 참고해주세요

이 문서는 `react-hook-form`과 함께 활용하는 예시를 소개합니다.

## 활용

<Demo code={`import { Button, FlexBox, TextField, FormField, FormControl, FormLabel, FormErrorMessage } from '@wanteddev/wds';
import { useForm, Controller } from 'react-hook-form';

const Demo = () => {
  const form = useForm();

  return (
    <FlexBox as="form" flexDirection="column" gap="12px" onSubmit={form.handleSubmit(v => alert(JSON.stringify(v)))}>
      <Controller
        control={form.control}
        name="content"
        rules={{
        required: {
            value: true,
            message: '필수 값입니다.'
          }
        }}
        render={({ field, formState }) => (
          <FormField>
            <FormLabel>라벨</FormLabel>

            <FormControl>
              <TextField {...field} width="300px" placeholder="값을 입력하세요." invalid={Boolean(formState.errors.content)} />
            </FormControl>

            <FormErrorMessage>{formState.errors.content?.message}</FormErrorMessage>
          </FormField>
        )}
      />

      <Button type="submit">제출</Button>
    </FlexBox>
  )
}

export default Demo;`}/>

## Components

아래와 같이 여러 컴포넌트를 조합하여 사용합니다.

```tsx
<form onSubmit={handleSubmit}>
  <FormField>
    <FormLabel>label</FormLabel>
    <FormControl>
      <input {...field} />
    </FormControl>

    <FormMessage>설명</FormMessage>
    <FormErrorMessage>오류 메시지</FormErrorMessage>
  </FormField>

  <button type="submit" />
</form>
```

### FormField

form 요소를 렌더링하기 위한 form field 입니다.
내부적으로 `FormLabel`, `FormControl`, `FormMessage`, `FormErrorMessage`에 접근성 처리를 합니다.

`FlexBox` 와 같은 props를 사용합니다.

<PropsTable component="FormField" />

### FormLabel

`Typography<Label>` 과 동일한 Props를 사용합니다.

<PropsTable component="FormLabel" />

### FormControl

children으로 제어 컴포넌트를 넣어 사용합니다.

에러 처리가 필요한 경우, 문서를 참고하여 children 컴포넌트에 invalid Props를 설정하세요.

### FormMessage

form field에 대한 설명을 추가합니다.

`Typography` 과 동일한 Props를 사용합니다.

<PropsTable component="FormMessage" />

### FormErrorMessage

children이 없으면 미노출합니다.

`Typography` 과 동일한 Props를 사용합니다.

<PropsTable component="FormErrorMessage" />

## 자주 겪는 오류

### form.reset

`form.reset()` 이 동작하지 않는 경우가 있습니다.
이 경우 `defaultValue` 가 설정되어 있는지 확인하세요.

[react-hook-form](https://github.com/orgs/react-hook-form/discussions/5858) 은 undefined value를 지원하지 않습니다.
