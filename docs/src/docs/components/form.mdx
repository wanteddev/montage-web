# Form

`react-hook-form` 과 함께 form action을 다룹니다.
각 컴포넌트별 활용법은 `TextField`, `TextArea`, `Checkbox`, `Radio` 등을 참고해주세요

## 활용

<Demo code={`import { Button, FlexBox, TextField, Form, FormField, FormItem, FormControl, FormLabel, FormMessage } from '@wanteddev/wds';
import { useForm } from 'react-hook-form';

const Demo = () => {
  const form = useForm();

  return (
    <Form {...form}>
      <FlexBox as="form" flexDirection="column" gap="12px" onSubmit={form.handleSubmit(v => alert(JSON.stringify(v)))}>
        <FormField
          control={form.control}
          name="content"
          rules={{
            required: {
              value: true,
              message: '필수 값입니다.'
            }
          }}
          render={({ field }) => (
            <FormItem>
              <FormLabel>라벨</FormLabel>

              <FormControl>
                <TextField {...field} width="300px" placeholder="값을 입력하세요." />
              </FormControl>

              <FormMessage />
            </FormItem>
          )} />

        <Button type="submit">제출</Button>
      </FlexBox>
    </Form>
  )
}

export default Demo;`}/>

## Components

아래와 같이 여러 컴포넌트를 조합하여 사용합니다.

```tsx
<Form {...form}>
  <form onSubmit={handleSubmit}>
    <FormField
      control={form.control}
      name="name"
      render={({ field }) => (
        <FormItem>
          <FormLabel>label</FormLabel>
          <FormControl {...field}>
            <input />
          </FormControl>
          <FormMessage />
        </FormItem>
      )}
    />

    <button type="submit" />
  </form>
</Form>
```

### Form

`react-hook-form` 의 `useForm` 반환값을 그대로 전달합니다.

```tsx
const form = useForm();

return <Form {...form} />
```

### FormField

`react-hook-form` 의 `Controller` 의 역할을 합니다.

<PropsTable component="FormField" />

### FormItem

form 요소를 렌더링하기 위한 form item 입니다.
내부적으로 `FormLabel`, `FormMessage`, `FormControl` 에 접근성 처리를 합니다. 


`FlexBox<'div'>` 와 같은 props를 사용합니다.

### FormLabel

`Label(Typography)` 과 동일한 Props를 사용합니다.

### FormControl

children으로 제어 컴포넌트를 넣어 사용합니다.

### FormMessage

Form의 오류 메시지를 보여주거나 Form에 대한 설명을 추가합니다.
