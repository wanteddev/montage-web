# Loading

화면을 불러올 때 사용합니다.

<Demo code={`import { Loading } from '@wanteddev/wds';

const Demo = () => {
  return (
    <Loading />
  );
}

export default Demo;`}
/>

## Props

<PropsTable component="Loading" />

## Examples

### Variant

- `wanted`: 2초 이상 로드할 때 사용합니다.
- `circular`: 로드 시간이 적은 일반적인 상황에서 사용합니다.

<Demo code={`import { Loading, FlexBox } from '@wanteddev/wds';

const Demo = () => {
  return (
    <FlexBox alignItems="center">
      <Loading />
      <Loading variant="circular" />
    </FlexBox>
  );
}

export default Demo;`}
/>

### Size

- width와 height를 size로 지정할 수 있어요.
- css의 width, height 속성과 동일한 값을 사용합니다.

<Demo code={`import { Loading, FlexBox } from '@wanteddev/wds';

const Demo = () => {
  return (
    <FlexBox alignItems="center">
      <Loading size="50px" />
      <Loading size="1em" />
    </FlexBox>
  );
}

export default Demo;`}
/>
