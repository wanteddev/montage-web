# Pagination Counter

## 활용

- 캐러셀에서 순서를 표시할 때 사용합니다.

<Demo code={`import { PaginationCounter } from '@wanteddev/wds';

const Demo = () => {

  return (
    <PaginationCounter totalPage={10} currentPage={2} />
  )
}

export default Demo;
`} />
