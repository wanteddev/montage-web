# SectionMessage

사용자의 작업 또는 시스템 상황에 대한 상태를 제공합니다.

`RegionConfig` 컴포넌트를 활용하여 노출되는 위치를 조정할 수 있습니다.

## 활용

- 사용자의 작업 또는 시스템 상황에 대한 상태를 제공합니다.
- 새 기능이나 사용하지 않는 기능, 또는 현재 컨텍스트와 관련된 정보를 알려줍니다.
- 사용자가 얼럿을 해제할 때까지 지속됩니다.
- 가독성을 위해 메시지가 2줄 이상 넘지 않도록 작성합니다.

<Demo code={`import { useState } from 'react';
import { SectionMessage, Button } from '@wanteddev/wds';

const Demo = () => {
  const [show, setShow] = useState(false);

  return (
    <>
      <SectionMessage
        show={show}
        onShowChange={setShow}
        variant="info"
      >
        사용자의 작업 또는 시스템 상황에 대한 상태를 제공합니다.
      </SectionMessage>

      <Button onClick={() => setShow(true)}>Click me</Button>
    </>
  )
}

export default Demo;`}
/>
