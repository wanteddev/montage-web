# List

인터랙션이 가능한 리스트입니다.

## Components

아래와 같이 조합하여 사용합니다.

```tsx
<List>
  <ListItem>
    <ListText>단일 리스트</ListText>
  </ListItem>
  <ListCell>
    <ListText>셀 리스트</ListText>
  </ListCell>
</List>
```

### List

- 리스트를 감싸고 있으며 `ul` 태그로 렌더링됩니다.
- `FlexBox`와 동일한 props를 사용합니다.

### ListItem

- 단일 형태를 가진 리스트입니다.
- leftContent, rightContent에 요소를 추가할 때는 `ListItemContent`를 이용해주세요.

<Demo code={`import { List, ListItem, ListItemContent, ListText } from '@wanteddev/wds';
import { IconApps } from '@wanteddev/wds-icon';

const Demo = () => {
  return (
    <List gap="16px">
      <ListItem>
        <ListText>텍스트</ListText>
      </ListItem>
      <ListItem active>
        <ListText>텍스트</ListText>
      </ListItem>
      <ListItem disabled>
        <ListText>텍스트</ListText>
      </ListItem>
      <ListItem
        leftContent={
          <ListItemContent variant="icon">
            <IconApps />
          </ListItemContent>
        }
      >
        <ListText>텍스트</ListText>
      </ListItem>
    </List>
  )
}

export default Demo;`}
/>

`FlexBox`의 props를 확장하여 사용합니다.

### Form + ListCell + RadioGroup

<Demo code={`import { Button, FlexBox, RadioGroup, RadioGroupItem, FormField, FormControl, List, ListCell, ListItemContent, ListText, FormLabel, FormErrorMessage } from '@wanteddev/wds';
import { useForm, Controller } from 'react-hook-form';

const Demo = () => {
  const form = useForm();

  return (
    <FlexBox
      as="form"
      flexDirection="column"
      gap="20px"
      onSubmit={form.handleSubmit((v) => alert(JSON.stringify(v)))}
    >
      <Controller
        control={form.control}
        name="selected"
        rules={{
          required: {
            value: true,
            message: "필수 값입니다.",
          },
        }}
        render={({ field, formState }) => (
          <FormField>
            <FormLabel>성별</FormLabel>

            <FormControl>
              <RadioGroup {...field} onValueChange={field.onChange}>
                <List>
                  <ListCell
                    as={FormField}
                    leftContent={
                      <FormControl>
                        <ListItemContent variant="radio">
                          <RadioGroupItem value="man" />
                        </ListItemContent>
                      </FormControl>
                    }
                  >
                    <ListText as={FormLabel}>Man</ListText>
                  </ListCell>
                  <ListCell
                    as={FormField}  
                    leftContent={
                      <FormControl>
                        <ListItemContent variant="radio">
                          <RadioGroupItem value="woman" />
                        </ListItemContent>
                      </FormControl>
                    }
                  >
                    <ListText as={FormLabel}>Woman</ListText>
                  </ListCell>
                </List>
              </RadioGroup>
            </FormControl>

            <FormErrorMessage>{formState.errors.selected?.message}</FormErrorMessage>
          </FormField>
        )}
      />

      <Button type="submit">제출</Button>
    </FlexBox>
  )
}

export default Demo;`}
/>

### Form + ListCell + Multiple Checkbox

<Demo code={`import { Button, FlexBox, Checkbox, FormField, FormControl, FormLabel, FormErrorMessage, List, ListCell, ListItemContent, ListText } from '@wanteddev/wds';
import { useForm, Controller } from 'react-hook-form';

const Demo = () => {
  const form = useForm({
    defaultValues: {
      selected: [],
    },
  });

  const items = [
    {
      id: "develop",
      label: "개발",
    },
    {
      id: "design",
      label: "디자인",
    },
  ];

  return (
    <FlexBox
      as="form"
      flexDirection="column"
      gap="20px"
      onSubmit={form.handleSubmit((v) => alert(JSON.stringify(v)))}
    >
      <Controller
        control={form.control}
        name="selected"
        render={({ formState }) => (
          <FormField>
            <FormLabel>관심 분야</FormLabel>

            <List>
              {items.map((item) => (
                <Controller
                  key={item.id}
                  control={form.control}
                  name="selected"
                  rules={{
                    required: {
                      value: true,
                      message: "필수 값입니다.",
                    },
                  }}
                  render={({ field }) => (
                    <ListCell
                      as={FormField}
                      flexDirection="row"
                      alignItems="center"
                      leftContent={
                        <FormControl>
                          <ListItemContent variant="checkbox">
                            <Checkbox
                              {...field}
                              checked={field.value.includes(item.id)}
                              onCheckedChange={(checked) => {
                                return checked
                                  ? field.onChange([...field.value, item.id])
                                  : field.onChange(
                                      field.value.filter(
                                        (value) => value !== item.id
                                      )
                                    );
                              }}
                            />
                          </ListItemContent>
                        </FormControl>
                      }
                    >
                      <ListText as={FormLabel}>{item.label}</ListText>
                    </ListCell>
                  )}
                />
              ))}
            </List>

            <FormErrorMessage>{formState.errors.selected?.message}</FormErrorMessage>
          </FormField>
        )}
      />
      <Button type="submit">제출</Button>
    </FlexBox>
  );
};

export default Demo;`}
/>
