# List

인터랙션이 가능한 리스트입니다.

## 활용

## Components

아래와 같이 조합하여 사용합니다.

```tsx
<List>
  <ListItem>
    <ListItemText>단일 리스트</ListItemText>
  </ListItem>
  <ListCell>
    <ListItemText>셀 리스트</ListItemText>
  </ListCell>
</List>
```

## List

리스트를 감싸고 있으며 기본 `ul` 태그로 렌더링됩니다.

`FlexBox`와 동일한 props를 확장하여 사용합니다.

<PropsTable component="List" />

## ListItem

단일 형태를 가진 리스트입니다.

<Demo code={`import { List, ListItem, ListItemText } from '@wanteddev/wds';
import { IconPerson } from '@wanteddev/wds-icon';

const Demo = () => {
  return (
    <List>
      <ListItem>
        <ListItemText>텍스트</ListItemText>
      </ListItem>
      <ListItem>
        <ListItemText active>텍스트</ListItemText>
      </ListItem>
      <ListItem leftContent={<IconPerson />}>
        <ListItemText>텍스트</ListItemText>
      </ListItem>
    </List>
  )
}

export default Demo;`}
/>

`FlexBox`의 props를 확장하여 사용합니다.

<PropsTable component="ListItem" />

### leftContent

`leftContent` props에 icon, radio, checkbox를 전달할 수 있습니다.

컨트롤 가능한 요소가 들어오면, 내부적으로 id를 생성하여 label로 렌더링되는 `~ ListItemText`에 전달합니다.

#### RadioGroupItem

<Demo code={`import { List, ListItem, ListItemText, RadioGroupItem } from '@wanteddev/wds';

const Demo = () => {
  return (
    <List>
      <ListItem leftContent={<RadioGroupItem value="man" />}>
        <ListItemText as="label">Man</ListItemText>
      </ListItem>
      <ListItem leftContent={<RadioGroupItem value="woman" />}>
        <ListItemText as="label">Woman</ListItemText>
      </ListItem>
    </List>
  )
}

export default Demo;`}
/>

#### Checkbox

<Demo code={`import { Checkbox, ListItem, ListItemText } from '@wanteddev/wds';

const Demo = () => {
  return (
    <ListItem leftContent={<Checkbox />}>
      <ListItemText as="label">Label</ListItemText>
    </ListItem>
  )
}

export default Demo;`}
/>

## Form

### ListItem + RadioGroup

<Demo code={`import { Button, FlexBox, RadioGroupItem, FormField, FormControl, List, ListItem, ListItemText, FormLabel, FormErrorMessage } from '@wanteddev/wds';
import { useForm, Controller } from 'react-hook-form';

const Demo = () => {
  const form = useForm();

  return (
    <FlexBox
      as="form"
      flexDirection="column"
      gap="20px"
      onSubmit={form.handleSubmit((v) => alert(JSON.stringify(v)))}
    >
      <Controller
        control={form.control}
        name="selected"
        rules={{
          required: {
            value: true,
            message: "필수 값입니다.",
          },
        }}
        render={({ field, formState }) => (
          <FormField>
            <FormLabel>성별</FormLabel>

            <FormControl>
              <List radioGroupProps={{ ...field, onValueChange: field.onChange }}>
                <ListItem
                  as={FormField}
                  leftContent={
                    <FormControl>
                      <RadioGroupItem value="man" />
                    </FormControl>
                  }
                >
                  <ListItemText as={FormLabel}>Man</ListItemText>
                </ListItem>

                <ListItem
                  as={FormField}
                  leftContent={
                    <FormControl>
                      <RadioGroupItem value="woman" />
                    </FormControl>
                  }
                >
                  <ListItemText as={FormLabel}>Woman</ListItemText>
                </ListItem>
              </List>
            </FormControl>

            <FormErrorMessage>{formState.errors.selected?.message}</FormErrorMessage>
          </FormField>
        )}
      />

      <Button type="submit">제출</Button>
    </FlexBox>
  )
}

export default Demo;`}
/>
