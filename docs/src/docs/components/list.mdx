# List

인터랙션이 가능한 리스트입니다.

## 활용

## Components

아래와 같이 조합하여 사용합니다.

```tsx
<List>
  <ListItem>
    <ListItemText>단일 리스트</ListItemText>
  </ListItem>
  <ListCell>
    <ListItemText>셀 리스트</ListItemText>
  </ListCell>
</List>
```

## List

리스트를 감싸고 있으며 기본 `ul` 태그로 렌더링됩니다.

`FlexBox`와 동일한 props를 확장하여 사용합니다.

<PropsTable component="List" />

## ListItem

단일 형태를 가진 리스트입니다.

<Demo code={`import { List, ListItem, ListItemText } from '@wanteddev/wds';
import { IconPerson } from '@wanteddev/wds-icon';

const Demo = () => {
  return (
    <List gap="16px">
      <ListItem>
        <ListItemText>텍스트</ListItemText>
      </ListItem>
      <ListItem>
        <ListItemText active>텍스트</ListItemText>
      </ListItem>
      <ListItem leftContent={<IconPerson />}>
        <ListItemText>텍스트</ListItemText>
      </ListItem>
    </List>
  )
}

export default Demo;`}
/>

`FlexBox`의 props를 확장하여 사용합니다.

### leftContent

`leftContent` props에 icon, radio, checkbox 등을 전달합니다.

#### RadioGroupItem

<Demo code={`import { List, ListItem, ListItemText, RadioGroupItem } from '@wanteddev/wds';

const Demo = () => {
  return (
    <List gap="16px">
      <ListItem leftContent={<RadioGroupItem value="man" />}>
        <ListItemText>Man</ListItemText>
      </ListItem>
      <ListItem leftContent={<RadioGroupItem value="woman" />}>
        <ListItemText>Woman</ListItemText>
      </ListItem>

## ListCell

셀 형태를 가진 리스트입니다. 
`Menu`, `Select` 등에서 셀 형태의 리스트를 사용합니다.

<Demo code={`import { List, ListCell, ListItemText } from '@wanteddev/wds';
import { IconPerson } from '@wanteddev/wds-icon';

const Demo = () => {
  return (
    <List>
      <ListCell>
        <ListItemText>텍스트</ListItemText>
      </ListCell>
      <ListCell size="small">
        <ListItemText caption="캡션">텍스트</ListItemText>
      </ListCell>
      <ListCell size="medium">
        <ListItemText caption="캡션">텍스트</ListItemText>
      </ListCell>
      <ListCell paddingInset>
        <ListItemText bold>텍스트</ListItemText>
      </ListCell>
      <ListCell divider>
        <ListItemText active>텍스트</ListItemText>
      </ListCell>
    </List>
  )
}

export default Demo;`}
/>

## Form

### ListCell + RadioGroup

<Demo code={`import { Button, FlexBox, RadioGroupItem, FormField, FormControl, List, ListCell, ListItemText, FormLabel, FormErrorMessage } from '@wanteddev/wds';
import { useForm, Controller } from 'react-hook-form';

const Demo = () => {
  const form = useForm();

  return (
    <FlexBox
      as="form"
      flexDirection="column"
      gap="20px"
      onSubmit={form.handleSubmit((v) => alert(JSON.stringify(v)))}
    >
      <Controller
        control={form.control}
        name="selected"
        rules={{
          required: {
            value: true,
            message: "필수 값입니다.",
          },
        }}
        render={({ field, formState }) => (
          <FormField>
            <FormLabel>성별</FormLabel>

            <FormControl>
              <List radioGroup={{ ...field, onValueChange: field.onChange }}>
                <ListCell
                  as={FormField}
                  listItemBox={{ as: FormLabel }}
                  leftContent={
                    <FormControl>
                      <RadioGroupItem value="man" />
                    </FormControl>
                  }
                >
                  <ListItemText>Man</ListItemText>
                </ListCell>
                <ListCell
                  as={FormField}  
                  listItemBox={{ as: FormLabel }}
                  leftContent={
                    <FormControl>
                      <RadioGroupItem value="woman" />
                    </FormControl>
                  }
                >
                  <ListItemText>Woman</ListItemText>
                </ListCell>
              </List>
            </FormControl>

            <FormErrorMessage>{formState.errors.selected?.message}</FormErrorMessage>
          </FormField>
        )}
      />

      <Button type="submit">제출</Button>
    </FlexBox>
  )
}

export default Demo;`}
/>
