# List

인터랙션이 가능한 리스트입니다.

## 활용

## Components

아래와 같이 조합하여 사용합니다.

```tsx
<List>
  <ListItem>
    <ListItemText>단일 리스트</ListItemText>
  </ListItem>
  <ListCell>
    <ListItemText>셀 리스트</ListItemText>
  </ListCell>
</List>
```

## List

리스트를 감싸고 있으며 기본 `ul` 태그로 렌더링됩니다.

`FlexBox`와 동일한 props를 확장하여 사용합니다.

## Form

### ListCell + RadioGroup

<Demo code={`import { Button, FlexBox, RadioGroup, RadioGroupItem, FormField, FormControl, List, ListCell, ListItemText, FormLabel, FormErrorMessage } from '@wanteddev/wds';
import { useForm, Controller } from 'react-hook-form';

const Demo = () => {
  const form = useForm();

  return (
    <FlexBox
      as="form"
      flexDirection="column"
      gap="20px"
      onSubmit={form.handleSubmit((v) => alert(JSON.stringify(v)))}
    >
      <Controller
        control={form.control}
        name="selected"
        rules={{
          required: {
            value: true,
            message: "필수 값입니다.",
          },
        }}
        render={({ field, formState }) => (
          <FormField>
            <FormLabel sx={{ marginLeft: '12px' }}>성별</FormLabel>

            <FormControl>
              <RadioGroup {...field} onValueChange={field.onChange}>
                <List>
                  <ListCell
                    as={FormField}
                    leftContent={
                      <FormControl>
                        <RadioGroupItem value="man" />
                      </FormControl>
                    }
                  >
                    <ListItemText as={FormLabel}>Man</ListItemText>
                  </ListCell>
                  <ListCell
                    as={FormField}  
                    leftContent={
                      <FormControl>
                        <RadioGroupItem value="woman" />
                      </FormControl>
                    }
                  >
                    <ListItemText as={FormLabel}>Woman</ListItemText>
                  </ListCell>
                </List>
              </RadioGroup>
            </FormControl>

            <FormErrorMessage>{formState.errors.selected?.message}</FormErrorMessage>
          </FormField>
        )}
      />

      <Button type="submit">제출</Button>
    </FlexBox>
  )
}

export default Demo;`}
/>

### ListCell + Multiple Checkbox

<Demo code={`import { useId } from 'react';
import { Button, FlexBox, Checkbox, FormField, FormControl, FormLabel, FormErrorMessage, List, ListCell, ListItemText } from '@wanteddev/wds';
import { useForm, Controller } from 'react-hook-form';

const Demo = () => {
  const id = useId();
  const form = useForm({
    defaultValues: {
      selected: [],
    },
  });

  const items = [
    {
      id: "develop",
      label: "개발",
    },
    {
      id: "design",
      label: "디자인",
    },
  ];

  return (
    <FlexBox
      as="form"
      flexDirection="column"
      gap="20px"
      onSubmit={form.handleSubmit((v) => alert(JSON.stringify(v)))}
    >
      <Controller
        control={form.control}
        name="selected"
        render={({ formState }) => (
          <FormField>
            <FormLabel sx={{ marginLeft: '12px' }}>관심 분야</FormLabel>
            <List>
              {items.map((item) => (
                <Controller
                  key={item.id}
                  control={form.control}
                  name="selected"
                  rules={{
                    required: {
                      value: true,
                      message: "필수 값입니다.",
                    },
                  }}
                  render={({ field }) => (
                    <ListCell
                      as={FormField}
                      flexDirection="row"
                      alignItems="center"
                    >
                      <FormControl>
                        <Checkbox
                          {...field}
                          checked={field.value.includes(item.id)}
                          onCheckedChange={(checked) => {
                            return checked
                              ? field.onChange([...field.value, item.id])
                              : field.onChange(
                                  field.value.filter(
                                    (value) => value !== item.id
                                  )
                                );
                          }}
                        />
                      </FormControl>
                      <ListItemText as={FormLabel}>{item.label}</ListItemText>
                    </ListCell>
                  )}
                />
              ))}
            </List>
            <FormErrorMessage>{formState.errors.selected?.message}</FormErrorMessage>
          </FormField>
        )}
      />
      <Button type="submit">제출</Button>
    </FlexBox>
  );
};

export default Demo;`}
/>
