# List

인터랙션이 가능한 리스트입니다.

## 활용

- ListCell 클릭 시 자동으로 leftContent, rightContent 내부의 컨트롤 요소를 클릭 처리 합니다.
  - 단 switch 컴포넌트는 클릭 처리 하지 않습니다.
- leftContent, rightContent 에 요소를 추가 할 때는 `ListCellContent` 로 감싸서 사용합니다.

<Demo code={`import { List, ListCell, ListCellContent, Checkbox } from '@wanteddev/wds';

const Demo = () => {
  return (
    <List>
      <ListCell leftContent={(
        <ListCellContent variant="checkbox">
          <Checkbox />
        </ListCellContent>
      )}>
        텍스트
      </ListCell>
      <ListCell textProps={{ caption: '캡션' }} leftContent={(
        <ListCellContent variant="checkbox">
          <Checkbox />
        </ListCellContent>
      )}>
        텍스트
      </ListCell>
    </List>
  )
}

export default Demo;`}
/>

## Components

아래와 같이 조합하여 사용합니다.

```tsx
<List>
  <ListCell>
    리스트1
  </ListCell>
  <ListCell>
    리스트2
  </ListCell>
</List>
```

### Form

checkbox를 활용한 form은 아래와 같이 사용합니다.

<Demo code={`import { Button, FlexBox, Checkbox, FormField, FormControl, FormLabel, FormErrorMessage, List, ListCell, ListCellContent } from '@wanteddev/wds';
import { useForm, Controller } from 'react-hook-form';

const items = [
  {
    id: "develop",
    label: "개발",
  },
  {
    id: "design",
    label: "디자인",
  },
];

const Demo = () => {
  const form = useForm({
    defaultValues: {
      selected: [],
    },
  });

  return (
    <FlexBox
      as="form"
      flexDirection="column"
      gap="20px"
      onSubmit={form.handleSubmit((v) => alert(JSON.stringify(v)))}
    >
      <Controller
        control={form.control}
        name="selected"
        render={({ formState }) => (
          <FormField>
            <FormLabel>관심 분야</FormLabel>

            <List>
              {items.map((item) => (
                <Controller
                  key={item.id}
                  control={form.control}
                  name="selected"
                  rules={{
                    required: {
                      value: true,
                      message: "필수 값입니다.",
                    },
                  }}
                  render={({ field }) => (
                    <ListCell
                      as={FormField}
                      flexDirection="row"
                      alignItems="center"
                      leftContent={
                        <FormControl>
                          <ListCellContent variant="checkbox">
                            <Checkbox
                              {...field}
                              checked={field.value.includes(item.id)}
                              onCheckedChange={(checked) => {
                                return checked
                                  ? field.onChange([...field.value, item.id])
                                  : field.onChange(
                                      field.value.filter(
                                        (value) => value !== item.id
                                      )
                                    );
                              }}
                            />
                          </ListCellContent>
                        </FormControl>
                      }
                    >
                      {item.label}
                    </ListCell>
                  )}
                />
              ))}
            </List>

            <FormErrorMessage>{formState.errors.selected?.message}</FormErrorMessage>
          </FormField>
        )}
      />
      <Button type="submit">제출</Button>
    </FlexBox>
  );
};

export default Demo;`}
/>

                  <ListCell

                    Woman
                  </ListCell>
                </List>
              </RadioGroup>

        )}

      <Button type="submit">제출</Button>

Switch를 사용하는 경우 `ListCell` 영역을 클릭해서 토글되지 않습니다.
스위치 영역을 직접 클릭해야만 스위치가 토글됩니다.

`disableInteraction` 과 함께 사용하면 자연스러운 동작으로 사용 가능합니다.

<Demo code={`import { Button, FlexBox, Switch, List, ListCell, ListCellContent, FormField, FormControl, FormLabel } from '@wanteddev/wds';
import { useForm, Controller } from 'react-hook-form';

const Demo = () => {
  const form = useForm();

  return (
    <FlexBox
      as="form"
      flexDirection="column"
      gap="20px"
      onSubmit={form.handleSubmit((v) => alert(JSON.stringify(v)))}
    >
      <List>
        <Controller
          control={form.control}
          name="notification"
          render={({ field, formState }) => (
            <ListCell
              as={FormField}
              disableInteraction
              rightContent={
                <FormControl>
                  <ListCellContent variant="switch" height="40px">
                    <Switch
                      {...field}
                      checked={field.value} 
                      onCheckedChange={field.onChange}
                    />
                  </ListCellContent>
                </FormControl>
              }
            >
              알림 받기
            </ListCell>
          )}
        />
        <Controller
          control={form.control}
          name="darkMode"
          render={({ field, formState }) => (
            <ListCell
              as={FormField}
              disableInteraction
              rightContent={
                <FormControl>
                  <ListCellContent variant="switch" height="40px">
                    <Switch
                      {...field}
                      checked={field.value}
                      onCheckedChange={field.onChange}
                    />
                  </ListCellContent>
                </FormControl>
              }
            >
              다크 모드
            </ListCell>
          )}
        />
      </List>
