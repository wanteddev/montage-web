# List

인터랙션이 가능한 리스트입니다.

## 활용

## Components

아래와 같이 조합하여 사용합니다.

```tsx
<List>
  <ListItem>
    <ListItemText>단일 리스트</ListItemText>
  </ListItem>
  <ListCell>
    <ListItemText>셀 리스트</ListItemText>
  </ListCell>
</List>
```

## List

리스트를 감싸고 있으며 기본 `ul` 태그로 렌더링됩니다.

`FlexBox`와 동일한 props를 확장하여 사용합니다.

<PropsTable component="List" />

## ListItem

단일 형태를 가진 리스트입니다.

<Demo code={`import { List, ListItem, ListItemText } from '@wanteddev/wds';
import { IconPerson } from '@wanteddev/wds-icon';

const Demo = () => {
  return (
    <List gap="16px">
      <ListItem>
        <ListItemText>텍스트</ListItemText>
      </ListItem>
      <ListItem>
        <ListItemText active>텍스트</ListItemText>
      </ListItem>
      <ListItem leftContent={<IconPerson />}>
        <ListItemText>텍스트</ListItemText>
      </ListItem>
    </List>
  )
}

export default Demo;`}
/>

`FlexBox`의 props를 확장하여 사용합니다.

<PropsTable component="ListItem" />

### leftContent

`leftContent` props에 icon, radio, checkbox 등을 전달합니다.

#### RadioGroupItem

<Demo code={`import { List, ListItem, ListItemText, RadioGroupItem } from '@wanteddev/wds';

const Demo = () => {
  return (
    <List gap="16px">
      <ListItem leftContent={<RadioGroupItem value="man" />}>
        <ListItemText>Man</ListItemText>
      </ListItem>
      <ListItem leftContent={<RadioGroupItem value="woman" />}>
        <ListItemText>Woman</ListItemText>
      </ListItem>
    </List>
  )
}

export default Demo;`}
/>

#### Checkbox

<Demo code={`import { Checkbox, ListItem, ListItemText } from '@wanteddev/wds';

const Demo = () => {
  return (
    <ListItem leftContent={<Checkbox />}>
      <ListItemText>Label</ListItemText>
    </ListItem>
  )
}

export default Demo;`}
/>

## ListItemText

리스트에서 사용하는 타이포 컴포넌트입니다.

<Demo code={`import { List, ListItem, ListItemText } from '@wanteddev/wds';
import { IconPerson } from '@wanteddev/wds-icon';

const Demo = () => {
  return (
    <List gap="16px">
      <ListItem>
        <ListItemText>텍스트</ListItemText>
      </ListItem>
      <ListItem>
        <ListItemText caption="캡션">텍스트</ListItemText>
      </ListItem>
      <ListItem>
        <ListItemText bold>텍스트</ListItemText>
      </ListItem>
      <ListItem>
        <ListItemText active>텍스트</ListItemText>
      </ListItem>
      <ListItem>
        <ListItemText disabled>텍스트</ListItemText>
      </ListItem>
    </List>
  )
}

export default Demo;`}
/>

`Typography`의 props를 확장하여 사용합니다.
