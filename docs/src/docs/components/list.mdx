# List

인터랙션이 가능한 리스트입니다.

## 활용

## Components

아래와 같이 조합하여 사용합니다.

```tsx
<List>
  <ListItem>
    <ListItemText>단일 리스트</ListItemText>
  </ListItem>
  <ListCell>
    <ListItemText>셀 리스트</ListItemText>
  </ListCell>
</List>
```

## List

리스트를 감싸고 있으며 기본 `ul` 태그로 렌더링됩니다.

`FlexBox`와 동일한 props를 사용합니다.

<PropsTable component="List" />

## ListItem

단일 형태를 가진 리스트입니다.

<Demo code={`import { List, ListItem, ListItemText } from '@wanteddev/wds';
import { IconPerson } from '@wanteddev/wds-icon';

const Demo = () => {
  return (
    <List gap="16px">
      <ListItem>
        <ListItemText>텍스트</ListItemText>
      </ListItem>
      <ListItem variant="action">
        <ListItemText>텍스트</ListItemText>
      </ListItem>
      <ListItem leftIcon={<IconPerson />}>
        <ListItemText>텍스트</ListItemText>
      </ListItem>
    </List>
  )
}

export default Demo;`}
/>

<PropsTable component="ListItem" />

## ListCell

셀 형태를 가진 리스트입니다
`Menu`, `Select` 등 주로 셀 형태의 리스트를 사용합니다.

<Demo code={`import { Box, css, listStyle } from '@wanteddev/wds';

const Demo = () => {
  return (
    <Box as="ul" sx={listStyle}>
      <li>List1</li>
      <li>List2</li>
    </Box>
  )
}

export default Demo;`}
/>

## ListItemRadio

리스트에서 사용하는 라디오 아이템 컴포넌트입니다.
children은 `ListItemText` 컴포넌트의 label로서 렌더링됩니다.

<Demo code={`import { List, ListItem, ListItemText, ListItemRadio, RadioGroup } from '@wanteddev/wds';
import { IconPerson } from '@wanteddev/wds-icon';
import { useId } from 'react';

const Demo = () => {
  const manId = useId();
  const womanId = useId();

  return (
    <RadioGroup>
      <List gap="16px">
        <ListItem>
          <ListItemRadio id={manId} value="man">Man</ListItemRadio>
        </ListItem>
        <ListItem>
          <ListItemRadio id={womanId} value="woman">Woman</ListItemRadio>
        </ListItem>
      </List>
    </RadioGroup>
  )
}

export default Demo;`}
/>

`RadioGroupItem`과 동일한 props를 사용하고, label은 `ListItemText`의 props 입니다.

### Form 

<Demo code={`import { Button, FlexBox, RadioGroup, List, ListItem, ListItemText, ListItemRadio, FormField, FormControl, FormLabel, FormErrorMessage } from '@wanteddev/wds';
import { useForm, Controller } from 'react-hook-form';

const Demo = () => {
  const form = useForm();

  return (
    <FlexBox
      as="form"
      flexDirection="column"
      gap="20px"
      onSubmit={form.handleSubmit((v) => alert(JSON.stringify(v)))}
    >
      <Controller
        control={form.control}
        name="selected"
        rules={{
          required: {
            value: true,
            message: "필수 값입니다.",
          },
        }}
        render={({ field, formState }) => (
          <FormField>
            <FormLabel>성별</FormLabel>

            <FormControl>
              <RadioGroup {...field} onValueChange={field.onChange}>
                <List>
                  <FormField as={ListItem}>
                    <FormControl>
                      <ListItemRadio value="man" label={{ as: FormLabel }}>Man</ListItemRadio>
                    </FormControl>
                  </FormField>

                  <FormField as={ListItem}>
                    <FormControl>
                      <ListItemRadio value="woman" label={{ as: FormLabel }}>Woman</ListItemRadio>
                    </FormControl>
                  </FormField>
                </List>
              </RadioGroup>
            </FormControl>

            <FormErrorMessage>{formState.errors.selected?.message}</FormErrorMessage>
          </FormField>
        )}
      />

      <Button type="submit">제출</Button>
    </FlexBox>
  )
}

export default Demo;`}
/>
