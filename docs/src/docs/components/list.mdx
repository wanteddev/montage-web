# List

인터랙션이 가능한 리스트입니다.

## Components

아래와 같이 조합하여 사용합니다.

```tsx
<List>
  <ListItem>
    <ListText>단일 리스트</ListText>
  </ListItem>
  <ListCell>
    <ListText>셀 리스트</ListText>
  </ListCell>
</List>
```

## List

- 리스트를 감싸고 있으며 `ul` 태그로 렌더링됩니다.
- `FlexBox`와 동일한 props를 사용합니다.

## ListItem

- 단일 형태를 가진 리스트입니다.
- leftContent, rightContent를 사용하여 요소를 추가합니다.

<Demo code={`import { List, ListItem, ListText } from '@wanteddev/wds';
import { IconPerson } from '@wanteddev/wds-icon';

const Demo = () => {
  return (
    <List gap="16px">
      <ListItem>
        <ListText>텍스트</ListText>
      </ListItem>
      <ListItem>
        <ListText bold>텍스트</ListText>
      </ListItem>
      <ListItem leftContent={<IconPerson />}>
        <ListText>텍스트</ListText>
      </ListItem>
    </List>
  )
}

export default Demo;`}
/>

                        <RadioGroupItem value="man" />

                    }

### ListCell + Multiple Checkbox

<Demo code={`import { Button, FlexBox, Checkbox, FormField, FormControl, FormLabel, FormErrorMessage, List, ListCell, ListText } from '@wanteddev/wds';
import { useForm, Controller } from 'react-hook-form';

const Demo = () => {
  const form = useForm({
    defaultValues: {
      selected: [],
    },
  });

  const items = [
    {
      id: "develop",
      label: "개발",
    },
    {
      id: "design",
      label: "디자인",
    },
  ];

  return (
    <FlexBox
      as="form"
      flexDirection="column"
      gap="20px"
      onSubmit={form.handleSubmit((v) => alert(JSON.stringify(v)))}
    >
      <Controller
        control={form.control}
        name="selected"
        render={({ formState }) => (
          <FormField>
            <FormLabel sx={{ marginLeft: '12px' }}>관심 분야</FormLabel>

            <List>
              {items.map((item) => (
                <Controller
                  key={item.id}
                  control={form.control}
                  name="selected"
                  rules={{
                    required: {
                      value: true,
                      message: "필수 값입니다.",
                    },
                  }}
                  render={({ field }) => (
                    <ListCell
                      as={FormField}
                      flexDirection="row"
                      alignItems="center"
                      leftContent={
                        <FormControl>
                          <Checkbox
                            {...field}
                            checked={field.value.includes(item.id)}
                            onCheckedChange={(checked) => {
                              return checked
                                ? field.onChange([...field.value, item.id])
                                : field.onChange(
                                    field.value.filter(
                                      (value) => value !== item.id
                                    )
                                  );
                            }}
                          />
                        </FormControl>
                      }
                    >
                      <ListText as={FormLabel}>{item.label}</ListText>
                    </ListCell>
                  )}
                />
              ))}
            </List>

            <FormErrorMessage>{formState.errors.selected?.message}</FormErrorMessage>
          </FormField>
        )}
      />
      <Button type="submit">제출</Button>
    </FlexBox>
  );
};

export default Demo;`}
/>
