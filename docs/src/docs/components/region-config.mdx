# RegionConfig

`SectionMessage`, `useDialog`, `useToast` 의 노출 위치를 조정합니다.
언마운트 시 기존 값으로 초기화 됩니다.

## Props

<PropsTable component="RegionConfig" />

## Examples

보통 `SectionMessage` 컴포넌트는 navigation 아래에 위치하기 때문에 아래와 같은 설정을 사용합니다.

```tsx
import { RegionConfig, Global, respondTo } from '@wanteddev/wds';

const Demo = () => {
  return (
    <>
      <Global
        styles={(theme) => ({
          [':root']: {
            '--header-height': '61px',
            [respondTo(theme.breakpoint.sm)]: {
              '--header-height': '57px',
            },
          },
        })}
      />

      <RegionConfig viewportTop="var(--header-height)" />
    </>
  )
}

export default Demo;
```
