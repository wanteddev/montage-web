# Toast

## 활용

- 상태에 대한 메시지를 안내할 때 사용해요.
- [useToast](../hooks/use-toast) 훅을 사용하면 더 간편하게 사용할 수 있어요.

<Demo code={`import { FlexBox, Toast, ToastContainer, ToastContent, ToastIcon } from '@wanteddev/wds';

const Demo = () => {
  return (
    <FlexBox justifyContent="center">
      <Toast open disablePortal disableAnimation variant="positive">
        <ToastContainer>
          <ToastIcon />
          <ToastContent>메시지에 마침표를 찍어요.</ToastContent>
        </ToastContainer>
      </Toast>
    </FlexBox>
  )
}

export default Demo;`}
/>

## Components

Toast 는 여러 컴포넌트를 조합해서 사용합니다.

기본 구성은 아래와 같습니다.

```tsx
<Toast>
  <ToastContainer>
    <ToastIcon />

    <ToastContent />
  </ToastContainer>
</Toast>
```

## Examples

### Variant

<Demo code={`import { FlexBox, Toast, ToastContainer, ToastContent, ToastIcon } from '@wanteddev/wds';

const Demo = () => {
  return (
    <FlexBox alignItems="center" flexDirection="column" gap="16px">
      <Toast open disablePortal disableAnimation variant="normal">
        <ToastContainer>
          <ToastIcon />
          <ToastContent>Normal</ToastContent>
        </ToastContainer>
      </Toast>

      <Toast open disablePortal disableAnimation variant="positive">
        <ToastContainer>
          <ToastIcon />
          <ToastContent>Positive</ToastContent>
        </ToastContainer>
      </Toast>

      <Toast open disablePortal disableAnimation variant="cautionary">
        <ToastContainer>
          <ToastIcon />
          <ToastContent>Cautionary</ToastContent>
        </ToastContainer>
      </Toast>

      <Toast open disablePortal disableAnimation variant="negative">
        <ToastContainer>
          <ToastIcon />
          <ToastContent>Negative</ToastContent>
        </ToastContainer>
      </Toast>
    </FlexBox>
  )
}

export default Demo;`}
/>

### Icon Custom

`ToastIcon` 의 children 으로 아이콘을 커스텀할 수 있어요.

<Demo code={`import { FlexBox, Toast, ToastContainer, ToastContent, ToastIcon } from '@wanteddev/wds';
import { IconBlank } from '@wanteddev/wds-icon';

const Demo = () => {
  return (
    <FlexBox justifyContent="center">
      <Toast open disablePortal disableAnimation variant="positive">
        <ToastContainer>
          <ToastIcon>
            <IconBlank />
          </ToastIcon>

          <ToastContent>메시지에 마침표를 찍어요.</ToastContent>
        </ToastContainer>
      </Toast>
    </FlexBox>
  )
}

export default Demo;`}
/>
