# ProgressIndicator

진행 중인 프로세스의 상태를 사용자에게 알려줍니다.

## 활용

- 상단 내비게이션 아래 위치해요.
- 주로 웹뷰로 이동할 때 사용해요.
- 0 ~ 100 까지 퍼센트로 값을 관리해요.

<Demo code={`import { ProgressIndicator } from '@wanteddev/wds';

const Demo = () => {
  return (
    <ProgressIndicator percent={30} />
  );
}

export default Demo;`}
/>
