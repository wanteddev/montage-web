# DatePicker

사용자가 YYYY. MM. DD순으로 날짜를 입력할 수 있는 폼을 제공합니다.

## 활용

- 키보드로 값을 제어할 수 있어요.
- locale, timezone을 지정할 수 있어요.
- 기본적으로 TextField 컴포넌트를 사용해요.
- 항상 유효한 Date 값을 가지고 있지는 않아요. Invalid date 상태를 가질 수 있어요.

<Demo code={`import { DatePicker } from '@wanteddev/wds';

const Demo = () => {
  return (
    <DatePicker placeholder="날짜를 선택해주세요." width="300px" />
  )
}

export default Demo;`}
/>

## Example

### Format

- 날짜가 표시되는 format 을 지정할 수 있어요.
- 아래 format을 모두 사용할 수 있어요.
  - YYYY, YY
  - M, MM, MMM, MMMM
  - D, DD
  - H, HH, h, hh
  - m, mm
  - s, ss
  - A, a

<Demo code={`import { DatePicker, FlexBox } from '@wanteddev/wds';

const Demo = () => {
  return (
    <FlexBox flexDirection="column" gap="20px">
      <DatePicker format="YYYY.MMM.DD" width="300px" />
      
      <DatePicker format="YYYY-MM-DD" width="300px" />
    </FlexBox>
  )
}

export default Demo;`}
/>

### Locale, Timezone

- Locale
  - 기본적으로 locale은 `ko-KR` 으로 지정되어 있어요.
  - [Intl](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl/DateTimeFormat/DateTimeFormat) API 에서 지원하는 언어를 모두 import 없이 사용할 수 있어요.
- Timezone
  - 기본적으로 timezone은 사용자의 환경에 따라 결정돼요.
  - [dayjs](https://day.js.org/docs/en/timezone/timezone) 에서 지원하는 timezone과 `UTC` 를 모두 import 없이 사용할 수 있어요.

<Demo code={`import { DatePicker, FlexBox } from '@wanteddev/wds';

const Demo = () => {
  return (
    <FlexBox flexDirection="column" gap="20px">
      <DatePicker format="YYYY.MMM.DD" width="300px" defaultValue={new Date()} locale="ko-KR" timezone="Asia/Seoul" />
      <DatePicker format="YYYY.MMM.DD" width="300px" defaultValue={new Date()} locale="en-US" timezone="UTC" />
    </FlexBox>
  )
}

export default Demo;`}
/>


### Validation

- 최소값과 최대값을 설정할 수 있어요.
- 하지만 키보드 조작을 통해 범위를 벗어나는 값을 입력할 수 있어요.
- Invalid date 상태를 가질 수 있어요.

<Demo code={`import { DatePicker, FlexBox, FormErrorMessage, FormField, FormLabel, FormControl } from '@wanteddev/wds';
import { Controller, useForm } from 'react-hook-form';

const minDate = new Date('2000-01-01');
const maxDate = new Date('2025-12-31');

const Demo = () => {
  const form = useForm({
    defaultValues: {
      date: new Date(),
    },
    mode: 'onChange'
  });

  return (
    <FlexBox as="form">
      <Controller
        control={form.control}
        name="date"
        rules={{
          validate: (value) => {
            if (isNaN(new Date(value).getTime())) {
              return '유효한 날짜를 입력해주세요.';
            }

            if (new Date(value).getTime() < minDate.getTime()) {
              return '최소 날짜는 2000년 1월 1일 이상이어야 합니다.';
            }

            if (new Date(value).getTime() > maxDate.getTime()) {
              return '최대 날짜는 2025년 12월 31일 이하이어야 합니다.';
            }
            
          return true;
          },
        }}
        render={({ field, formState }) => (
          <FormField>
            <FormLabel>날짜</FormLabel>

            <FormControl>
              <DatePicker
                min={minDate}
                max={maxDate}
                format="YYYY.MM.DD"
                width="300px"
                inputRef={field.ref}
                value={field.value}
                onChange={field.onChange}
                invalid={!!formState.errors.date}
              />
            </FormControl>

            <FormErrorMessage>{formState.errors.date?.message}</FormErrorMessage>
          </FormField>
        )}
      />
    </FlexBox>
  )
}

export default Demo;`}
/>


### Customize

- `TextField` 컴포넌트 대신 커스텀 컴포넌트를 사용할 수 있어요.
- react 18.3 미만의 버전을 사용 중이라면, `forwardRef` 를 필수로 작성해주세요.

<Demo code={`import { DatePicker, DatePickerFieldProps, ChipAction, FlexBox } from '@wanteddev/wds';
import { forwardRef, useState } from 'react';

const CustomChipField = forwardRef<HTMLDivElement, DatePickerFieldProps>(
  ({ value, onClick, inputRef, invalid, ...props }, ref) => {
    return (
      <ChipAction ref={ref} onClick={onClick}>
        {value || 'YYYY.MM.DD'}
      </ChipAction>
    )
  }
)

const CustomFieldField = forwardRef<HTMLDivElement, DatePickerFieldProps>(
  ({ trailingContent, inputRef, invalid, ...props }, ref) => {
    return (
      <FlexBox ref={ref} gap="10px" alignItems="center">
        <input ref={inputRef} {...props} />
        {trailingContent}
      </FlexBox>
    )
  }
)

const Demo = () => {
  const [open1, setOpen1] = useState(false);
  const [open2, setOpen2] = useState(false);

  return (
    <FlexBox flexDirection="column" gap="20px">
      <DatePicker
        width="300px"
        input={CustomChipField}
        open={open1}
        onOpenChange={setOpen1}
        onClick={() => setOpen1(true)}
      />
      <DatePicker
        width="300px"
        input={CustomFieldField}
        open={open2}
        onOpenChange={setOpen2}
      />
    </FlexBox>
  )
}

export default Demo;`}
/>



### Views

- `views`, `defaultView`, `view`, `onViewChange` 로 선택 가능한 UI를 조절할 수 있어요.
- `'year' | 'month' | 'day'` 를 지원해요.

<Demo code={`import { DatePicker, FlexBox } from '@wanteddev/wds';

const Demo = () => {

  return (
    <FlexBox flexDirection="column" gap="20px">
      <DatePicker
        width="300px"
        format="YYYY.MM"
        views={['year', 'month']}
      />
      <DatePicker
        width="300px"
        format="YYYY"
        views={['year']}
      />
      <DatePicker
        width="300px"
        format="YYYY MM DD"
        defaultView="year"
        views={['year', 'day']}
      />
    </FlexBox>
  )
}

export default Demo;`}
/>



### ActionArea

- PickerActionArea를 통해 현재 시간을 선택하는 버튼과 적용하는 버튼을 커스텀 할 수 있어요.
- `now`, `accept`, `cancel`, `reset` variant를 사용할 수 있어요.

<Demo code={`import { DatePicker, FlexBox, PickerActionArea, PickerActionAreaButton, FormField, FormControl, FormLabel, Checkbox } from '@wanteddev/wds';

const Demo = () => {
  return (
    <FlexBox flexDirection="column" gap="20px">
      <DatePicker
        width="300px"
        placeholder="현재, 확인"
        actionArea={
          <PickerActionArea>
            <PickerActionAreaButton variant="now">현재</PickerActionAreaButton>
            <PickerActionAreaButton variant="accept">확인</PickerActionAreaButton>
          </PickerActionArea>
        }
      />

      <DatePicker
        width="300px"
        placeholder="취소, 초기화"
        actionArea={
          <PickerActionArea>
            <PickerActionAreaButton variant="cancel">취소</PickerActionAreaButton>
            <PickerActionAreaButton variant="reset">초기화</PickerActionAreaButton>
          </PickerActionArea>
        }
      />


      <DatePicker
        width="300px"
        placeholder="checkbox, 확인"
        disableLastUnitClickClose
        actionArea={
          <PickerActionArea>
            <FormField
              gap="8px"
              flexDirection="row"
            >
              <FormControl>
                <Checkbox size="normal" />
              </FormControl>
              <FormLabel
                sx={{ padding: "1px 0px" }}
              >
                텍스트
              </FormLabel>
            </FormField>
            <PickerActionAreaButton variant="accept">확인</PickerActionAreaButton>
          </PickerActionArea>
        }
      />
    </FlexBox>
  )
}

export default Demo;`}
/>
