# RadioGroup

사용자에게 입력해야 할 정보를 명확하게 인지시키고, 정보를 정확하게 입력할 수 있도록 도와줍니다.

## 활용

<Demo code={`import { RadioGroup, RadioGroupItem } from '@wanteddev/wds';

const Demo = () => {

  return (
    <RadioGroup>
      <RadioGroupItem value="woman" />
    </RadioGroup>
  )
}

export default Demo;`}
/>

## Example


### Label

`size` 옵션과 `tight` 옵션, `FormField` 등을 활용하여 조합해요.

`size=normal` 일 때는 Label에 padding-y 1px 혹은 alignItems center로 정렬을 맞춰요.

<Demo code={`import { FlexBox, RadioGroup, RadioGroupItem, FormField, FormControl, FormLabel } from '@wanteddev/wds';

const Demo = () => {
  return (
    <RadioGroup>
      <FlexBox flexDirection="column" gap="8px">
        <FormField flexDirection="row" gap="8px">
          <FormControl>
            <RadioGroupItem value="small" size="small" />
          </FormControl>
          <FormLabel>Size=Small, Tight=False</FormLabel>
        </FormField>

        <FormField flexDirection="row" gap="10px">
          <FormControl>
            <RadioGroupItem value="small,tight" size="small" tight />
          </FormControl>
          <FormLabel>Size=Small, Tight=True</FormLabel>
        </FormField>

        <FormField flexDirection="row" gap="8px">
          <FormControl>
            <RadioGroupItem value="normal" size="medium" />
          </FormControl>
          <FormLabel sx={{ padding: '1px 0px' }}>Size=Medium, Tight=False</FormLabel>
        </FormField>

        <FormField flexDirection="row" gap="10px">
          <FormControl>
            <RadioGroupItem value="normal,tight" size="medium" tight />
          </FormControl>
          <FormLabel sx={{ padding: '1px 0px' }}>Size=Medium, Tight=True</FormLabel>
        </FormField>
      </FlexBox>
    </RadioGroup>
  )
}

export default Demo;`}
/>

### Form

<Demo code={`import { Button, FlexBox, RadioGroup, RadioGroupItem, FormField, FormControl, FormLabel, FormErrorMessage } from '@wanteddev/wds';
import { useForm, Controller } from 'react-hook-form';

const Demo = () => {
  const form = useForm();

  return (
    <FlexBox
      as="form"
      flexDirection="column"
      gap="20px"
      onSubmit={form.handleSubmit((v) => alert(JSON.stringify(v)))}
    >
      <Controller
        control={form.control}
        name="selected"
        rules={{
          required: {
            value: true,
            message: "필수 값입니다.",
          },
        }}
        render={({ field, formState }) => (
          <FormField>
            <FormLabel>성별</FormLabel>

            <FormControl>
              <RadioGroup {...field} onValueChange={field.onChange}>
                <FormField flexDirection="row" gap="8px">
                  <FormControl>
                    <RadioGroupItem value="man" />
                  </FormControl>

                  <FormLabel sx={{ padding: '1px 0px' }}>Man</FormLabel>
                </FormField>

                <FormField flexDirection="row" gap="8px">
                  <FormControl>
                    <RadioGroupItem value="woman" />
                  </FormControl>
                  
                  <FormLabel sx={{ padding: '1px 0px' }}>Woman</FormLabel>
                </FormField>
              </RadioGroup>
            </FormControl>

            <FormErrorMessage>{formState.errors.selected?.message}</FormErrorMessage>
          </FormField>
        )}
      />

      <Button type="submit">제출</Button>
    </FlexBox>
  )
}

export default Demo;`}
/>
