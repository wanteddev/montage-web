# Select

필드를 눌러 드롭다운 메뉴, 모달, 바텀시트를 호출하여 항목을 선택할 수 있습니다.

## 활용

- 여러 옵션 중 하나의 값을 선택할 수 있어요.
- leftContent에 요소를 추가 할 때는 `SelectContent`로 감싸서 사용합니다.

<Demo code={`import { Select, Option, OptionGroup, SelectContent, Label, FlexBox } from '@wanteddev/wds';

const Demo = () => {
  return (
    <FlexBox flexDirection="column" gap="8px">
      <Label>Label</Label>
      <Select width="300px" placeholder="선택해주세요.">
        {new Array(3).fill(0).map((_, i) => (
          <OptionGroup key={i} title={\`그룹 \${i + 1}\`}>
            {new Array(3).fill(0)
              .map((__, j) => (
                <Option key={j} value={\`값 \${i} \${j}\`}>
                  {\`값 \${i} \${j}\`}
                </Option>
              ))
            }
          </OptionGroup>
        ))}
      </Select>
    </FlexBox>
  )
}

export default Demo;`}
/>

## Components

아래와 같이 조합하여 사용합니다.

```tsx
<Select>
  <OptionGroup>
    <Option>
      옵션1
    </Option>
  </OptionGroup>
  <OptionGroup>
    <Option>
      옵션2
    </Option>
  </OptionGroup>
</Select>
```

## Examples

### Radio

`Option` 컴포넌트에 variant="radio" 옵션을 주어 radio를 렌더링 할 수 있습니다.

<Demo code={`import { Select, Option, OptionGroup, SelectContent, Label, FlexBox } from '@wanteddev/wds';

const Demo = () => {
  return (
    <FlexBox flexDirection="column" gap="8px">
      <Label>Label</Label>
      <Select width="300px" placeholder="선택해주세요.">
        {new Array(3).fill(0).map((_, i) => (
          <OptionGroup key={i} title={\`그룹 \${i + 1}\`}>
            {new Array(3).fill(0)
              .map((__, j) => (
                <Option variant="radio" key={j} value={\`값 \${i} \${j}\`}>
                  {\`값 \${i} \${j}\`}
                </Option>
              ))
            }
          </OptionGroup>
        ))}
      </Select>
    </FlexBox>
  )
}

export default Demo;`}
/>
