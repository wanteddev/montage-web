# Pagination

페이지 위치 표시와 이동을 위한 내비게이션으로 사용합니다.

## 활용

<Demo code={`import { Pagination } from '@wanteddev/wds';

const Demo = () => {
  return (
    <Pagination totalPages={10} />
  )
}

export default Demo;`}
/>

## Examples

### BoundaryPages, SiblingPages

boundaryPages, siblingPages로 표시할 페이지 수를 조정해요.

<Demo code={`import { Pagination, FlexBox } from '@wanteddev/wds';

const Demo = () => {
  return (
    <FlexBox flexDirection="column" gap="24px">
      <Pagination totalPages={99} defaultPage={9} />
      <Pagination totalPages={99} defaultPage={9} boundaryPages={3} />
      <Pagination totalPages={99} defaultPage={9} siblingPages={3} />
    </FlexBox>
  )
}

export default Demo;`}
/>

### PaginationSelect

페이지당 표시할 아이템 개수를 조정할 수 있어요.

<Demo code={`import { Pagination, PaginationSelect, FlexBox } from '@wanteddev/wds';

const Demo = () => {
  return (
    <FlexBox flexDirection="column" gap="24px">
      <Pagination
        totalPages={10}
        leadingContent={<PaginationSelect />}
      />
      <Pagination
        totalPages={10}
        leadingContent={<PaginationSelect pageSizeOptions={[20, 50, 100]} />}
      />
      <Pagination
        totalPages={10}
        leadingContent={
          <PaginationSelect
            label="items per page"
            optionRender={(pageSize) => \`\${pageSize} items\`}
          />
        }
      />
    </FlexBox>
  )
}

export default Demo;`}
/>

### PaginationField

페이지 번호를 입력해서 이동할 수 있어요.<br />
유효하지 않은 페이지 번호를 입력하면 이동하지 않아요.

<Demo code={`import { Pagination, PaginationField, FlexBox } from '@wanteddev/wds';

const Demo = () => {
  return (
    <FlexBox flexDirection="column" gap="24px">
      <Pagination totalPages={10} leadingContent={<PaginationField />} />
      <Pagination totalPages={10} leadingContent={<PaginationField label="go to page" />} />
    </FlexBox>
  )
}

export default Demo;`}
/>

### LeadingContent, TrailingContent

variant가 `extended`일 때 콘텐츠를 추가할 수 있어요.

<Demo code={`import { Pagination, PaginationField, PaginationSelect, FlexBox } from '@wanteddev/wds';

const Demo = () => {
  return (
    <FlexBox flexDirection="column" gap="40px">
      <FlexBox flexDirection="column" gap="24px">
        <Pagination 
          totalPages={10}
          leadingContent={<PaginationSelect />}
        />
        <Pagination 
          totalPages={10}
          leadingContent={<PaginationField />}
        />
        <Pagination 
          totalPages={10}
          leadingContent={<span>커스텀 요소</span>}
        />
      </FlexBox>

      <FlexBox flexDirection="column" gap="24px">
        <Pagination 
          totalPages={10}
          trailingContent={<PaginationSelect />} 
        />
        <Pagination 
          totalPages={10}
          trailingContent={<PaginationField />} 
        />
        <Pagination 
          totalPages={10}
          trailingContent={<span>커스텀 요소</span>} 
        />
      </FlexBox>

      <FlexBox flexDirection="column" gap="24px">
        <Pagination 
          totalPages={10}
          leadingContent={<PaginationSelect />}
          trailingContent={<PaginationField />} 
        />
        <Pagination 
          totalPages={10} 
          leadingContent={<span>커스텀 요소</span>} 
          trailingContent={<span>커스텀 요소</span>} 
        />
      </FlexBox>
    </FlexBox>
  )
}

export default Demo;`}
/>
