# AvatarButton

클릭할 수 있는 아바타에 사용하며 상태를 표시할 수 있어요.

## 활용

- interaction이 있는 아바타에 사용해요.

<Demo code={`import { Avatar, AvatarButton } from '@wanteddev/wds';

const Demo = () => {
  return (
    <AvatarButton>
      <Avatar src="https://static.wanted.co.kr/oneid-user/2kcR2ULXRgEC7Rgk5psLTK/BwWtS7ZW8ryS2dpQrAW8Cr.png" alt="User"/>
    </AvatarButton>
  )
}

export default Demo;`}
/>
