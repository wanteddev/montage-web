# TopNavigation

## 활용

- 애플리케이션과 웹에서 주요한 제어 영역을 구성할 때 사용합니다.
- 내부 간격을 조정할 때는 `--wds-action-area-margin-x`, `--wds-action-area-margin-y`, `--wds--action-area-extra-content-margin` 을 사용해주세요.
- 스크롤 여부에 따라 scrolled 옵션을 prop 으로 조정해요.
- 모달 내부에서 사용할 경우에는 별도의 추가 처리가 필요하지 않아요. (scrolled, 간격, 닫기 버튼)

<Demo code={`import {
  TopNavigation,
  TopNavigationButton,
} from '@wanteddev/wds';
import { IconChevronLeft, IconClose } from '@wanteddev/wds-icon';

const Demo = () => {
  return (
    <TopNavigation
      leftButton={(
        <TopNavigationButton>
          <IconChevronLeft />
        </TopNavigationButton>
      )}
      rightButton={(
        <TopNavigationButton>
          <IconClose />
        </TopNavigationButton>
      )}>
      프로필
    </TopNavigation>
  )
}

export default Demo;`}
/>

### Toolbar

`Tab` 컴포넌트 등과 함께 조합할 수 있습니다.

Background blur 효과를 함께 적용하기 위해 사용합니다.

<Demo code={`import {
  TopNavigation,
  TopNavigationButton,
  Tab,
  TabList,
  TabListItem,
} from '@wanteddev/wds';

const Demo = () => {
  return (
    <Tab defaultValue="">
      <TopNavigation toolbar={(
        <TabList padding size="small">
          <TabListItem value="">기본</TabListItem>
          <TabListItem value="1">추가</TabListItem>
        </TabList>
      )}>
        Normal
      </TopNavigation>
    </Tab>
  )
}

export default Demo;`}
/>
