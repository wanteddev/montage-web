# Select

필드를 눌러 드롭다운 메뉴, 모달, 바텀시트를 호출하여 항목을 선택할 수 있습니다.

## 활용

- 여러 옵션 중 하나의 값을 선택할 수 있어요.
- leftContent에 요소를 추가 할 때는 `SelectContent`로 감싸서 사용합니다.

## Components

아래와 같이 조합하여 사용합니다.

```tsx
<Select>
  <OptionGroup>
    <Option>
      옵션1
    </Option>
  </OptionGroup>
  <OptionGroup>
    <Option>
      옵션2
    </Option>
  </OptionGroup>
</Select>
```
