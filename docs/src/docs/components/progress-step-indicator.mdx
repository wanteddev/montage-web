# ProgressStepIndicator

진행 중인 프로세스의 상태를 사용자에게 알려줍니다.

## 활용

- 시스템 작업(다운로드, 업로드, 처리 등)의 진행률을 시각적으로 보여줍니다.
- 작업에 완료 비율을 표시하려면 Step 타입을 사용합니다.
- 프로필 작성 완료 비율을 보여줄 수 있어요.
- 이력서 글자 수 정보를 안내할 때 사용해요.
- 현재 단계와 총 단계를 표시하는 데 사용해요.

### Collaboration
<Demo code={`import { Button, FlexBox, ProgressStepIndicator, ProgressStepIndicatorItem } from '@wanteddev/wds';
import { useState } from 'react';

const Demo = () => {
  const [activeStep, setActiveStep] = useState('3');

  const handleClickPrev = () => {
    if (activeStep === 0) return;

    setActiveStep(prev => (Number(prev) - 1).toString());
  };

  const handleClickNext = () => {
    if (activeStep === 5) return;

    setActiveStep(prev => (Number(prev) + 1).toString());
  };

  return (
    <FlexBox flexDirection="column" gap="16px">
      <FlexBox gap="20px">
        <Button onClick={handleClickPrev}>Prev</Button>
        <Button onClick={handleClickNext}>Next</Button>
      </FlexBox>
      <ProgressStepIndicator value={activeStep} onValueChange={setActiveStep}>
        <ProgressStepIndicatorItem value="1" />
        <ProgressStepIndicatorItem value="2" />
        <ProgressStepIndicatorItem value="3" />
        <ProgressStepIndicatorItem value="4" />
        <ProgressStepIndicatorItem value="5" />
      </ProgressStepIndicator>
    </Flexbox>
  )
}

export default Demo;`}
/>
