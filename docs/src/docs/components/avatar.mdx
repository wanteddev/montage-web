# Avatar

아바타는 사용자(개인) 또는 기업의 시각적 표현이며, 이미지를 표시할 수 있습니다.

## 활용

- 사용자를 시각적으로 표현할 때 사용해요.
- 예외적으로 Variant에 없는 사이즈를 사용할 경우 4배수 크기로 작업합니다.

<Demo code={`import { Avatar } from '@wanteddev/wds';

const Demo = () => {
  return (
    <Avatar
      src="https://static.wanted.co.kr/oneid-user/2kcR2ULXRgEC7Rgk5psLTK/BwWtS7ZW8ryS2dpQrAW8Cr.png"
      alt="User"
    />
  )
}

export default Demo;`}
/>
