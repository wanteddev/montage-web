# ImageLoader

`https://image.wanted.co.kr/optimize` 를 이용하여 이미지 최적화 + 캐시를 진행한 img 소스를 반환합니다.

## 활용

- 이미지 소스가 `/^https\:\/\/.+\.wanted(\.co\.kr|\.com|\.jobs)/` 정규식에 따라 일치하는 경우에만 이미지 최적화를 진행해요.
- `width` 및 `quality` 속성을 활용하여 이미지가 최적화 될 때 깨지지 않도록 설정이 필요해요.

<Demo code={`import { ImageLoader } from '@wanteddev/wds';

const Demo = () => {
  return (
    <ImageLoader
      quality={90}
      width="300px"
      src="https://static.wanted.co.kr/images/company/79/elpzxpmgh94xesrf__1080_790.png"
      alt="Wanted Company Image"
    />
  )
}

export default Demo;`}
/>

## getOptimizedImageSource

`srcset`, `sizes` 속성을 통해 브라우저 첫 접속 시 `mediaQuery` 에 따라 사진 사이즈를 조절할 수 있습니다.
이를 위해 `getOptimizedImageSource` 유틸 함수를 제공합니다.

<Demo code={`import { ImageLoader, getOptimizedImageSource } from '@wanteddev/wds';

const Demo = () => {
  return (
    <ImageLoader
      quality={90}
      width="400px"
      src="https://static.wanted.co.kr/images/company/79/elpzxpmgh94xesrf__1080_790.png"
      alt="Wanted Company Image"
      srcSet={\`\$\{getOptimizedImageSource({
        src: 'https://static.wanted.co.kr/images/company/79/elpzxpmgh94xesrf__1080_790.png',
        width: '200px',
        quality: 90
      })\} 200w, \$\{getOptimizedImageSource({
        src: 'https://static.wanted.co.kr/images/company/79/elpzxpmgh94xesrf__1080_790.png',
        width: '400px',
        quality: 90
      })\} 400w\`}
      sizes="(max-width: 767px) 200px, 400px"
    />
  )
}

export default Demo;`}
/>
