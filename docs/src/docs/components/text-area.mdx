# TextArea

사용자가 특정한 텍스트를 입력하거나 편집할 수 있습니다.

## 활용

- 입력한 텍스트에 따라 자동으로 늘어나요.
- `maxRows` 와 `minRows` 로 최대 / 최소로 늘어나는 line 수를 정할 수 있어요.
- 너비 값은 `width` prop을 이용해주세요.
- leadingContent, trailingContent에 요소를 추가할 때는 `TextAreaContent` 를 이용해주세요.

const Demo = () => {
  return (
    <TextArea placeholder="입력하세요." width="300px" />
  )
}

export default Demo;`}
/>

## Example

### MaxRows

`maxRows` 를 이용하여 최대 line 수를 결정할 수 있습니다.

<Demo code={`import { TextArea, FlexBox, Label, TextButton } from '@wanteddev/wds';

  return (
    <TextArea
      placeholder="입력하세요."
      width="300px"
      maxRows={3}
    />
  )
}

export default Demo;`}
/>

### Content

`TextAreaContent` 를 이용하여 left, right에 추가할 수 있어요.
다만, invalid 상태에서는 trailingContent가 경고 아이콘으로 Override 됩니다.

### Form

<Demo code={`import { TextArea, FlexBox, Label, TextButton, TextAreaContent, Button, FormField, FormLabel, FormControl, FormMessage, FormErrorMessage } from '@wanteddev/wds';
import { useForm, Controller } from 'react-hook-form';

const Demo = () => {
  const form = useForm({ defaultValues: { content: '' } })

  return (
    <FlexBox
      as="form"
      flexDirection="column"
      gap="20px"
      onSubmit={form.handleSubmit((v) => alert(JSON.stringify(v)))}
    >
      <Controller
        control={form.control}
        name="content"
        rules={{
          required: {
            value: true,
            message: "필수 값입니다.",
          },
          maxLength: 20
        }}
        render={({ field, formState }) => (
          <FormField>
            <FormLabel required>주제</FormLabel>

            <FormControl>
              <TextArea
                {...field}
                placeholder="입력하세요."
                invalid={Boolean(formState.errors.content)}
                width="300px"
                leadingContent={(
                  <TextAreaContent variant="characterCounter">
                    20
                  </TextAreaContent>
                )}
                trailingContent={(
                  <TextAreaContent variant="button">
                    <TextButton size="small">텍스트</TextButton>
                  </TextAreaContent>
                )}
              />
            </FormControl>

            {Boolean(formState.errors.content) ? (
              <FormErrorMessage>{formState.errors.content?.message}</FormErrorMessage>  
            ) : (
              <FormMessage>메시지에 마침표를 찍어요.</FormMessage>  
            )}

          </FormField>
        )}
      />

      <Button type="submit">제출</Button>
    </FlexBox>
  )
}

export default Demo;`}
/>
