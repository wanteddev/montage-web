# TextArea

사용자가 특정한 텍스트를 입력하거나 편집할 수 있습니다.

## 활용

- 입력한 텍스트에 따라 자동으로 늘어나요.
- `maxRows` 와 `minRows` 로 최대 / 최소로 늘어나는 line 수를 정할 수 있어요.
- Custom Css로 padding 값을 바꾸면 동작이 달라져요. padding 값은 변경하지 않도록 주의해요.

<Demo code={`import { TextArea } from '@wanteddev/wds';

    <TextArea placeholder="입력하세요." width="300px" />
  )
}

/>
