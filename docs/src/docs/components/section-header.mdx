# SectionHeader

## 활용

- 섹션 헤더는 콘텐츠 본문을 나누어 전체적인 구조를 만들고, 주제와 탐색을 쉽게 할 수 있도록 도와줘요.


<Demo code={`import { SectionHeader, TextButton } from '@wanteddev/wds';
const Demo = () => {
  return (
    <SectionHeader trailingContent={<TextButton color="assistive">더보기</TextButton>}>
      최근 본 포지션
    </SectionHeader>
  )
}

export default Demo;`}
/>

### Content

`headingContent`, `trailingContent` 속성을 통해 컨텐츠를 추가할 수 있어요.

<Demo code={`import { FlexBox, SectionHeader, SectionHeaderNavigation, SectionHeaderNavigationButton, TextButton, IconButton, ChipFilter } from '@wanteddev/wds';
import { IconBlank, IconChevronLeftSmall, IconChevronRightSmall } from '@wanteddev/wds-icon';

const Demo = () => {
  return (
    <FlexBox flexDirection="column" gap="32px">
      <SectionHeader
        headingContent={
          <ChipFilter
            size="small"
            variant="outlined"
          >
            텍스트
          </ChipFilter>
        }
        trailingContent={
          <TextButton color="assistive">
            더보기
          </TextButton>
        }
      >
        최근 본 포지션
      </SectionHeader>

      <SectionHeader
        headingContent={
          <IconButton size={24}>
            <IconBlank />
          </IconButton>
        }
        trailingContent={
          <SectionHeaderNavigation>
            <SectionHeaderNavigationButton>
              <IconChevronLeftSmall />
            </SectionHeaderNavigationButton>
            <SectionHeaderNavigationButton>
              <IconChevronRightSmall />
            </SectionHeaderNavigationButton>
          </SectionHeaderNavigation>
        }
      >
        최근 본 포지션
      </SectionHeader>
    </FlexBox>
  )
}

export default Demo;`} />
