# Slider

특정 범위에 대한 값을 선택할 때 사용합니다.

## 활용

<Demo code={`import { Slider } from '@wanteddev/wds';

const Demo = () => {
  return (
    <Slider defaultValue={[0, 50]} />
  )
}

export default Demo;`}
/>

<PropsTable component="Slider" />


## Examples

### Label

각 Thumb 부분에 label을 추가할 수 있습니다.

<Demo code={`import { Slider } from '@wanteddev/wds';

const Demo = () => {
  return (
    <Slider
      defaultValue={[1, 4]}
      label={({ value }) => {
        if (value === 0) return '신입';
        if (value === 10) return '10년 이상';
        return \`\${value}년\`
      }}
      max={35}
    />
  )
}

export default Demo;`}
/>

### Heading

<Demo code={`import { Slider } from '@wanteddev/wds';

const getSliderLabel = ({ value }) => {
  if (value === 0) return '신입';
  if (value === 10) return '10년 이상';
  return \`\${value}년\`
}

const MIN = 0;
const MAX = 10;

const Demo = () => {
  return (
    <Slider
      min={MIN}
      max={MAX}
      defaultValue={[MIN, MAX]}
      label={getSliderLabel}
      heading={({ values }) => {
        if (values.every((v) => v === values.at(0))) {
          return \`경력 \$\{getSliderLabel({ value: values.at(0) })\}\`
        }

        if (values.every((v) => v === MIN || v === MAX)) {
          return '경력 전체'
        }

        return (
          <React.Fragment>
            <span>{getSliderLabel({ value: values.at(0) })}</span>
            <span>~</span>
            <span>{getSliderLabel({ value: values.at(1) })}</span>
          </React.Fragment>
        )
      }}
    />
  )
}

export default Demo;`}
/>

### Step

키보드로 조작했을 때 한번에 이동할 거리를 설정할 수 있습니다.

<Demo code={`import { Slider } from '@wanteddev/wds';

const Demo = () => {
  return (
    <Slider defaultValue={[0, 8]} step={4} max={20} />
  )
}

export default Demo;`}
/>

### MinStepBetweenThumbs

두 Step 사이 최소 거리를 제한할 수 있습니다.

    <Slider defaultValue={[0, 16]} minStepBetweenThumbs={8} max={20} />

export default Demo;`}
/>

### DisableSwapThumbs

Slider를 조작할 때 다른 Thumb을 넘어갈 수 없도록 제한합니다.

<Demo code={`import { Slider } from '@wanteddev/wds';

export default Demo;`}
/>

### Form

<Demo code={`import { Slider, FlexBox, Button } from '@wanteddev/wds';
import { useForm, Controller } from 'react-hook-form';

const Demo = () => {
  const form = useForm({
    defaultValues: {
      single: 0,
      multiple: [0, 5]
    }
  })

  return (
    <FlexBox as="form" gap="16px" onSubmit={form.handleSubmit(v => alert(JSON.stringify(v)))} flexDirection="column">
      <Controller 
        name="single"
        control={form.control}
        render={({ field }) => (
          <Slider {...field} heading="Single" value={[field.value]} onValueChange={([value]) => field.onChange(value)} max={10} />
        )}
      />

      <Controller 
        name="multiple"
        control={form.control}
        render={({ field }) => (
          <Slider {...field} heading="Multiple" onValueChange={field.onChange} max={10} />
        )}
      />

      <Button type="submit">제출</Button>
    </FlexBox>
  )
}

export default Demo;`}
/>
