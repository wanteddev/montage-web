# Sx Prop

`sx` 라는 prop을 이용하면 마치 emotion을 사용하는 것 처럼 동작하게 합니다.

## Box

`Box` 컴포넌트는 디자인시스템 테마 객체에 접근할 수 있는 컴포넌트입니다.

디자인 시스템 컴포넌트들은 모두 해당 Box를 기반으로 설계되었으며 sx Prop을 자유롭게 사용할 수 있습니다.

<Demo 
  code={`import { Box } from '@wanteddev/wds';

const Demo = () => {
  return (
    <Box
      sx={theme => ({
        backgroundColor: theme.palette.background.elevated.alternative, width: '50px', height: '50px'
      })}
    />
  );
}

export default Demo;
`}
/>
