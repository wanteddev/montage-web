# Tree Shacking

현재 `@wanteddev/wds-icon` 패키지만 tree shacking을 지원합니다.

## Next.js

Nextjs를 사용하는 경우에는 간단하게 트리쉐이킹을 활성화 할 수 있습니다.

```javascript
/** @type {import('next').NextConfig} */
module.exports = {
  experimental: {
    optimizePackageImports: ['@wanteddev/wds-icon'],
  },
};
```

## Compiler

그 외의 경우에는 컴파일러의 도움을 받아 트리쉐이킹을 진행합니다.

### Babel

`pnpm`, `yarn`, `npm` 등 툴을 활용하여 패키지를 설치합니다.

```bash
yarn add -D babel-plugin-import
```

babelrc를 아래와 같이 구성합니다.

```json
{
  "plugins": [
    ["import", {
      "libraryName": "@wanteddev/wds-icon",
      "libraryDirectory": "",
      "camel2DashComponentName": true,
    }]
  ]
}
```

### 설정

`emotion` 의 Theme 타입을 지정하기 위해 `@types/wds.d.ts` 를 생성합니다.

```typescript
/// <reference types="@wanteddev/wds/declaration" />
```

> tsconfig 의 includes 필드에 `@types/wds.d.ts` 가 포함되어 있어야 합니다.

## 추가 구성

### Babel

`babel` 을 사용하는 경우 패키지를 설치합니다.

```bash
yarn add -D @emotion/babel-plugin
```

`.babelrc` 에 아래 구성을 추가합니다.

```json
{
  "plugins": ["@emotion"]
}
```
