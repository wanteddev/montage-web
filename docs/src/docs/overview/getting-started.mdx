# Wanted Design System

WDS는 Emotion 기반으로 작성되어 있습니다. 현재는 Emotion 11버전을 지원합니다.

## 시작하기

### 설치

`pnpm`, `yarn`, `npm` 등 툴을 활용하여 패키지를 설치합니다.

```bash
yarn add @wanteddev/wds @wanteddev/wds-icon @emotion/react
```

### 설정

`emotion` 의 Theme 타입을 지정하기 위해 `@types/wds.d.ts` 를 생성합니다.

```typescript
/// <reference types="@wanteddev/wds/declaration" />
```

> tsconfig 의 includes 필드에 `@types/wds.d.ts` 가 포함되어 있어야 합니다.

## 추가 구성

### Babel

`babel` 을 사용하는 경우 패키지를 설치합니다.

```bash
yarn add -D @emotion/babel-plugin
```

`.babelrc` 에 아래 구성을 추가합니다.

```json
{
  "plugins": ["@emotion"]
}
```

### Swc

`swc` 를 사용하는 경우 Next.js와 React.js의 구성이 다릅니다.

Next.js를 사용하는 경우에는 `next.config.js` 에 아래 구성을 추가합니다.

```javascript
/** @type {import('next').NextConfig} */
module.exports = {
  compiler: {
    emotion: true,
  },
};
```

React.js의 경우 아래 패키지를 설치합니다.

```bash
yarn add -D @swc/plugin-emotion
```

`.swcrc` 에 아래 구성을 추가합니다.

```json
{
  "jsc": {
    "experimental": {
      "plugins": ["@emotion"]
    }
  }
}
```

## React.js

Root App에서 global css를 가져오도록 설정합니다.
또한 ThemeProvider로 앱을 감싸줍니다.

```tsx
// App.tsx
import { createRoot } from 'react-dom/client';
import { ThemeProvider } from '@wanteddev/wds';

import App from './App';

import '@wanted-frontend/wds/global.css';

const root = createRoot(document.getElementById('app')!);

root.render(
  <ThemeProvider>
    <BrowserRouter>
      <App />
    </BrowserRouter>
  </ThemeProvider>
);
```

## Next.js

`_app.tsx` 혹은 `app/layout.tsx` 에 global css를 불러옵니다.

```typescript
import '@wanted-frontend/wds/global.css';
```

서버사이드에서 emotion을 사용하기 위한 추가 설정을 진행합니다.
이미 emotion을 사용하도록 구성되어 있는 경우 추가 설정을 진행할 필요가 없습니다.

### App Dir

Next.js에서 사용하기 위한 추가 패키지를 설치합니다.

```bash
yarn add @wanteddev/wds-nextjs
```

이후 `app/layout.tsx` 를 아래와 같이 작성해줍니다.

```tsx
// app/layout.tsx
'use client';
import { Head } from '@wanted-frontend/config';
import { ThemeProvider } from '@wanted-frontend/wds';
import { AppRouterCacheProvider } from '@wanted-frontend/wds-nextjs';

import type { PropsWithChildren } from 'react';

import '@wanted-frontend/wds/global.css';

const RootLayout = (props: PropsWithChildren) => {
  return (
    <html suppressHydrationWarning>
      <head>
        <Head />
      </head>
      <body>
        <ThemeProvider>
          <AppRouterCacheProvider>{props.children}</AppRouterCacheProvider>
        </ThemeProvider>
      </body>
    </html>
  );
};

export default RootLayout;
```
