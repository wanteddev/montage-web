## Basic

`minRows`, `maxRows` 를 이용하여 TextArea의 높이를 조절할 수 있습니다.

또한 `rightIcon` 의 위치를 변경하고 싶을 때는 `[wds-component='text-area-right-icon']` 을 이용합니다.

<Markdown>
  {`
\`\`\`css
[wds-component="text-area-right-icon"] {
	bottom: 15px;
}
\`\`\`
`}
</Markdown>
