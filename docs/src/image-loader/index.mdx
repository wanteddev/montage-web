# Image Loader

`https://image.wanted.co.kr/optimize` 를 이용하여 이미지 최적화 + 캐시를 진행한 img 소스를 반환합니다.

`/^https\:\/\/.+\.wanted(\.co\.kr|\.com|\.jobs)/` 정규식에 따라 일치하는 경우에만 이미지 최적화를 진행하고
그렇지 않을 경우 기본 `src` 를 이용하여 이미지를 렌더링 합니다.

`width` 및 `quality` 속성을 활용하여 이미지가 최적화 될 때 깨지지 않도록 설정이 필요합니다.
