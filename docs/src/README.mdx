## Wanted Design System (WDS)

WDS는 Emotion 기반으로 작성되어 있습니다.
현재는 Emotion 11버전까지 지원합니다.

## 설치

<Markdown>
  {`
\`\`\`shell
pnpm -F service-name install @wanteddev/wds @wanteddev/wds-icon @emotion/react @emotion/core
\`\`\`
`}
</Markdown>

## 설정

`@types/wds.d.ts` 를 생성합니다.

> 주의: tsconfig 내에 include로 소스가 포함 되어 있는지 확인하세요.

{`

\`\`\`

</Markdown>

## 사용 규칙

컴포넌트 별로 `xs`, `sm`, `md`, `lg` prop이 있을 수 있습니다.
해당 prop은 반응형에 따라 prop을 다르게 override할 수 있습니다.

이 때 Mobile First Design 원칙에 따라 (min-width) 로 breakpoint를 지정 합니다.
모바일일 때 `variant="label1_normal"`, 태블릿일 때 `variant="body1_normal"` 로 변경하고 싶으면
아래와 같이 작성합니다.

<Markdown>
{`
\`\`\`tsx
// app/page.tsx
'use client';
import { Typography } from '@wanteddev/wds';

const RootPage = () => {
return (
<Typography variant="label1_normal" weight="regular" md={{ variant: "body1_normal" }}>Result</Typography>
);
};

export default RootPage;
\`\`\`
`}
</Markdown>

또한 emotion의 css Props도 object 형태, 배열형태, theme callback을 받는 형태 모두 사용가능합니다.

<Markdown>
{`
\`\`\`tsx
// app/page.tsx
'use client';
import { css } from '@emotion/react';
import { Typography } from '@wanteddev/wds';

const RootPage = () => {
return (
<Typography
variant="label1_normal"
weight="regular"
css={theme => css\`
display: flex;
\`}>
Result
</Typography>
);
};

export default RootPage;
\`\`\`
`}
</Markdown>
