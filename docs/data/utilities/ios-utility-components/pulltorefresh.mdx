## Overview

SwiftUI `ScrollView` 밑에 깔린 `UIScrollView`를 찾아 `refreshControl`에 [PullToRefreshControl](/documentation/montage/pulltorefreshcontrol.md)을 붙입니다. UIKit 화면과 같은 컨트롤을 쓰므로 로고 모션과 트리거 거리, 갱신 중 높이가 같습니다.

<summary>``func pullToRefresh(refresh: () async -> Void) -> some View``</summary>


스크롤 뷰에 당겨서 새로고침(Pull-to-Refresh)을 추가합니다.

- **Parameters**

  | Parameter | Description |
  | --- | --- |
  | `refresh` | 갱신할 때 실행할 비동기 작업 |

- **Return Value**

  당겨서 새로고침이 추가된 뷰
- **Discussion**

  당기면 로고가 그려지고, 놓으면 `refresh`가 끝날 때까지 로고가 돕니다. [PullToRefreshControl](/documentation/montage/pulltorefreshcontrol.md)을 쓰므로 UIKit 화면과 동작이 같습니다.

  [ScrollView](/documentation/montage/scrollview.md)는 [onRefresh(_:)](/documentation/montage/scrollview/onrefresh(_:).md)가 이 수정자를 대신 붙여 주므로, 직접 붙이는 건 `SwiftUI.ScrollView`를 쓰는 경우입니다. 스크롤 뷰에 바로 붙입니다.

  ```swift
  SwiftUI.ScrollView {
      content
  }
  .pullToRefresh {
      await loadData()
  }
  ```
