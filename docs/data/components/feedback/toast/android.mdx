## WantedToast
SnackbarHost를 기반으로 한 Wanted 커스텀 Toast 컴포넌트입니다.

WantedToastVisuals 를 사용하면 Variant와 아이콘이 포함된 Toast로 표시되고
기본 SnackbarVisuals 를 사용하면 같은 Wanted 레이아웃에 메시지만 표시됩니다(actionLabel 등은 표시되지 않습니다).

```kotlin
val snackbarHostState = remember { SnackbarHostState() }
WantedToast(snackbarHostState = snackbarHostState)
```

### Parameters
| 이름 | 타입 | 설명 |
|:---|:---|:---|
| snackbarHostState | SnackbarHostState | Snackbar 상태를 관리합니다. |
| modifier | Modifier | 토스트를 띄우는 호스트(SnackbarHost)에 적용됩니다. 토스트 카드의 모양·배경은 바꿀 수 없으며, 위치·크기 배치에 씁니다. (WantedSnackBar 의 modifier 는 각 카드에 적용되어 동작이 다릅니다.) |
| windowInsets | WindowInsets | 시스템 인셋 대응을 위한 설정입니다. |


## Advanced
### WantedGlobalToastManager
앱 전역에서 Toast를 관리하는 싱글톤 매니저입니다.

Activity 생명주기를 추적하여 현재 활성화된 화면에 Toast를 표시하며,
키보드 및 Navigation bar 높이에 맞춰 자동으로 패딩을 조정합니다.

```kotlin
// Application 클래스(onCreate)에서 초기화
WantedGlobalToastManager.initialize(this)

// 토스트 표시
WantedGlobalToastManager.showToast(
    text = "저장되었습니다.",
    variant = WantedToastVariant.Positive
)
```

### initialize
Toast 매니저를 초기화합니다.

Application 생명주기에 콜백을 등록하여 Activity 상태를 추적합니다.
반드시 Application 클래스에서 한 번만 호출해야 합니다.

### showToast
커스텀 컴포넌트 콘텐츠로 Toast를 표시합니다.

이전에 표시 중이던 Toast는 자동으로 취소되며, 지정된 시간 후에 자동으로 사라집니다.

현재 Activity 에 View 를 붙이므로 메인 스레드에서 호출해야 합니다. initialize 전에 호출하면 아무것도 표시하지 않습니다.

<details>
  <summary>Parameters</summary>

  | 이름 | 타입 | 설명 |
  |:---|:---|:---|
  | duration | ToastDuration | 토스트가 표시될 시간입니다. 기본값은 Short(3초)입니다. |
  | content | (@Composable () -> Unit) | 표시할 컴포넌트 콘텐츠입니다. |

</details>
<br />
### showToast
텍스트와 스타일을 지정하여 Toast를 표시합니다.

Variant를 통해 메시지 타입(긍정, 주의, 부정 등)을 지정할 수 있습니다.

현재 Activity 에 View 를 붙이므로 메인 스레드에서 호출해야 합니다. initialize 전에 호출하면 아무것도 표시하지 않습니다.

<details>
  <summary>Parameters</summary>

  | 이름 | 타입 | 설명 |
  |:---|:---|:---|
  | text | String | 토스트에 표시할 메시지입니다. 최대 두 줄까지 표시되고 넘으면 말줄임(…)됩니다. |
  | duration | ToastDuration | 토스트가 표시될 시간입니다. 기본값은 Short(3초)입니다. |
  | padding | PaddingValues | 토스트 바깥에 추가로 더하는 여백입니다. 토스트 자체의 20dp 여백과 내비게이션 바·키보드 높이 보정은 이 값과 별도로 항상 적용됩니다. 기본값은 하단 20dp입니다. |
  | variant | WantedToastVariant | 토스트 스타일입니다. 기본값은 Normal입니다. |
  | icon | (@Composable () -> Unit)? | 사용자 정의 아이콘입니다. variant 가 Normal(deprecated Message 포함)일 때만 표시되고, 그 외 variant 는 variant 고유 아이콘이 사용되어 무시됩니다. |

</details>

### SnackbarHostState.showToast
Wanted 스타일의 Toast를 표시하는 확장 함수입니다.

WantedToastVisuals를 사용하여 표시하며,
Variant를 통해 메시지 타입(긍정, 주의, 부정 등)을 지정할 수 있습니다.
이미 표시 중인 Toast가 있다면 자동으로 닫고 새로운 Toast를 표시합니다.

```kotlin
val snackbarHostState = remember { SnackbarHostState() }
val scope = rememberCoroutineScope()

// 컴포저블 본문에서 바로 부르면 리컴포지션마다 다시 뜬다. 이벤트 콜백 안에서 호출한다.
WantedButton(
    text = "저장",
    onClick = {
        snackbarHostState.showToast(
            scope = scope,
            message = "저장되었습니다.",
            variant = WantedToastVariant.Positive
        )
    }
)
```

<details>
  <summary>Parameters</summary>

  | 이름 | 타입 | 설명 |
  |:---|:---|:---|
  | scope | CoroutineScope | 코루틴을 실행할 스코프입니다. |
  | message | String | 토스트에 표시할 메시지입니다. 최대 두 줄까지 표시되고 넘으면 말줄임(…)됩니다. |
  | variant | WantedToastVariant | 토스트 스타일입니다. 기본값은 Normal입니다. |

</details>

### WantedToastVisuals
커스텀 Toast를 위한 시각적 구성 클래스입니다.

메시지, 아이콘, variant 설정 등을 포함하며 SnackbarVisuals를 확장합니다.
WantedToast 는 message·variant·icon 만 화면에 그리고, 토스트 폭은 최대 420dp 입니다.

<details>
  <summary>Properties</summary>

  | 이름 | 타입 | 설명 |
  |:---|:---|:---|
  | message | String | 토스트에 표시할 메시지입니다. 최대 두 줄까지 표시되고 넘으면 말줄임(…)됩니다. |
  | actionLabel | String | SnackbarVisuals 계약을 맞추기 위한 값입니다. Toast 는 액션 버튼을 그리지 않으므로 화면에 표시되지 않습니다. |
  | duration | SnackbarDuration | 토스트 노출 시간입니다. |
  | withDismissAction | Boolean | SnackbarVisuals 계약을 맞추기 위한 값입니다. Toast 는 닫기 버튼을 그리지 않으므로 효과가 없습니다. |
  | variant | WantedToastVariant | 메시지 타입을 나타내는 스타일 variant입니다. |
  | icon | (@Composable () -> Unit)? | 사용자 정의 아이콘 슬롯입니다. variant 가 Normal(deprecated Message 포함)일 때만 표시되고, 그 외 variant 는 variant 고유 아이콘이 사용되어 무시됩니다. |

</details>

## Sealed Class
### WantedToastVariant
Toast 메시지의 시각적 스타일을 정의하는 sealed 클래스입니다.

각 타입은 고유의 아이콘 리소스 및 색상 리소스를 포함하고 있으며,
사용자 피드백의 성격(정보, 긍정, 경고, 부정 등)을 나타냅니다.

| 값 | 설명 |
|:---|:---|
| Normal | 일반 텍스트 메시지를 표시하는 스타일입니다. 고유 아이콘은 없으며, icon 슬롯을 넘기면 그 아이콘이 표시됩니다. |
| Positive | 긍정적인 알림을 위한 스타일입니다. 체크 아이콘과 초록색 색상이 사용됩니다. |
| Cautionary | 주의가 필요한 상황을 나타내는 스타일입니다. 삼각형 느낌표 아이콘과 주황색 색상이 사용됩니다. |
| Negative | 부정적인 상황을 나타내는 스타일입니다. X 아이콘과 빨간색 색상이 사용됩니다. |

<details>
  <summary>Properties</summary>

  | 이름 | 타입 | 설명 |
  |:---|:---|:---|
  | resourceId | Int | 표시할 아이콘 리소스의 ID입니다. Normal·Message 는 고유 아이콘이 없어 -1 이므로 painterResource 에 바로 넘기지 않습니다. |
  | tinColor | Int | 아이콘에 적용될 색상 리소스의 ID입니다. Normal·Message 는 -1 입니다. |
  | backgroundResourceId | Int? | 배경 이미지 리소스의 ID입니다. |
  | backgroundTintColor | Int | 배경 이미지 리소스에 적용될 색상 리소스의 ID입니다. |

</details>
