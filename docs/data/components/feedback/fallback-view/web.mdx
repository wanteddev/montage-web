## Basic fallback view

콘텐츠가 비어있거나 오류가난 상황에 사용합니다.

<Demo code={`import { FallbackView, FallbackViewContent, FallbackViewText, FallbackViewActionArea, FallbackViewActionAreaButton } from '@montage-ui/core';

const Demo = () => {
  return (
    <FallbackView sx={{ margin: 'auto' }}>
      <FallbackViewContent>
        <FallbackViewText
          title="타이틀이 들어가요."
          description={
            <>
              상황에 대한 설명이 들어가요.
              <br />
              설명은 최대 두 줄로 작성해요.
            </>
          }
        />
        <FallbackViewActionArea>
          <FallbackViewActionAreaButton>텍스트</FallbackViewActionAreaButton>
        </FallbackViewActionArea>
      </FallbackViewContent>
    </FallbackView>
  )
}

export default Demo;`}
/>

## Anatomy

아래와 같이 조합하여 사용합니다.

```tsx
<FallbackView>
  <FallbackViewContent>
    <FallbackViewText />

    <FallbackViewActionArea>
      <FallbackViewActionAreaButton />
    </FallbackViewActionArea>
  </FallbackViewContent>
</FallbackView>
```

버튼은 항상 `FallbackViewActionArea`로 감싸서 사용합니다. 버튼 배치는 `FallbackViewActionArea`의 `variant`로 지정합니다.

## Action area

`FallbackViewActionArea`의 `variant`에 따라 버튼 레이아웃이 달라집니다.
- single (default)
- horizontal
- vertical

### Single

버튼을 하나만 배치할 때 사용합니다.

<Demo code={`import { FallbackView, FallbackViewContent, FallbackViewText, FallbackViewActionArea, FallbackViewActionAreaButton } from '@montage-ui/core';

const Demo = () => {
  return (
    <FallbackView padding="compact">
      <FallbackViewContent>
        <FallbackViewText
          title="variant: single"
          description={
            <>
              상황에 대한 설명이 들어가요.
              <br />
              설명은 최대 두 줄로 작성해요.
            </>
          }
        />
        <FallbackViewActionArea variant="single">
          <FallbackViewActionAreaButton>텍스트</FallbackViewActionAreaButton>
        </FallbackViewActionArea>
      </FallbackViewContent>
    </FallbackView>
  )
}

export default Demo;`}
/>

## Platform

`platform`에 따라 글자, 버튼 크기, action area 간격이 달라집니다.
- mobile
- desktop (default)

### Desktop

<Demo code={`import { FlexBox, SegmentedControl, SegmentedControlItem, FallbackView, FallbackViewContent, FallbackViewText, FallbackViewActionArea, FallbackViewActionAreaButton } from '@montage-ui/core';
import { useState } from 'react';

const Demo = () => {
  const [variant, setVariant] = useState('single');

  return (
    <FlexBox flexDirection="column" alignItems="center" gap="40px" sx={{ width: '100%' }}>
      <SegmentedControl value={variant} onValueChange={setVariant} sx={{ width: '100%', maxWidth: 320 }}>
        <SegmentedControlItem value="single">Single</SegmentedControlItem>
        <SegmentedControlItem value="horizontal">Horizontal</SegmentedControlItem>
        <SegmentedControlItem value="vertical">Vertical</SegmentedControlItem>
      </SegmentedControl>

      <FallbackView platform="desktop">
        <FallbackViewContent>
          <FallbackViewText
            title={\`platform: desktop / variant: \${variant}\`}
            description={
              <>
                상황에 대한 설명이 들어가요.
                <br />
                설명은 최대 두 줄로 작성해요.
              </>
            }
          />
          <FallbackViewActionArea variant={variant}>
            <FallbackViewActionAreaButton>텍스트</FallbackViewActionAreaButton>
            {variant !== 'single' && (
              <FallbackViewActionAreaButton>텍스트</FallbackViewActionAreaButton>
            )}
          </FallbackViewActionArea>
        </FallbackViewContent>
      </FallbackView>
    </FlexBox>
  )
}

export default Demo;`}
/>

- normal (default)
- compact
