## WantedFallbackView
제목, 설명, 버튼을 조합하여 비어 있는 상태를 안내하는 컴포넌트입니다.

주로 데이터가 없거나 결과가 없을 때 사용자에게 피드백을 제공하는 용도로 사용됩니다.
제목, 설명, 버튼을 선택적으로 구성할 수 있으며, 버튼 클릭 시 콜백을 전달할 수 있습니다.
버튼은 Assistive 색상만 사용하며, 좌우 여백은 호출하는 화면에서 배치합니다.
상하 여백은 `padding` 으로 지정합니다.

```kotlin
WantedFallbackView(
    padding = WantedFallbackPadding.Normal,
    heading = "데이터가 없습니다.",
    description = "새로운 데이터를 추가해보세요.",
    main = "추가하기",
    onClickMain = { /* 버튼 클릭 처리 */ }
)
```

### Parameters
| 이름 | 타입 | 설명 |
|:---|:---|:---|
| modifier | Modifier | 외형 및 배치를 조정하는 Modifier입니다. |
| padding | WantedFallbackPadding | 콘텐츠 상하 여백을 지정합니다 (Normal, Compact). |
| buttonVariant | WantedFallbackButtonVariant | 버튼 배치 방식입니다. Single 은 main 버튼 하나만 표시하고 alternative 는 무시합니다. Horizontal 은 alternative(왼쪽)·main(오른쪽)을 가로로, Vertical 은 main(위)·alternative(아래)를 세로로 배치합니다. 기본값은 Single입니다. |
| heading | String? | 상단에 강조 텍스트(제목)를 표시합니다. |
| description | String? | 제목 아래에 설명 텍스트를 표시합니다. 최대 두 줄까지만 표시됩니다. |
| main | String? | 메인 액션 버튼에 표시될 텍스트입니다. null일 경우 버튼은 렌더링되지 않습니다. |
| alternative | String? | 대체 액션 버튼 텍스트입니다. buttonVariant 가 Horizontal·Vertical 일 때만 표시되며, null 이면 렌더링되지 않습니다. |
| onClickMain | () -> Unit | 메인 액션 버튼 클릭 시 호출되는 콜백입니다. |
| onClickAlternative | () -> Unit | 대체 액션 버튼 클릭 시 호출되는 콜백입니다. |


## Advanced

## Enum
### WantedFallbackButtonVariant
| 값 | 설명 |
|:---|:---|
| Single | main 버튼 하나만 표시합니다. alternative 는 무시합니다. |
| Horizontal | alternative(왼쪽)·main(오른쪽)을 가로로 같은 너비로 배치합니다. |
| Vertical | main(위)·alternative(아래)를 세로로 배치합니다. |

### WantedFallbackPadding
| 값 | 설명 |
|:---|:---|
| Normal | 콘텐츠 위·아래에 각각 160dp 여백을 둡니다. |
| Compact | 콘텐츠 위·아래에 각각 80dp 여백을 둡니다. |
