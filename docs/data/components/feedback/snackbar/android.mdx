## WantedSnackBar
앱 전역에서 사용할 수 있는 커스텀 Snackbar 호스트입니다.

WantedSnackbarVisuals 사용 시 아이콘과 설명이 포함된 커스텀 레이아웃으로 표시되며,
기본 SnackbarVisuals를 사용하면 같은 Wanted 레이아웃에 메시지와 액션 버튼(actionLabel)만 표시됩니다.

```kotlin
val snackbarHostState = remember { SnackbarHostState() }
WantedSnackBar(snackbarHostState = snackbarHostState)
```

### Parameters
| 이름 | 타입 | 설명 |
|:---|:---|:---|
| snackbarHostState | SnackbarHostState | 스낵바 표시 상태를 제어합니다. |
| modifier | Modifier | 각 스낵바 항목에 적용되는 Modifier입니다(호스트가 아님). 카드와 그 바깥 고정 20dp 여백을 함께 감싸므로 border·background 등 장식은 카드보다 20dp 큰 영역에 적용됩니다. 호스트 배치는 부모(Scaffold 의 snackbarHost 등)에서 정합니다. (WantedToast 의 modifier 는 호스트에 적용되어 동작이 다릅니다.) |


## Advanced
### WantedSnackbarVisuals
Wanted 전용 Snackbar 메시지와 UI 요소를 지정하는 클래스입니다.

기본 메시지 외에 부가 설명, 아이콘을 지정할 수 있습니다.
WantedSnackBar 는 message·description·actionLabel·icon 만 화면에 그리며, 스낵바 폭은 최대 420dp 입니다.

<details>
  <summary>Parameters</summary>

  | 이름 | 타입 | 설명 |
  |:---|:---|:---|
  | message | String | 스낵바에 표시될 기본 메시지입니다. 한 줄까지만 표시되고 넘으면 말줄임(…)되며, 빈 문자열이면 생략됩니다. |
  | actionLabel | String? | 버튼에 표시될 텍스트입니다. 한 줄까지만 표시되고, null 이거나 빈 문자열이면 버튼이 생략됩니다. |
  | duration | SnackbarDuration | 스낵바 노출 지속 시간입니다. |
  | withDismissAction | Boolean | SnackbarVisuals 계약을 맞추기 위한 값입니다. WantedSnackBar 는 닫기 버튼을 그리지 않으므로 효과가 없습니다. |
  | description | String | 추가 설명 텍스트입니다. 메시지 아래에 최대 두 줄까지 표시되고 넘으면 말줄임(…)되며, 빈 문자열이면 생략됩니다. |
  | padding | PaddingValues | 현재 WantedSnackBar 가 사용하지 않아 효과가 없습니다. 바깥 여백은 WantedSnackBar 의 modifier 로 더할 수 있으며, 기본 20dp 보다 줄일 수는 없습니다. |
  | icon | (@Composable () -> Unit)? | 스낵바 좌측에 표시할 아이콘입니다. |

</details>

### SnackbarHostState.showSnackbar
Wanted 스타일의 Snackbar를 표시하는 확장 함수입니다.

WantedSnackbarVisuals를 사용하여 표시하며,
이미 표시 중인 Snackbar가 있다면 자동으로 닫고 새로운 Snackbar를 표시합니다.

```kotlin
val snackbarHostState = remember { SnackbarHostState() }
val scope = rememberCoroutineScope()

// 컴포저블 본문에서 바로 부르면 리컴포지션마다 다시 뜬다. 이벤트 콜백 안에서 호출한다.
WantedButton(
    text = "저장",
    onClick = {
        snackbarHostState.showSnackbar(
            scope = scope,
            message = "저장되었습니다."
        )
    }
)
```

<details>
  <summary>Parameters</summary>

  | 이름 | 타입 | 설명 |
  |:---|:---|:---|
  | scope | CoroutineScope | 코루틴을 실행할 스코프입니다. |
  | message | String | 스낵바에 표시할 메시지입니다. |

</details>
