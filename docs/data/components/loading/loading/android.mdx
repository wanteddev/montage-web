## WantedCircularLoading
부모 영역을 가득 채우고 그 가운데에 원형 로딩을 표시하는 컴포넌트입니다.

dim 배경 포함 여부, 크기, 색상을 설정할 수 있습니다.

```kotlin
WantedCircularLoading(
    size = 32.dp,
    circleColor = Color.Gray,
    dimColor = Color.Black.copy(alpha = 0.3f)
)
```

### Parameters
| 이름 | 타입 | 설명 |
|:---|:---|:---|
| modifier | Modifier | 컴포넌트에 적용할 Modifier입니다. 바깥 Surface 와 안쪽 Box 에 두 번 적용되므로 padding·background 등은 두 번 반영됩니다. 크기·배치 용도로만 씁니다. |
| circleColor | Color | 로딩 인디케이터 색상입니다. |
| dimColor | Color | 배경 dim 색상입니다. |
| size | Dp | 로딩 인디케이터 크기입니다. |


## Advanced
### WantedCircularProgressIndicator
커스터마이징 가능한 원형 Loading Indicator입니다.

기본 크기는 24dp이며, 선 굵기는 전체 크기의 10%로 자동 적용됩니다.

```kotlin
WantedCircularProgressIndicator(
    modifier = Modifier.size(40.dp),
    color = Color.Red
)
```

  | color | Color | 인디케이터 색상입니다. |

</details>

### WantedLogoLoading
Wanted 심볼 로딩 애니메이션을 표시하는 컴포넌트입니다.

isUseDim이 true인 경우 Dialog 기반으로 dim 처리된 로딩 화면이 표시되며, 이때 modifier 는 적용되지 않습니다.

```kotlin
WantedLogoLoading(isUseDim = true)
```

<details>
  <summary>Parameters</summary>

  | 이름 | 타입 | 설명 |
  |:---|:---|:---|
  | modifier | Modifier | 컴포넌트에 적용할 Modifier입니다. isUseDim 이 false 일 때만 적용되며, true 이면 무시됩니다. 적용될 때는 바깥 Surface 와 안쪽 Box 에 두 번 적용되므로 padding·background 등은 두 번 반영됩니다. |
  | isUseDim | Boolean | dim 배경 사용 여부입니다. true 이면 Dialog 로 표시하고, false 이면 부모를 가득 채워 가운데에 표시합니다. 기본값은 false입니다. |

</details>
<br />
### WantedLogoLoadingDialog
Dialog 기반의 Wanted 심볼 로딩 컴포넌트입니다.

외부 터치나 뒤로가기로 닫히지 않도록 설정된 Dialog에 로고 애니메이션이 표시됩니다.

<details>
  <summary>Parameters</summary>

  | 이름 | 타입 | 설명 |
  |:---|:---|:---|
  | onDismissRequest | () -> Unit | 다이얼로그 닫기 요청 시 호출되는 콜백입니다. |
  | properties | DialogProperties | Dialog 속성 설정입니다. |

</details>
