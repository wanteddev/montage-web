## WantedSkeletonCircle
원형 Skeleton 컴포넌트입니다.

내부적으로 WantedSkeletonRectangle을 CircleShape로 설정하여 사용합니다.

```kotlin
WantedSkeletonCircle(
    modifier = Modifier.size(100.dp)
)
```

### Parameters
| 이름 | 타입 | 설명 |
|:---|:---|:---|
| modifier | Modifier | 컴포넌트에 적용할 Modifier입니다. |
| color | Color | 배경 색상입니다. |

    modifier = Modifier.size(200.dp, 50.dp),
    shape = RoundedCornerShape(8.dp)

### WantedSkeletonText
텍스트를 표현하는 Skeleton 컴포넌트입니다.

다양한 길이 비율과 정렬 방식을 지원하며, Shimmer 애니메이션이 자동으로 적용됩니다.

```kotlin
WantedSkeletonText(
    length = WantedSkeletonLength.Ratio75,
    align = WantedSkeAlign.Left
)
```

  | align | WantedSkeAlign | 정렬 방식입니다. |
  | shape | RoundedCornerShape | 모서리 곡률입니다. |

### WantedSkeletonText
커스텀 비율 기반의 텍스트를 표현하는 Skeleton 컴포넌트입니다.

widthRadio 파라미터를 통해 너비 비율을 직접 지정할 수 있습니다.

<details>
  <summary>Parameters</summary>

  | 이름 | 타입 | 설명 |
  |:---|:---|:---|
  | widthRadio | Float | 텍스트 박스의 너비 비율입니다. 0.0 ~ 1.0 사이의 값을 사용합니다. |
  | modifier | Modifier | 컴포넌트에 적용할 Modifier입니다. |
  | align | WantedSkeAlign | 정렬 방식입니다. |
  | shape | RoundedCornerShape | 스켈레톤 박스의 모서리 곡률입니다. |
  | color | Color | 스켈레톤 박스의 배경 색상입니다. |

</details>
<br />
### Modifier.shimmer
콘텐츠 위에 단색 레이어를 덮고 그 투명도를 1초에 걸쳐 0 → 0.66 으로, 다시 1초에 걸쳐 0 으로 되돌리기를 반복하는 깜빡임 효과를 적용합니다.

원래 콘텐츠를 먼저 그린 뒤 그 위에 사각형을 칠하므로, 모양(둥근 모서리 등)이 필요하면 이 Modifier 앞에 clip 을 적용합니다.

<details>
  <summary>Parameters</summary>

  | 이름 | 타입 | 설명 |
  |:---|:---|:---|
  | colorRes | Int | 덮을 레이어의 색 리소스 ID(`@ColorRes`)입니다. 기본값은 R.color.background_neutral_primary 입니다. |

</details>
<br />
### Modifier.shimmerLinear
콘텐츠 위에 color 와 반투명 color 를 잇는 가로 방향 그라데이션을 덮고, 1.5초 주기로 흐르게 하는 shimmer 효과를 적용합니다.

원래 콘텐츠를 먼저 그린 뒤 그 위에 사각형을 칠하므로, 모양(둥근 모서리 등)이 필요하면 이 Modifier 앞에 clip 을 적용합니다. 색을 리소스 ID 로 넘기려면 colorRes 오버로드를 사용합니다.

<details>
  <summary>Parameters</summary>

  | 이름 | 타입 | 설명 |
  |:---|:---|:---|
  | color | Color | 그라데이션의 기준 색입니다. |
  | alpha | Float | 그라데이션 반대쪽 끝에 쓸 color 의 투명도입니다. 기본값은 OPACITY_16(0.16) 입니다. |

</details>
<br />
### Modifier.shimmerLinear
shimmerLinear 의 색 리소스 오버로드입니다. colorRes 를 색으로 바꿔 color 오버로드와 같은 효과를 적용합니다.

<details>
  <summary>Parameters</summary>

  | 이름 | 타입 | 설명 |
  |:---|:---|:---|
  | colorRes | Int | 그라데이션 기준 색의 리소스 ID(`@ColorRes`)입니다. 기본값은 R.color.surface_neutral_tertiary 입니다. |
  | alpha | Float | 그라데이션 반대쪽 끝에 쓸 색의 투명도입니다. 기본값은 OPACITY_16(0.16) 입니다. |

</details>
