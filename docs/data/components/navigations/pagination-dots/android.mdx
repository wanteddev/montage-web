## WantedDotIndicator
페이지네이션용 Dot Indicator 컴포넌트입니다.

현재 페이지 위치를 중심으로 일정 개수의 Dot을 표시합니다.
dot 크기는 표시 구간 안의 위치로 정해져 가장자리 쪽이 작아지고(전체 5페이지 이하면 모두 같은 크기), 선택된 dot 은 색으로 구분되며 변화는 애니메이션됩니다.

```kotlin
var currentPage by remember { mutableIntStateOf(0) }

WantedDotIndicator(
    totalPageCount = 10,
    visibleDotCount = 5,
    currentIndex = currentPage
)
```

### Parameters
| 이름 | 타입 | 설명 |
|:---|:---|:---|
| totalPageCount | Int | 전체 페이지 수입니다. |
| visibleDotCount | Int | 화면에 표시할 최대 dot 개수입니다. 전체 페이지가 5 이하면 이 값과 관계없이 모든 dot 을 표시합니다. |
| currentIndex | Int | 현재 선택된 페이지 인덱스입니다. |
| modifier | Modifier | 컴포넌트에 적용할 Modifier입니다. |
| size | WantedDotIndicatorSize | dot의 크기입니다. |
| type | WantedDotIndicatorType | dot의 스타일 타입입니다. |


## Advanced
### WantedPaginationDotDefaults
Pagination 컴포넌트에서 사용하는 설정값을 정의하는 객체입니다.


## Enum
### WantedDotIndicatorSize
| 값 | 설명 |
|:---|:---|
| Small | dot 크기 6dp(표시 구간 가장자리 쪽은 4·2dp 로 줄어듦)입니다. |
| Medium | dot 크기 10dp(표시 구간 가장자리 쪽은 8·6dp 로 줄어듦)입니다. |

### WantedDotIndicatorType
| 값 | 설명 |
|:---|:---|
| Normal | foregroundNeutralPrimary 색 dot 이며, dot 간격은 10dp 입니다. |
| White | 이미지 위에 쓰는 흰색 dot 이며, 1dp 테두리가 있고 dot 간격은 6dp 입니다. |
