## WantedScrollableTabRow
스크롤할 수 있는 Tab 레이아웃 컴포넌트입니다

좌우 그라디언트 효과, 우측 아이콘을 지원하며, 선택된 Tab은 하단 Indicator로 강조합니다.

```kotlin
var selectedIndex by remember { mutableIntStateOf(0) }

WantedScrollableTabRow(
    itemCount = 5,
    selectedTabIndex = selectedIndex,
    content = { index -> "탭$index" },
    onClickItem = { selectedIndex = it }
)
```

### Parameters
| 이름 | 타입 | 설명 |
|:---|:---|:---|
| itemCount | Int | 탭 항목 수입니다. |
| selectedTabIndex | Int | 현재 선택된 탭 인덱스입니다. |
| modifier | Modifier | 컴포넌트에 적용할 Modifier입니다. |
| disableIndexList | List<Int> | 비활성화할 탭 인덱스 리스트입니다. |
| tabSize | TabSize | 탭 크기 설정입니다. |
| horizontalPadding | Boolean | 양쪽 여백 적용 여부입니다. |
| isLeftGradient | Boolean | 왼쪽 gradient 표시 여부입니다. true 여도 왼쪽으로 더 스크롤할 수 있을 때만 표시됩니다. |
| isRightGradient | Boolean | 오른쪽 gradient 표시 여부입니다. true 여도 오른쪽으로 더 스크롤할 수 있을 때만 표시됩니다. |
| gradientColor | Color | gradient 색상입니다. |
| scrollState | ScrollState | 스크롤 상태를 관리하는 객체입니다. |
| onClickItem | (Int) -> Unit | 탭 클릭 시 호출되는 콜백입니다. |
| rightIcon | (@Composable (Dp) -> Unit)? | 탭 우측에 추가할 아이콘 슬롯입니다. 인자는 tabSize 에 맞춘 아이콘 슬롯 크기(Small 20dp, Medium 22dp, Large 24dp)이며, 아이콘 크기로 그대로 쓰면 됩니다. |
| content | (Int) -> String | 각 탭의 텍스트를 반환하는 함수입니다. |


## Advanced
### WantedTabItem
단일 Tab 항목을 구성하는 컴포넌트입니다.

선택 상태에 따라 텍스트 스타일이 변경되며, 클릭 이벤트를 처리합니다.

<details>
  <summary>Parameters</summary>

  | 이름 | 타입 | 설명 |
  |:---|:---|:---|
  | tabSize | TabSize | 탭의 텍스트 크기입니다. |
  | title | String | 탭에 표시할 텍스트입니다. |
  | active | Boolean | 선택 여부입니다. |
  | enable | Boolean | 활성화 여부입니다. |
  | modifier | Modifier | 컴포넌트에 적용할 Modifier입니다. |
  | onTextLayout | ((TextLayoutResult) -> Unit)? | 텍스트 레이아웃 결과를 전달하는 콜백입니다. |
  | onClick | () -> Unit | 클릭 시 호출되는 콜백입니다. clickOnce 를 쓰는 디자인 시스템 컴포넌트의 직전 클릭(다른 컴포넌트 포함)으로부터 200ms 안의 클릭은 무시됩니다. |

</details>
<br />
### WantedTabRow
고정형 Tab 레이아웃 컴포넌트입니다.

Tab 항목들이 전체 너비에 균등하게 배치되며, 선택된 Tab은 하단 Indicator로 강조합니다.

```kotlin
var selectedIndex by remember { mutableIntStateOf(0) }

WantedTabRow(
    itemSize = 3,
    modifier = Modifier.fillMaxWidth(),
    selectedTabIndex = selectedIndex,
    content = { index -> "탭$index" },
    onClickItem = { selectedIndex = it }
)
```

<details>
  <summary>Parameters</summary>

  | 이름 | 타입 | 설명 |
  |:---|:---|:---|
  | itemSize | Int | 탭 항목 수입니다. |
  | selectedTabIndex | Int | 현재 선택된 탭 인덱스입니다. |
  | modifier | Modifier | 컴포넌트에 적용할 Modifier입니다. 기본값이 없어 반드시 전달해야 합니다. |
  | tabSize | TabSize | 탭 텍스트 크기입니다. |
  | disableIndexList | List<Int> | 비활성화할 탭 인덱스 리스트입니다. |
  | onClickItem | (Int) -> Unit | 탭 클릭 시 호출되는 콜백입니다. |
  | content | (Int) -> String | 각 탭의 텍스트를 반환하는 함수입니다. |

</details>
<br />
### Modifier.tabIndicatorOffset
Tab 인디케이터를 선택된 Tab 의 위치·폭에 맞춰 하단에 배치하는 Modifier입니다. 위치와 폭이 바뀌면 250ms 동안 애니메이션으로 이동합니다.

<details>
  <summary>Parameters</summary>

  | 이름 | 타입 | 설명 |
  |:---|:---|:---|
  | currentTabPosition | TabPosition | 선택된 Tab 의 위치(left)와 폭(width)입니다. deprecated 인 ScrollableFlexTabRow 의 indicator 슬롯이 넘겨 주는 값을 그대로 사용합니다. WantedTabRow·WantedScrollableTabRow 에는 인디케이터 슬롯이 없어 이 Modifier 를 쓸 일이 없습니다. |

</details>
<br />
### WantedTabDefaults
Tab 컴포넌트에서 사용하는 설정값을 정의하는 객체입니다.


## Enum
### TabSize
| 값 | 설명 |
|:---|:---|
| Small | body2Bold 타이포를 씁니다. rightIcon 슬롯 크기는 20dp 입니다. |
| Medium | headline2Bold 타이포를 씁니다. rightIcon 슬롯 크기는 22dp 입니다. |
| Large | heading2Bold 타이포를 씁니다. rightIcon 슬롯 크기는 24dp 입니다. |
