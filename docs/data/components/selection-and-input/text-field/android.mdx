## WantedTextField
입력 필드 본체만 렌더링하는 Text field 컴포넌트입니다.
라벨·필수 표시(*)·하단 메시지는 포함하지 않습니다. 해당 요소가 필요하면
WantedFormControl 의 input 슬롯에 조합해서 사용합니다.
커서 위치와 선택 영역을 다루기 위해 TextFieldValue 로 값을 주고받습니다.

```kotlin
val state = remember { mutableStateOf(TextFieldValue("")) }

WantedFormControl(
    label = "이메일",
    required = true,
    description = "올바른 이메일 형식을 입력해 주세요."
) {
    WantedTextField(
        value = state.value,
        placeholder = "이메일을 입력해 주세요.",
        error = false,
        enabled = true,
        trailingButtonEnabled = true,
        complete = false,
        maxLines = 1,
        minLines = 1,
        maxWordCount = 2000,
        enabledOverflowText = false,
        interactionSource = remember { MutableInteractionSource() },
        keyboardOptions = KeyboardOptions.Default,
        keyboardActions = KeyboardActions.Default,
        onValueChange = { state.value = it }
    )
}
```

### Parameters
| 이름 | 타입 | 설명 |
|:---|:---|:---|
| value | TextFieldValue | 입력된 텍스트와 커서·선택 영역 상태를 포함한 값입니다. single line 이고 포커스가 없으면 넘치는 값은 말줄임(…) 처리됩니다. |
| placeholder | String | 값이 비어 있을 때 힌트로 표시될 문자열입니다. |
| error | Boolean | 에러(Negative) 상태 여부입니다. true 면 red ring 과 border 를 표시합니다. |
| enabled | Boolean | 입력 가능 여부입니다. |
| trailingButtonEnabled | Boolean | 우측 버튼 활성화 여부입니다. |
| complete | Boolean | 완료(Positive) 상태 여부입니다. 포커스가 없을 때 우측에 체크 아이콘을 표시합니다. |
| maxLines | Int | 텍스트 필드의 최대 줄 수입니다. minLines 와 함께 1 이면 single line 으로 동작합니다. (1 이상, minLines 이상) |
| minLines | Int | 텍스트 필드의 최소 줄 수입니다. (1 이상, maxLines 이하) |
| maxWordCount | Int | 허용되는 최대 글자 수입니다. |
| enabledOverflowText | Boolean | 최대 글자 수 초과 입력 허용 여부입니다. |
| interactionSource | MutableInteractionSource | 포커스 및 인터랙션 상태를 추적합니다. |
| keyboardOptions | KeyboardOptions | 키보드 동작 옵션입니다. |
| keyboardActions | KeyboardActions | 키보드 액션에 대한 핸들링입니다. |
| modifier | Modifier | 레이아웃 및 스타일을 설정합니다. |
| size | Size | 텍스트 필드의 크기입니다. (Large, Medium) |
| focused | State<Boolean> | 포커스 상태입니다. 기본값은 interactionSource 에서 수집합니다. |
| cursorBrush | Brush | 커서를 그릴 Brush 입니다. |
| background | Color | 텍스트 필드 배경 색상입니다. |
| visualTransformation | VisualTransformation | 텍스트 표시 방식을 변환합니다 (예: 비밀번호 마스킹). |
| trailingButton | String? | 우측 버튼에 표시될 텍스트입니다. null 또는 빈 문자열이면 버튼을 표시하지 않습니다. |
| trailingContent | (@Composable () -> Unit)? | 우측 아이콘과 버튼 사이에 들어갈 커스텀 콘텐츠 슬롯입니다. |
| leadingIcon | (@Composable () -> Unit)? | 좌측 아이콘 슬롯입니다. |
| trailingIcon | (@Composable () -> Unit)? | 우측 아이콘 슬롯입니다. 지정하지 않으면 포커스 상태에서 전체 삭제 아이콘이 표시됩니다. |
| onClickTrailingButton | () -> Unit | 우측 버튼 클릭 시 콜백입니다. |
| onValueChange | (TextFieldValue) -> Unit | 값 변경 시 콜백입니다. |
| focusRequester | FocusRequester | 포커스 요청에 사용하는 FocusRequester 입니다. |

title·requiredBadge·description 은 WantedFormControl 의 label·required·description 으로

```kotlin
) {
    WantedTextField(value = state.value, ..., onValueChange = { state.value = it })

```

## Advanced
### WantedTextFieldDefaults
TextField 컴포넌트에서 사용되는 설정 값을 정의하는 객체입니다.
선택 렌더링 방식과 선택 UI 스타일을 제어할 수 있는 enum 클래스를 포함합니다.


## Enum
### Status
| 값 | 설명 |
|:---|:---|
| Normal | 일반 상태입니다. |
| Positive | 긍정 상태입니다. |
| Negative | 부정 상태입니다. |

### Size
| 값 | 설명 |
|:---|:---|
| Large | 큰 크기입니다. (최소 높이 48dp) |
| Medium | 중간 크기입니다. (최소 높이 40dp) |
