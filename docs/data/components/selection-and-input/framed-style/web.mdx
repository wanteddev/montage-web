## Basic usage

Sx Prop 혹은 `css` 내부에서 사용 가능합니다.

<Demo code={`import { Box, framedStyle } from '@montage-ui/core';

const Demo = () => {
  return (
    <Box
      tabIndex={0}
      sx={framedStyle()}
    >
      <Placeholder />
    </Box>
  )
}

const Placeholder = () => {
  return (
    <Box
      sx={theme => ({
        width: 100,
        height: 40,
        backgroundColor: theme.semantic.surface.accent.violetOpaque,
        opacity: theme.opacity[8]
      })}
    />
  )
}

export default Demo;`}
/>

## Sizes

`small`, `medium(Default)`, `large`, `xlarge` 4개의 사이즈를 제공합니다.

사이즈에 따라 아래 속성들이 변경됩니다.
- `borderRadius`
- `padding`

<Demo code={`import { Box, framedStyle, FlexBox } from '@montage-ui/core';

## States

아래 옵션을 이용하여 다양한 상태를 표현할 수 있습니다.

- `selected`
- `status` (`normal` | `negative`)
- `disabled`

각 옵션은 서로 조합하여 사용할 수 있습니다. 예를 들어 `selected`와 `status: 'negative'`를 함께 지정하면 오류 상태의 선택 테두리가 표시됩니다.

<Demo code={`import { Box, framedStyle, FlexBox, Checkbox, Label } from '@montage-ui/core';
import { useState } from 'react';

const Demo = () => {
  const [selected, setSelected] = useState(true);
  const [negative, setNegative] = useState(false);
  const [disabled, setDisabled] = useState(false);

  return (
    <FlexBox flexDirection="column" gap={24} sx={{ width: '100%' }} justifyContent="center">
      <Box
        tabIndex={disabled ? -1 : 0}
        sx={[
          framedStyle({
            size: 'small',
            selected,
            status: negative ? 'negative' : 'normal',
            disabled
          }),
          {
            width: '100%',
          }
        ]}
      >
        <Placeholder />
      </Box>

      <FlexBox gap="16px" flexWrap="wrap">
        <FlexBox gap="8px">
          <Checkbox id="framed-style-selected" checked={selected} onCheckedChange={setSelected} />
          <Label htmlFor="framed-style-selected">selected</Label>
        </FlexBox>
        <FlexBox gap="8px">
          <Checkbox id="framed-style-negative" checked={negative} onCheckedChange={setNegative} />
          <Label htmlFor="framed-style-negative">status: negative</Label>
        </FlexBox>
        <FlexBox gap="8px">
          <Checkbox id="framed-style-disabled" checked={disabled} onCheckedChange={setDisabled} />
          <Label htmlFor="framed-style-disabled">disabled</Label>
        </FlexBox>
      </FlexBox>
    </FlexBox>
  )
}

const Placeholder = () => {
  return (
    <Box
      sx={theme => ({
        width: '100%',
        height: 60,
        backgroundColor: theme.semantic.surface.accent.violetOpaque,
        opacity: theme.opacity[8]
      })}
    />
  )
}

export default Demo;`}
/>

## Shadow

기본적으로 shadow는 적용되지 않습니다. `shadow` 옵션을 사용하여 시스템 컬러 토큰에 정의된 shadow를 추가할 수 있습니다.

<Demo code={`import { Box, framedStyle, FlexBox } from '@montage-ui/core';

const Demo = () => {
  return (
    <FlexBox flexWrap="wrap" gap={12} alignItems="center">
      <Box
        tabIndex={0}
        sx={framedStyle({
          shadow: 'semantic.elevation.shadow.normal.xsmall',
        })}
      >
        <Placeholder />
      </Box>
      <Box
        tabIndex={0}
        sx={framedStyle({
          shadow: 'semantic.elevation.shadow.normal.small',
        })}
      >
        <Placeholder />
      </Box>
      <Box
        tabIndex={0}
        sx={framedStyle({
          shadow: 'semantic.elevation.shadow.normal.medium',
        })}
      >
        <Placeholder />
      </Box>
      <Box
        tabIndex={0}
        sx={framedStyle({
          shadow: 'semantic.elevation.shadow.normal.large',
        })}
      >
        <Placeholder />
      </Box>
      <Box
        tabIndex={0}
        sx={framedStyle({
          shadow: 'semantic.elevation.shadow.normal.xlarge',
        })}
      >
        <Placeholder />
      </Box>
    </FlexBox>
  )
}

const Placeholder = () => {
  return (
    <Box
      sx={theme => ({
        width: 100,
        height: 40,
        backgroundColor: theme.semantic.surface.accent.violetOpaque,
        opacity: theme.opacity[8]
      })}
    />
  )
}

export default Demo;`}
/>
