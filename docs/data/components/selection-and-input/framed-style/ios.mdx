<summary>``enum Status``</summary>


프레임의 상태를 정의하는 열거형입니다.
- **Overview**

  각 상태마다 다른 테두리 색상과 스타일이 적용됩니다. 선택 여부는 상태와 별개로 `framedStyle(status:selected:borderRadius:shadowLevel:)`의 `selected`로 지정합니다.

<summary>``extension View``</summary>

<summary>``func framedStyle(status: FramedStyle.Status, selected: Bool, borderRadius: CGFloat, shadowLevel: Shadow.Level) -> some View``</summary>


현재 뷰에 프레임 스타일을 적용합니다.

- **Parameters**

  | Parameter | Description |
  | --- | --- |
  | `status` | 프레임 상태, 생략하면 기본값으로 `.normal` 적용 |
  | `selected` | 선택 여부, 생략하면 기본값으로 `false` 적용 |
  | `borderRadius` | 테두리 반경, 생략하면 기본값으로 `0` 적용 |
  | `shadowLevel` | 그림자 레벨, 생략하면 기본값으로 `.none` 적용 |

- **Return Value**

  프레임 스타일이 적용된 뷰
- **Discussion**

  선택되면 테두리 바깥에 4pt 링이 표시됩니다. 링 색은 `status`를 따르므로 `.negative`와 함께 쓰면 오류 상태의 선택으로 표시됩니다. 프레임에는 배경이 없어 뒤의 콘텐츠가 그대로 보입니다. 그림자는 기본으로 적용되지 않으며, `shadowLevel`을 지정하면 흰 배경과 함께 표시됩니다.
  > **Note**
  >
  > 비활성화는 SwiftUI 표준 `disabled(_:)`를 사용합니다. 상위 컨테이너에 한 번 걸면 하위 컴포넌트까지 함께 비활성 스타일로 표시됩니다.


  ```swift
  // 기본 사용법
  Text("입력 필드")
      .framedStyle()
  
  // 부정적 상태의 프레임 (오류 표시)
  Text("오류 메시지")
      .framedStyle(status: .negative)
  
  // 선택된 프레임
  Text("선택된 항목")
      .framedStyle(selected: true, borderRadius: 16)
  
  // 오류 상태에서 선택된 프레임
  Text("선택된 항목")
      .framedStyle(status: .negative, selected: true, borderRadius: 16)
  
  // 프레임에 그림자 적용
  Text("카드")
      .framedStyle(selected: isSelected, shadowLevel: .xsmall)
  
  // 비활성화된 프레임
  Text("비활성화된 항목")
      .framedStyle(selected: true)
      .disabled(true)
  ```
