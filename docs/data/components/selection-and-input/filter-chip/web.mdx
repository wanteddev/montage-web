## Basic filter chip

`ChipFilter` 는 2가지 variant를 사용할 수 있어요.
- solid (default)
- outlined

<Demo code={`import { FlexBox, ChipFilter } from '@wanteddev/wds';

const Demo = () => {
  return (
    <FlexBox gap="12px" flexDirection="column" alignItems="center">
      <ChipFilter variant="solid">
        Solid
      </ChipFilter>
      <ChipFilter variant="outlined">
        Outlined
      </ChipFilter>
    </FlexBox>
  );
}

export default Demo;`}
/>

## Sizes

4가지 크기를 지원해요.
- xsmall
- small
- medium (default)
- large

<Demo code={`import { ChipFilter, FlexBox } from '@wanteddev/wds';

const Demo = () => {
  return (
    <FlexBox gap="12px" flexDirection="column" alignItems="center">
      <FlexBox gap="12px" alignItems="center" flexWrap="wrap">
        <ChipFilter variant="solid" size="xsmall">
          Xsmall
        </ChipFilter>
        <ChipFilter variant="solid" size="small">
          Small
        </ChipFilter>
        <ChipFilter variant="solid" size="medium">
          Medium
        </ChipFilter>
        <ChipFilter variant="solid" size="large">

        </ChipFilter>

          Medium

        <ChipFilter variant="outlined" size="large">

export default Demo;`}
/>

## Active

`active` prop 을 사용하면 활성화된 상태를 표현할 수 있어요.

또한 `activeLabel` prop 을 사용하면 활성화된 필터의 개수를 표현할 수 있어요.

<Demo code={`import { ChipFilter, FlexBox } from '@wanteddev/wds';

const Demo = () => {
  return (
    <FlexBox gap="8px" alignItems="center" flexWrap="wrap">
      <ChipFilter variant="solid">직군</ChipFilter>
      <ChipFilter activeLabel={3} variant="solid" active>직무</ChipFilter>
      <ChipFilter variant="outlined">지역</ChipFilter>
      <ChipFilter activeLabel={2} variant="outlined" active>태그</ChipFilter>
    </FlexBox>
  )
}

export default Demo;`}
/>

## With popover

`Popover` 컴포넌트와 함께 사용하여 자연스럽게 열리고 닫힌 상태를 표현할 수 있어요.

혹은 `expanded` prop 을 사용하여 필터가 열린 상태를 표현할 수 있어요.

<Demo code={`import { ChipFilter, FlexBox, Popover, PopoverTrigger, PopoverContent } from '@wanteddev/wds';

const Demo = () => {
  return (
    <Popover>
		  <PopoverTrigger>
        <ChipFilter variant="solid" active>직군</ChipFilter>
			</PopoverTrigger>
			<PopoverContent>
				필터 콘텐츠
			</PopoverContent>
    </Popover>
  )
}

export default Demo;`}
/>
