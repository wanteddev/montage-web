## Basic select

`Select`는 여러 옵션 중 하나의 값을 선택할 수 있습니다.

<Demo code={`import { Select, Option, OptionGroup } from '@montage-ui/core';

const Demo = () => {
  return (
    <Select width="25ch" placeholder="선택해주세요.">
      {new Array(3).fill(0).map((_, i) => (
        <OptionGroup key={i} title={\`그룹 \${i + 1}\`}>
          {new Array(3).fill(0)
            .map((__, j) => (
              <Option key={j} value={\`값 \${i} \${j}\`}>
                {\`값 \${i} \${j}\`}
              </Option>
            ))
          }
        </OptionGroup>
      ))}
    </Select>
  )
}

export default Demo;`}
/>

## Anatomy

아래와 같은 구조로 조합하여 사용합니다.

```tsx
<Select>

  </OptionGroup>
  <OptionGroup>
    <Option value="2">옵션2</Option>
  </OptionGroup>
</Select>
```

### Render

`render` 옵션을 사용하여 텍스트 대신 `SelectRenderChip` 으로 렌더링 하거나 커스텀 텍스트를 작성할 수 있습니다.

onClick이 들어가는 경우 `e.stopPropagation()` 을 통해 메뉴가 열리고 닫히는 동작을 막을 수 있습니다.

<Demo code={`import { SelectRenderChip, SelectMultiple, Option, OptionGroup } from '@montage-ui/core';
import { useState, useRef } from 'react';

const Demo = () => {
  const [value, setValue] = useState(['값 1 0', '값 2 0', '값 0 2']);
  const ref = useRef(null);

  return (
    <SelectMultiple
      ref={ref}
      value={value}
      onChange={setValue}
      width="30ch"
      placeholder="선택해주세요."
      render={() => (
        value.map((v, i) => (
          <SelectRenderChip
            key={v}
            onClick={(e) => {
              e.stopPropagation();
              setValue(value.filter(data => data !== v))
              ref.current?.focus();
            }}
            status={i === 1 ? 'negative' : 'normal'}
            disabled={i === 0}
          >
            {v}
          </SelectRenderChip>
        ))
      )}
    >
      {new Array(3).fill(0).map((_, i) => (
        <OptionGroup key={i} title={\`그룹 \${i + 1}\`}>
          {new Array(3).fill(0)
            .map((__, j) => (
              <Option key={j} value={\`값 \${i} \${j}\`}>
                {\`값 \${i} \${j}\`}
              </Option>
            ))
          }
        </OptionGroup>
      ))}
    </SelectMultiple>
  )
}

export default Demo;`}
/>

### Overflow

`overflow` prop 으로 선택된 값이 필드 너비를 넘어갈 때의 동작을 지정합니다.

- `false` (default): 필드를 한 줄로 유지합니다. 텍스트는 말줄임, Chip은 가로 스크롤로 나머지 값을 탐색합니다.
- `true`: 값이 모두 보이도록 줄바꿈되며 필드의 높이가 늘어납니다.

`Select` 는 항상 하나의 값만 가지므로 `overflow` 를 제공하지 않습니다.

const Demo = () => {
  return (
    <FlexBox gap="12px" flexDirection="column" alignItems="center">
      <SelectMultiple defaultValue={OPTIONS} width="25ch" placeholder="Overflow false">

### With select content

`Select`, `SelectMultiple` 컴포넌트에 `leadingContent` prop 을 사용하여 요소의 앞쪽에 콘텐츠를 추가할 수 있습니다.

`size` 에 따라 사용법이 일부 다릅니다.
- IconButton의 size

          <SelectContent variant="icon">

        )}
      >

          <Option value="옵션1">옵션1</Option>

        size="medium"

        size="medium"

        leadingContent={(

        </OptionGroup>
      </SelectMultiple>

      <SelectMultiple
        size="medium"
        width="25ch"
        placeholder="Multiple, Icon, chip"
        ref={iconRef}
        value={iconValue}
        onChange={setIconValue}
        render={renderChips(iconValue, setIconValue, iconRef)}
        leadingContent={(
          <SelectContent variant="icon">
            <IconBlank />
          </SelectContent>
        )}
      >
        <OptionGroup title="그룹 1">
          <Option variant="checkbox" value="옵션1">옵션1</Option>
          <Option variant="checkbox" value="옵션2">옵션2</Option>
        </OptionGroup>
      </SelectMultiple>

      <SelectMultiple
        size="medium"
        width="25ch"
        placeholder="Multiple, Icon button, chip"
        ref={iconButtonRef}
        value={iconButtonValue}
        onChange={setIconButtonValue}
        render={renderChips(iconButtonValue, setIconButtonValue, iconButtonRef)}
        leadingContent={(
          <SelectContent variant="icon-button">

export default Demo;`}

## With action area

Action Area 영역을 추가할 수 있습니다.

Action Area 영역을 사용한다면 `enableMenuActionArea` prop 을 주어 `value` 와 `menuValue` 두 가지 상태로 관리할 수 있습니다.

- value: 실제 값
- menuValue: 메뉴에서 선택된 값

<Demo code={`import { Select, Option, OptionGroup, MenuActionArea, MenuActionAreaContent, Button } from '@montage-ui/core';
import { IconRefresh } from '@montage-ui/icon';
import { useState } from 'react';

const Demo = () => {
  const [value, setValue] = useState('');
  const [menuValue, setMenuValue] = useState('');
  const [open, setOpen] = useState(false);

  return (
    <Select
      enableMenuActionArea
      open={open}
      onOpenChange={setOpen}
      value={value}
      onChange={setValue}
      menuValue={menuValue}
      onMenuValueChange={setMenuValue}
      width="25ch"
      placeholder="선택해주세요."
    >
      {new Array(3).fill(0).map((_, i) => (
        <OptionGroup key={i} title={\`그룹 \${i + 1}\`}>
          {new Array(3).fill(0)
            .map((__, j) => (
              <Option key={j} value={\`값 \${i} \${j}\`}>
                {\`값 \${i} \${j}\`}
              </Option>
            ))
          }
        </OptionGroup>
      ))}

      <MenuActionArea
        leadingContent={
          <MenuActionAreaContent variant="button">
            <Button
              variant="outlined"
              color="assistive"
              iconOnly
              size="small"
              onClick={() => setMenuValue('')}
            >
              <IconRefresh />
            </Button> 
          </MenuActionAreaContent>
        }
        trailingContent={

            <Button size="small" onClick={() => {

              setOpen(false);
            }}>
              적용
            </Button>
          </MenuActionAreaContent>
        }
      />
    </Select>

export default Demo;`}

        name="selection"
        rules={{
          required: {
            value: true,
            message: "필수 값입니다.",
          },

        render={({ field, formState }) => (

                {...field}

            )}
          </FormControl>
        )}
