## Overview

스위치는 선택 상태를 표시하는 컴포넌트로, 체크박스와 유사한 기능을 제공합니다.

```swift
Switch(checked: true) { checked in
    print("스위치 선택 상태: \(checked)")
}

// 비활성화
Switch(checked: true)
    .disabled(true)
```

> **Note**
>
> 비활성화는 SwiftUI 표준 `disabled(_:)`를 사용합니다. 상위 컨테이너에 한 번 걸면 하위 컴포넌트까지 함께 비활성 스타일로 표시됩니다.
