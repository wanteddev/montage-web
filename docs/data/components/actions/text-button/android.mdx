## WantedTextButton
Text 형태의 버튼을 생성하는 Compose 함수입니다.

```kotlin
WantedTextButton(
    text = "확인",
    color = WantedTextButtonColor.PRIMARY,
    size = WantedTextButtonSize.MEDIUM,
    onClick = { /* 클릭 이벤트 처리 */ }
)
```

### Parameters
| 이름 | 타입 | 설명 |
|:---|:---|:---|
| text | String | 버튼에 표시할 텍스트입니다. 한 줄로 표시되며 넘치면 말줄임(…) 처리됩니다. |
| modifier | Modifier | 버튼 외형을 조정하는 Modifier입니다. |
| color | WantedTextButtonColor | 버튼의 색(PRIMARY, ASSISTIVE)을 지정합니다. |
| size | WantedTextButtonSize | 버튼의 크기(SMALL, MEDIUM)를 지정합니다. LARGE/XSMALL은 공식 미지원(레거시)입니다. |
| enabled | Boolean | 버튼의 활성화 여부를 지정합니다. |
| isLoading | Boolean | true 이면 텍스트·아이콘을 숨기고 로딩 인디케이터를 표시하며, 클릭 콜백을 호출하지 않습니다. |
| leadingDrawable | Int? | 버튼 왼쪽에 표시할 Drawable 리소스 ID입니다. |
| trailingDrawable | Int? | 버튼 오른쪽에 표시할 Drawable 리소스 ID입니다. |
| onClick | () -> Unit | 버튼 클릭 시 호출되는 콜백입니다. clickOnce 를 쓰는 디자인 시스템 컴포넌트의 직전 클릭(다른 컴포넌트 포함)으로부터 200ms 안의 클릭은 무시됩니다. |
| buttonDefault | WantedTextButtonDefault | 버튼의 기본 스타일 설정입니다. 넘기면 색·크기·타이포는 이 값만 쓰이고 color·size 인자는 무시되며, enabled 인자는 클릭 가능 여부에만 쓰입니다. 덮어 쓸 때는 WantedTextButtonDefaults.getDefault(color = …, size = …, enabled = …, contentColor = …) 처럼 축 값을 함께 넘깁니다. |


## Advanced
### WantedTextButtonDefault
WantedTextButton의 스타일을 정의한 데이터 클래스입니다.

SOLID/OUTLINED와 공유하던 `WantedButtonDefault`와 달리 배경·테두리처럼 Text Button에 없는 속성을 갖지 않으며,
폐기된 `ButtonVariant`에도 의존하지 않습니다.

  | size | WantedTextButtonSize | 버튼의 크기 축입니다. |
  | enabled | Boolean | 버튼의 활성화 여부입니다. |

### WantedTextButtonDefaults
`WantedTextButtonDefault`의 기본값을 제공하는 객체입니다.

Figma Text Button 컴포넌트가 정의한 `color` x `size` 축만으로 기본 스타일을 결정하고,
그 조합으로 표현되지 않는 색·타이포는 `contentColor` / `textStyle` 인자로 덮어 사용합니다.
(Figma의 customize 속성 = contentColor, typography)

### getDefault
`WantedTextButtonDefault`의 기본 설정을 생성합니다.

`enabled = false`일 때 텍스트·아이콘 색은 Figma 스펙상 고정이므로 호출부가 덮은 색보다 우선합니다.
덕분에 색을 덮는 호출부가 disabled 분기를 따로 들고 있지 않아도 됩니다.

```kotlin
val config = WantedTextButtonDefaults.getDefault(
    color = WantedTextButtonColor.ASSISTIVE,
    size = WantedTextButtonSize.SMALL
)
```

## Enum
### WantedTextButtonColor
| 값 | 설명 |
|:---|:---|
| PRIMARY | 브랜드 색(foregroundBrandPrimary)을 사용하는 기본 색입니다. |
| ASSISTIVE | 보조 색(foregroundNeutralTertiary)을 사용합니다. |

### WantedTextButtonSize
| 값 | 설명 |
|:---|:---|
| SMALL | 최소 높이 28dp · label1Bold 입니다. 아이콘만 있을 때 최소 폭은 32dp 입니다. |
| MEDIUM | 최소 높이 32dp · body1Bold 입니다. 아이콘만 있을 때 최소 폭은 40dp 입니다. |
| LARGE | 공식 미지원(레거시). 최소 높이 40dp · body1Bold 입니다. 아이콘만 있을 때 최소 폭은 48dp 입니다. |
| XSMALL | 공식 미지원(레거시). 최소 높이 28dp · label1Bold 이며, SMALL 과 아이콘 크기(14dp)·터치 영역 좌우 여백(8dp)·모서리(10dp)·아이콘 간격(5dp)·아이콘만 있을 때 최소 폭(28dp)이 다릅니다. |
