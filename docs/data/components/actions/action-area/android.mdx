## WantedActionArea
하단 액션 버튼 영역을 생성합니다.

버튼은 main, alternative, sub 텍스트로 생성하며, 각 버튼에 클릭 콜백을 전달할 수 있습니다.
또한, extra 슬롯으로 버튼 영역 위에 부가적인 요소를 렌더링할 수 있습니다.

```kotlin
WantedActionArea(
    type = ActionAreaType.Strong,
    main = "확인",
    onClickMain = { /* 처리 */ },
    alternative = "취소",
    onClickAlternative = { /* 처리 */ },
    sub = "건너뛰기",
    onClickSub = { /* 처리 */ }
)
```

### Parameters
| 이름 | 타입 | 설명 |
|:---|:---|:---|
| type | ActionAreaType | 액션 영역의 타입입니다. Cancel 이면 alternative·sub 가 표시되지 않습니다(값별 배치는 `ActionAreaType` 참고). |
| main | String | 메인 액션 버튼의 텍스트입니다. |
| modifier | Modifier | Modifier를 설정합니다. |
| isEnableMain | Boolean | 메인 액션 버튼의 활성화 여부입니다. |
| onClickMain | () -> Unit | 메인 액션 버튼 클릭 콜백입니다. clickOnce 를 쓰는 디자인 시스템 컴포넌트의 직전 클릭(다른 컴포넌트 포함)으로부터 200ms 안의 클릭은 무시됩니다. |
| alternative | String? | 대체 액션 버튼의 텍스트입니다. onClickAlternative 가 null 이면 버튼이 표시되지 않습니다. |
| isEnableAlternative | Boolean | 대체 액션 버튼의 활성화 여부입니다. |
| sub | String? | 보조 액션 버튼의 텍스트입니다. onClickSub 가 null 이면 버튼이 표시되지 않습니다. |
| isEnableSub | Boolean | 보조 액션 버튼의 활성화 여부입니다. |
| caption | String? | 버튼 바로 위(extra 가 있으면 extra 아래)에 표시할 캡션입니다. |
| captionIcon | Int? | 캡션 텍스트 앞에 표시할 아이콘 리소스입니다. 기본값은 아이콘 없음이며, 권장 아이콘은 `WantedActionAreaDefaults.CAPTION_ICON`입니다. |
| scrollableState | ScrollableState? | 위쪽 콘텐츠의 스크롤 상태입니다. 그라데이션은 background 가 true 이고 extra 가 없을 때만 그리며, 그 조건에서 이 값을 전달하면 아래로 더 스크롤할 내용이 있는 동안에만, null 이면 항상 표시합니다. |
| background | Boolean | true 이면 버튼 영역에 배경색을 칠하고, extra 가 없을 때 위쪽에 그라데이션을 겹쳐 그립니다(scrollableState 조건 참고). safeArea 도 true 이고 extra 가 없으면 버튼 영역의 상단 여백(20dp)을 없앱니다. extra 가 있으면 그라데이션은 그리지 않습니다. |
| safeArea | Boolean | true 이면 버튼 영역에 좌우·하단 20dp 와 상단 20dp(background 가 true 이고 extra 가 없으면 0) 여백을, extra 에 좌우 24dp 여백을 둡니다. false 이면 좌우·하단 여백을 빼고 상단은 extra 가 있을 때만 20dp 를 둡니다(extra 자체의 상단 20dp 는 항상 유지). 시스템 바 inset 은 적용하지 않으므로 호출부에서 처리합니다. |
| divider | Boolean | 구분선 표시 여부를 지정합니다. extra가 있을 때만 표시됩니다. |
| backgroundColor | Color | Extra·버튼 영역의 배경색이자 위쪽 그라데이션의 색상입니다. background 가 false 이고 extra 도 없으면 배경을 칠하지 않습니다. |
| onClickAlternative | (() -> Unit)? | 대체 액션 버튼 클릭 콜백입니다. null 이면 해당 버튼을 그리지 않습니다. clickOnce 를 쓰는 디자인 시스템 컴포넌트의 직전 클릭(다른 컴포넌트 포함)으로부터 200ms 안의 클릭은 무시됩니다. |
| onClickSub | (() -> Unit)? | 보조 액션 버튼 클릭 콜백입니다. null 이면 해당 버튼을 그리지 않습니다. clickOnce 를 쓰는 디자인 시스템 컴포넌트의 직전 클릭(다른 컴포넌트 포함)으로부터 200ms 안의 클릭은 무시됩니다. |
| extra | (@Composable () -> Unit)? | 추가적으로 표시할 컴포넌트입니다. |

## Overload
Slot을 활용하여 커스텀 버튼을 직접 전달할 수 있습니다.
버튼의 스타일 및 배치를 완전히 자유롭게 제어할 수 있습니다.

```kotlin
WantedActionArea(
    type = ActionAreaType.Strong,
    main = {
        WantedButton(text = "확인", modifier = Modifier.fillMaxWidth(), onClick = { /* 처리 */ })
    },
    alternative = {
        WantedButton(text = "취소", modifier = Modifier.fillMaxWidth(), variant = ButtonVariant.OUTLINED, onClick = { /* 처리 */ })
    }
)
```

## Advanced
### WantedActionAreaGradation
액션 영역 위쪽에 겹쳐 그리는 세로 그라데이션입니다. 위는 투명, 아래는 color 로 점점 진해집니다.

자기 자리보다 콘텐츠 높이만큼 위로 올려 배치하므로, 액션 영역 바로 위의 스크롤 콘텐츠가 자연스럽게 가려집니다. 높이는 modifier 로 지정합니다.

<details>
  <summary>Parameters</summary>

  | 이름 | 타입 | 설명 |
  |:---|:---|:---|
  | modifier | Modifier | 그라데이션 크기(특히 높이)를 지정하는 Modifier입니다. |
  | color | Color | 그라데이션이 닿는 아래쪽 색입니다. 보통 액션 영역의 배경색을 넘깁니다. |

</details>
<br />
### WantedActionAreaDefault
ActionArea에 필요한 버튼 기본 스타일을 정의한 데이터 클래스입니다.

각 버튼의 WantedButtonDefault를 개별적으로 설정할 수 있습니다.

이 설정을 받는 WantedActionArea(actionAreaDefault = …) 오버로드는 DeprecationLevel.ERROR 로 막혀 있습니다.
신규 코드는 WantedActionArea(type = …) 또는 Slot 오버로드를 사용합니다.

<details>
  <summary>Properties</summary>

  | 이름 | 타입 | 설명 |
  |:---|:---|:---|
  | type | ActionAreaType | 액션 영역 타입입니다. |
  | mainButtonDefault | WantedButtonDefault | 메인 액션 버튼 스타일을 설정합니다. |
  | alternativeButtonDefault | WantedButtonDefault | 대체 액션 버튼 스타일을 설정합니다. |
  | subButtonDefault | WantedButtonDefault | 보조 액션 버튼 스타일을 설정합니다. |

</details>
<br />
### WantedActionAreaDefaults
WantedActionAreaDefault의 기본값을 제공하는 객체입니다.

액션 영역 타입에 따라 적절한 버튼 스타일을 자동으로 설정합니다.

<details>
  <summary>Properties</summary>

  | 이름 | 타입 | 설명 |
  |:---|:---|:---|
  | CAPTION_ICON | Int | 캡션 아이콘을 사용할 때 권장되는 기본 아이콘(`@DrawableRes`)입니다. 캡션 아이콘은 기본적으로 표시되지 않으며, 아이콘이 필요할 때 `WantedActionArea` 의 `captionIcon` 에 이 값을 전달합니다. |

</details>
<br />
### getDefault
WantedActionAreaDefault의 기본 설정을 생성합니다.

액션 영역 타입에 따라 main, alternative, sub 버튼의 기본 스타일을 자동으로 설정합니다.
각 버튼의 스타일을 개별적으로 커스터마이징할 수도 있습니다.

이 설정을 받는 WantedActionArea(actionAreaDefault = …) 오버로드는 DeprecationLevel.ERROR 로 막혀 있습니다.
신규 코드는 WantedActionArea(type = …) 또는 Slot 오버로드를 사용합니다.

```kotlin
val config = WantedActionAreaDefaults.getDefault(
    type = ActionAreaType.Strong
)
```

  | subButtonDefault | WantedButtonDefault | 보조 액션 버튼의 기본 스타일입니다. 타입에 따라 자동 설정됩니다. |

## Enum
### ActionAreaType
| 값 | 설명 |
|:---|:---|
| Strong | 버튼을 세로로 쌓습니다(main → alternative → sub). 문자열 오버로드에서 sub 는 Text·Small 버튼입니다. |
| Neutral | 버튼을 한 줄에 가로로 배치합니다(sub → alternative → main). sub 는 내용 크기만큼, alternative 와 main 은 남은 폭을 똑같이 나눠 가집니다. |
| Cancel | main 버튼만 표시합니다. alternative·sub 를 넘겨도 표시되지 않으며, 문자열 오버로드의 main 은 Solid·Assistive 입니다. |
