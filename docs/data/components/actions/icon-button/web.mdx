## Basic icon button

아이콘을 버튼으로 사용할 때 활용합니다.

접근성을 위해 `aria-label` 속성을 필수로 작성하길 권장합니다.

<Demo code={`import { FlexBox, IconButton } from '@montage-ui/core';
import { IconBlank } from '@montage-ui/icon';

const Demo = () => {
  return (
    <FlexBox gap="12px" justifyContent="center">
      <IconButton variant="normal" aria-label="Basic icon button">
        <IconBlank />
      </IconButton>
    </FlexBox>
  )
}

export default Demo;`}
/>

## Variants

`IconButton` 은 4가지 variant 를 사용할 수 있습니다.
- normal (default)
- background
- outlined
- solid

<Demo code={`import { FlexBox, IconButton } from '@montage-ui/core';

## Alternative

`background` variant 를 사용할 때에는 `alternative` prop 으로 배경 색상을 다르게 표시할 수 있습니다.

`alternative` prop 을 사용하면 blur 효과가 적용되지 않는 환경에서도 자연스러운 스타일을 적용할 수 있습니다.

<Demo code={`import { FlexBox, IconButton } from '@montage-ui/core';
import { IconBlank } from '@montage-ui/icon';

const Demo = () => {
  return (
    <FlexBox gap="12px" justifyContent="center" alignItems="center">
      <IconButton variant="background" aria-label="Background icon button">
        <IconBlank />
      </IconButton>
      <IconButton variant="background" alternative aria-label="Alternative background icon button">
        <IconBlank />
      </IconButton>
    </FlexBox>
  )
}

export default Demo;`}
/>

## Interaction effect

`interactionEffect` prop 으로 hover / press 시 표시되는 인터랙션 효과를 선택할 수 있습니다.
- `normal` (default): `interactionColor` 로 채워진 인터랙션 레이어가 아이콘 뒤에 나타납니다.
- `dim`: 인터랙션 레이어를 숨기고, 아이콘 색상을 `interactionColor` 로 바꾸면서 투명도를 낮춥니다.
- `none`: 인터랙션 효과를 표시하지 않습니다.

`dim` 은 `normal` variant 에서만 동작합니다. 다른 variant 에서는 `normal` 과 동일하게 동작합니다.

<Demo code={`import { FlexBox, IconButton, Typography } from '@montage-ui/core';
import { IconBlank } from '@montage-ui/icon';

const Demo = () => {
  return (
    <FlexBox gap="12px" flexDirection="column" alignItems="center">
      <FlexBox gap="12px" alignItems="center">
        <Typography variant="body2-reading">Normal</Typography>
        <IconButton interactionEffect="normal" aria-label="Normal interaction effect icon button">
          <IconBlank />
        </IconButton>
      </FlexBox>

      <FlexBox gap="12px" alignItems="center">
        <Typography variant="body2-reading">Dim</Typography>
        <IconButton interactionEffect="dim" aria-label="Dim interaction effect icon button">
          <IconBlank />
        </IconButton>
      </FlexBox>

      <FlexBox gap="12px" alignItems="center">
        <Typography variant="body2-reading">None</Typography>
        <IconButton interactionEffect="none" aria-label="No interaction effect icon button">
          <IconBlank />
        </IconButton>
      </FlexBox>
    </FlexBox>
  )
}

export default Demo;`}
/>

### Interaction color

`interactionColor` prop 으로 인터랙션 색상을 변경할 수 있습니다. 기본값은 `semantic.foreground.neutral.primary` 입니다.

- `normal`: 인터랙션 레이어의 채움 색상으로 사용됩니다.
- `dim`: hover / press 시 아이콘 색상으로 사용됩니다.
- `none`: 무시됩니다.

<Demo code={`import { FlexBox, IconButton, Typography } from '@montage-ui/core';
import { IconBlank } from '@montage-ui/icon';

const Demo = () => {
  return (
    <FlexBox gap="12px" flexDirection="column" alignItems="center">
      <FlexBox gap="12px" alignItems="center">
        <Typography variant="body2-reading">Normal</Typography>
        <IconButton
          interactionEffect="normal"
          interactionColor="semantic.foreground.brand.primary"
          aria-label="Normal interaction effect icon button with brand interaction color"
        >
          <IconBlank />
        </IconButton>
      </FlexBox>

      <FlexBox gap="12px" alignItems="center">
        <Typography variant="body2-reading">Dim</Typography>
        <IconButton
          interactionEffect="dim"
          interactionColor="semantic.foreground.brand.primary"
          aria-label="Dim interaction effect icon button with brand interaction color"
        >
          <IconBlank />
        </IconButton>
      </FlexBox>
    </FlexBox>
  )
}

export default Demo;`}
/>

## Sizes

variant 별로 지원하는 size 가 다릅니다.

- normal
  - `xlarge` (default)
  - `large`
  - `medium`
  - `small`
- outlined, solid:
  - `medium` (default)
  - `small`
- background
  - 단일 사이즈(32x32) 고정. `number` 로만 박스 크기를 커스텀할 수 있습니다.

`size={number}` 는 모든 variant 에서 **박스(컨테이너) 크기** 를 의미합니다.

padding, `normal` variant 의 border-radius 는 가장 가까운 theme 토큰으로 자동 매핑됩니다.
WCAG 2.2 SC 2.5.8 Target Size 에 따라 박스 크기는 24x24 px 미만으로 줄지 않습니다.

## Legacy interaction layer

4.0.0 부터 `normal` variant 의 `size` 는 아이콘이 아닌 **박스(컨테이너) 크기** 를 의미합니다. 3.x 에서 `size={24}` 로 24px 아이콘을 렌더하던 코드는 4.0.0 에서 24px 박스 안의 16px 아이콘으로 렌더되고, 인터랙션 레이어가 레이아웃 공간을 차지하게 되어 주변 요소와의 간격도 달라집니다.

`useLegacyInteractionLayer` prop 을 사용하면 `normal` variant 에서 3.x 레이아웃을 유지할 수 있습니다.

- `size={number}` 는 기존처럼 **아이콘 크기** 로 적용되고, 박스도 아이콘과 같은 크기입니다.
- 문자열 `size` 는 해당 프리셋의 **아이콘 크기** 가 박스가 됩니다. (`xlarge` 24(기본값), `large` 20, `medium` 18, `small` 16)
- 인터랙션 레이어와 border-radius 는 현재 사이즈 정책을 따릅니다. 아이콘 크기에 대응하는 박스 크기(24 → 36, 20 → 32, 18 → 28, 16 → 24)와 radius 로 그려지되, 레이아웃에 영향을 주지 않고 아이콘 위에 겹쳐집니다.
- `normal` 이외의 variant 에서는 무시됩니다. `size` 가 원래부터 박스 크기였기 때문입니다.

새로 작성하는 코드에서는 사용하지 말고, 기존 화면의 레이아웃을 깨지 않고 마이그레이션할 때만 사용하세요.

아래 데모에서 점선은 버튼이 실제로 차지하는 레이아웃 영역입니다. 각 행의 왼쪽은 `useLegacyInteractionLayer` 를 켠 버튼, 오른쪽은 같은 `size` 의 기본 버튼입니다. hover 하면 레이아웃 바깥으로 그려지는 인터랙션 레이어를 확인할 수 있습니다.
