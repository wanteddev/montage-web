## WantedChip
사용자가 선택할 수 있는 Chip 컴포넌트를 생성합니다.
텍스트, 아이콘, 크기, 선택 여부(isActive)·사용 가능 여부(isEnable) 등의 다양한 설정을 지원합니다.

```kotlin
WantedChip(
    text = "텍스트",
    leadingContent = R.drawable.icon_normal_bookmark,
    trailingContent = R.drawable.icon_normal_bookmark,
    onClick = { /* 클릭 처리 */ }
)
```

### Parameters
| 이름 | 타입 | 설명 |
|:---|:---|:---|
| text | String | 표시할 텍스트입니다. 한 줄로 표시되며 넘치면 말줄임(…) 처리됩니다. |
| modifier | Modifier | Modifier를 통한 외형 스타일 지정입니다. |
| size | ChipSize | Chip의 크기를 설정합니다. |
| variant | ChipVariant | Chip의 스타일 변형입니다 (Solid, Outlined). |
| isActive | Boolean | 선택 여부 상태입니다. |
| isEnable | Boolean | 사용 가능 여부입니다. |
| leadingContent | Int? | 왼쪽에 표시할 아이콘 리소스 ID입니다. |
| trailingContent | Int? | 오른쪽에 표시할 아이콘 리소스 ID입니다. |
| interactionSource | MutableInteractionSource | 클릭 시의 상호작용 상태입니다. |
| onClick | (() -> Unit)? | 클릭 시 실행되는 콜백입니다. clickOnce 를 쓰는 디자인 시스템 컴포넌트의 직전 클릭(다른 컴포넌트 포함)으로부터 200ms 안의 클릭은 무시됩니다. |

## Overload
커스텀 스타일을 적용할 수 있는 Chip 컴포넌트를 생성합니다.
기본 스타일 외에 WantedChipDefault를 통한 직접 설정이 가능합니다.

```kotlin
WantedChip(
    text = "커스텀 텍스트",
    chipDefault = WantedChipDefaults.getDefault(isActive = true),
    onClick = { /* 클릭 처리 */ }
)
```
<details>
  <summary>Parameters</summary>


  | 이름 | 타입 | 설명 |
  |:---|:---|:---|
  | text | String | 표시할 텍스트입니다. 한 줄로 표시되며 넘치면 말줄임(…) 처리됩니다. |
  | modifier | Modifier | Modifier를 통한 스타일 지정입니다. |
  | leadingContent | Int? | 왼쪽 아이콘 리소스 ID입니다. |
  | trailingContent | Int? | 오른쪽 아이콘 리소스 ID입니다. |
  | chipDefault | WantedChipDefault | 직접 지정한 Chip 스타일입니다. |
  | interactionSource | MutableInteractionSource | 클릭 상호작용을 위한 상태 객체입니다. |
  | onClick | (() -> Unit)? | 클릭 시 실행될 콜백입니다. clickOnce 를 쓰는 디자인 시스템 컴포넌트의 직전 클릭(다른 컴포넌트 포함)으로부터 200ms 안의 클릭은 무시됩니다. |

좌우 아이콘과 텍스트 Content를 포함한 Chip Layout을 구성합니다.
직접 Chip 기본 스타일 및 구성요소를 입력할 수 있습니다.

```kotlin
WantedChip(
    content = { Text("Content") },
    leadingContent = { Icon(painter = painterResource(R.drawable.icon_normal_bookmark), contentDescription = null) },
    trailingContent = { Icon(painter = painterResource(R.drawable.icon_normal_close), contentDescription = null) }
)
```
<details>
  <summary>Parameters</summary>


  | 이름 | 타입 | 설명 |
  |:---|:---|:---|
  | modifier | Modifier | Modifier를 통한 외형 스타일 지정입니다. |
  | size | ChipSize | Chip 크기 설정입니다. 기본값은 Small 입니다. |
  | variant | ChipVariant | Chip 스타일 변형입니다. |
  | isActive | Boolean | 선택 여부 상태입니다. |
  | isEnable | Boolean | 사용 가능 여부입니다. |
  | chipDefault | WantedChipDefault | Chip 스타일 객체입니다. 넘기면 size·variant·isActive·isEnable 인자는 무시되고 이 값이 쓰입니다. |
  | interactionSource | MutableInteractionSource | 터치 인터랙션 제어용 객체입니다. |
  | content | (@Composable () -> Unit) | 텍스트 또는 기타 Composable 콘텐츠입니다. |
  | leadingContent | (@Composable (() -> Unit)?) | 좌측 아이콘 Composable입니다. |
  | trailingContent | (@Composable (() -> Unit)?) | 우측 아이콘 Composable입니다. |
  | onClick | (() -> Unit)? | 클릭 이벤트 콜백입니다. clickOnce 를 쓰는 디자인 시스템 컴포넌트의 직전 클릭(다른 컴포넌트 포함)으로부터 200ms 안의 클릭은 무시됩니다. |

</details>

## Advanced
### WantedChipContract
Chip에 대한 전반적인 계약(Contract)을 정의하는 객체입니다.

이 객체는 Chip의 시각적 변형 및 크기에 대한 enum 클래스를 포함합니다.

### WantedChipDefault
WantedChip의 기본 스타일을 정의하는 데이터 클래스입니다.
크기, 스타일 변형, 선택 여부(isActive), 사용 가능 여부(isEnable), 아이콘 색상, 배경 색상, 테두리 색상, 텍스트 스타일을 포함합니다.

```kotlin
val chipDefault = WantedChipDefault(
    size = ChipSize.Medium,
    variant = ChipVariant.Solid,
    isActive = true,
    isEnable = true,
    iconColor = Color.Black,
    backgroundColor = Color.White,
    borderColor = Color.Gray,
    textStyle = TextStyle.Default
)
```

<details>
  <summary>Properties</summary>

  | 이름 | 타입 | 설명 |
  |:---|:---|:---|
  | size | ChipSize | Chip의 크기를 설정합니다. |
  | variant | ChipVariant | Chip의 스타일 변형입니다 (Solid, Outlined). |
  | isActive | Boolean | 선택 여부 상태입니다. 이 객체를 직접 만들면 색은 iconColor·backgroundColor·borderColor·textStyle 값을 그대로 쓰며, 이 값은 Solid 의 눌림 효과(ripple) 색에만 영향을 줍니다. 상태에 맞는 색이 필요하면 WantedChipDefaults.getDefault 로 만듭니다. |
  | isEnable | Boolean | Chip의 사용 가능 여부입니다. |
  | iconColor | Color | 아이콘의 색상입니다. |
  | backgroundColor | Color | 배경 색상입니다. |
  | borderColor | Color | 테두리 색상입니다. |
  | textStyle | TextStyle | 텍스트 스타일입니다. |

</details>
<br />
### WantedChipDefaults
WantedChip의 기본 스타일을 제공하는 객체입니다.

### getDefault
기본 스타일에 맞춰 WantedChipDefault 객체를 생성합니다.
Compose 환경에 따라 Chip의 스타일을 동적으로 결정합니다.

```kotlin
val chipDefault = WantedChipDefaults.getDefault(
    size = ChipSize.Medium,
    variant = ChipVariant.Solid
)
```

<details>
  <summary>Parameters</summary>

  | isEnable | Boolean | 사용 가능 여부입니다. |
  | iconColor | Color | 아이콘의 색상입니다. |
  | backgroundColor | Color | 배경 색상입니다. |
  | borderColor | Color | 테두리 색상입니다. |

## Enum
### ChipVariant
| 값 | 설명 |
|:---|:---|
| Solid | 배경이 채워진 형태입니다. |
| Outlined | 테두리가 있는 형태입니다. 선택(isActive)되면 브랜드 색 5% 배경이 칠해집니다. |

### ChipSize
| 값 | 설명 |
|:---|:---|
| Large | 최소 높이 40dp, label1Medium 타이포입니다. |
| Medium | 최소 높이 36dp, label2Medium 타이포입니다. |
| Small | 최소 높이 32dp, caption1Medium 타이포입니다. |
| XSmall | 최소 높이 24dp, caption2Medium 타이포입니다. |
