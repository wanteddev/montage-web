## WantedSectionHeader
타이틀, 아이콘, 액션을 포함하는 Section header 컴포넌트입니다.

다양한 크기 옵션과 좌/우측 컴포넌트 삽입을 통해 유연하게 커스터마이징할 수 있습니다.
일반적으로 리스트, 섹션 구분, 콘텐츠 제목 등에 사용할 수 있습니다.

```kotlin
WantedSectionHeader(
    title = "제목",
    size = Size.Medium,
    headingContents = {
        Icon(painter = painterResource(R.drawable.icon_normal_circle_info), contentDescription = null)
    },
    trailingContent = {
        Icon(painter = painterResource(R.drawable.icon_normal_more_horizontal), contentDescription = null)
    },
    modifier = Modifier
)
```

### Parameters
| 이름 | 타입 | 설명 |
|:---|:---|:---|
| title | String | 섹션 제목으로 표시되는 텍스트입니다. headingContents 를 넣으면 title 은 1줄로 제한되고 넘치면 말줄임(…) 처리됩니다(없으면 줄 수 제한 없음). |
| modifier | Modifier | 외형, 정렬, 배치를 제어하는 Modifier입니다. 기본값이 없어 반드시 전달해야 합니다. |
| size | WantedSectionHeaderDefaults.Size | 헤더의 텍스트 스타일 크기를 결정합니다 (XSmall, Small, Medium, Large). |
| textStyle | TextStyle? | 커스텀 텍스트 스타일입니다. null 이면 size 에 맞는 스타일을 씁니다(색은 XSmall 이 foregroundNeutralTertiary, 그 외 foregroundNeutralStrong). 지정하면 size 는 무시되고 색도 이 스타일의 color 를 쓰므로, 색이 없는 스타일을 넘기면 LocalContentColor 로 그려집니다. |
| headingContents | (@Composable () -> Unit)? | 제목 오른쪽에 배치될 부가 정보 아이콘 등 컴포넌트 콘텐츠입니다. |
| trailingContent | (@Composable RowScope.() -> Unit)? | 오른쪽 끝에 배치되는 행동 버튼 또는 아이콘입니다. |


## Advanced
### WantedSectionHeaderDefaults
Section header 컴포넌트에 사용하는 설정값을 정의하는 객체입니다.

제목 타이포·색을 고르는 크기 정보를 제공합니다.


## Enum
### Size
| 값 | 설명 |
|:---|:---|
| XSmall | label1Bold, foregroundNeutralTertiary 색입니다. |
| Small | headline2Bold, foregroundNeutralStrong 색입니다. |
| Medium | heading2Bold, foregroundNeutralStrong 색입니다. |
| Large | title3Bold, foregroundNeutralStrong 색입니다. |
