## WantedListCard
썸네일과 설명 영역을 좌우로 배치한 가로형 카드 컴포넌트입니다.

로딩 상태(isLoading)에 따라 Skeleton 또는 실제 콘텐츠를 렌더링합니다.
상단/하단 커스텀 콘텐츠와 좌우 콘텐츠 Slot을 제공합니다.

```kotlin
WantedListCard(
    modifier = Modifier.fillMaxWidth(),
    title = "제목",
    caption = "캡션",
    extraCaption = "추가 설명",
    topContent = { WantedContentBadge(text = "상단") },
    bottomContent = { WantedContentBadge(text = "하단") },
    leadingContent = { WantedCheckBox(checkState = CheckBoxState.Checked, onCheckedChange = { }) },
    trailingContent = { Icon(painter = painterResource(R.drawable.icon_normal_bookmark), contentDescription = null) },
    onClick = { /* 클릭 처리 */ }
)
```

### Parameters
| 이름 | 타입 | 설명 |
|:---|:---|:---|
| modifier | Modifier | 카드 최외곽 노드에 적용됩니다. 배경·테두리는 이 노드 기준이고, 클릭·리플 영역은 이 노드보다 상하좌우 8dp 넓게 잡히므로 카드 사이 간격이 8dp 보다 좁으면 터치 영역이 겹칩니다. |
| title | String | 카드의 주요 제목입니다. 1줄까지 표시하고 넘치면 말줄임(…) 처리됩니다. |
| caption | String | 제목 아래에 표시될 보조 설명입니다. 1줄까지 표시하고 넘치면 말줄임(…) 처리됩니다. |
| extraCaption | String | 추가적인 설명 텍스트입니다. 1줄까지 표시하고 넘치면 말줄임(…) 처리됩니다. |
| isLoading | Boolean | true일 경우 스켈레톤 UI로 렌더링됩니다. thumbnail 을 넘기면 로딩 중에도 그 썸네일이 그대로 표시되고, leading/trailingContent 는 24dp 빈 자리로 바뀝니다. |
| cardDefault | WantedCardDefault | 스켈레톤 표시 여부와 카드 표면(배경색·모양·테두리·안쪽 여백) 설정을 담는 객체입니다. |
| thumbnail | (@Composable () -> Unit)? | 썸네일 이미지 영역입니다. null이면 기본 배경으로 표시됩니다. |
| topContent | (@Composable () -> Unit)? | 설명 위에 표시될 추가 콘텐츠입니다. |
| bottomContent | (@Composable () -> Unit)? | 설명 아래에 표시될 추가 콘텐츠입니다. |
| leadingContent | (@Composable () -> Unit)? | 썸네일 왼쪽에 표시될 콘텐츠입니다 (예: 체크박스). |
| trailingContent | (@Composable () -> Unit)? | 설명 오른쪽에 표시될 콘텐츠입니다 (예: 아이콘 버튼). |
| onClick | () -> Unit | 카드 클릭 시 호출되는 콜백 함수입니다. clickOnce 를 쓰는 디자인 시스템 컴포넌트의 직전 클릭(다른 컴포넌트 포함)으로부터 200ms 안의 클릭은 무시됩니다. |
