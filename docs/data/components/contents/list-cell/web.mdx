## Basic cell

인터랙션이 가능한 리스트 셀입니다.

<Demo code={`import { List, ListCell } from '@montage-ui/core';

const Demo = () => {
  return (
    <List sx={{ width: '80%' }}>
      <ListCell>
        Label
      </ListCell>
      <ListCell textProps={{ caption: 'Caption' }}>
        Label
      </ListCell>
    </List>
  )
}

export default Demo;`}
/>

## Anatomy

보통 List 컴포넌트와 함께 사용합니다.

```tsx
<List>
  <ListCell
    trailingContent={(
      <ListCellContent variant="value" chevron>
        Value
      </ListCellContent>
    )}
    leadingContent={(
      <ListCellContent variant="checkbox">
        <Checkbox />
      </ListCellContent>
    )}
  >
    Clickable list
  </ListCell>
</List>
```

## Variants

2가지 variant를 사용할 수 있습니다.

- inset (default)
- full

### Inset

좌/우측 padding이 없으며, 인터렉션 레이어만 바깥으로 넘어가서 노출됩니다.

<Demo code={`import { List, ListCell } from '@montage-ui/core';

const Demo = () => {
  return (
    <List sx={{ width: '80%' }}>
      <ListCell variant="inset">
        Inset variant cell
      </ListCell>

      <ListCell variant="inset" sx={theme => ({ border: \`1px solid \${theme.semantic.line.neutral.primary}\` })}>
        Inset variant cell
      </ListCell>
    </List>
  )
}

export default Demo;`}
/>

### Full

좌/우측 padding이 생기며, 인터렉션 레이어와 너비가 일치하도록 합니다.
또한 Border radius를 제거합니다.

<Demo code={`import { List, ListCell } from '@montage-ui/core';

const Demo = () => {
  return (
    <List sx={{ width: '80%' }}>
      <ListCell variant="full">
        Full variant cell
      </ListCell>

      <ListCell variant="full" sx={theme => ({ border: \`1px solid \${theme.semantic.line.neutral.primary}\` })}>
        Full variant cell
      </ListCell>
    </List>
  )
}

export default Demo;`}
/>


## States

여러 상태를 표시할 수 있습니다.
- default
- selected
- disabled

selected 상태일 때는 우측에 체크 아이콘이 기본으로 표시됩니다.
`trailingContent`를 직접 지정하면 교체되며, `null`을 전달하면 제거할 수 있습니다.

<Demo code={`import { List, ListCell } from '@montage-ui/core';

const Demo = () => {
  return (
    <List sx={{ width: '80%' }}>
      <ListCell>
        Default list cell
      </ListCell>
      <ListCell selected>
        Selected list cell
      </ListCell>
      <ListCell disabled>
        Disabled list cell
      </ListCell>
    </List>
  )
}

export default Demo;`}
/>


## Divider

`divider` 속성을 사용하여 셀 사이에 구분선을 추가할 수 있습니다.

인터렉션 효과가 발생할 때는 자동 숨김처리 됩니다.

<Demo code={`import { List, ListCell } from '@montage-ui/core';

const Demo = () => {
  return (
    <List sx={{ width: '80%' }}>
      <ListCell divider>
        Divider list cell
      </ListCell>
      <ListCell divider>
        Divider list cell
      </ListCell>
    </List>
  )
}

export default Demo;`}
/>


## Vertical padding

`verticalPadding` 속성을 사용하여 수직 간격을 조정할 수 있습니다.
- none
- small
- medium (default)
- large

`verticalPadding="none"` 일 때에는 인터렉션 영역이 비활성화됩니다.

<Demo code={`import { List, ListCell } from '@montage-ui/core';

const Demo = () => {
  return (
    <List sx={{ width: '80%' }}>
      <ListCell verticalPadding="none">
        VerticalPadding, None
      </ListCell>
      <ListCell>
        VerticalPadding, Medium (default)
      </ListCell>
      <ListCell verticalPadding="small">
        VerticalPadding, Small
      </ListCell>
      <ListCell verticalPadding="large">
        VerticalPadding, Large
      </ListCell>
    </List>
  )
}

export default Demo;`}
/>

## With content

leadingContent, trailingContent를 사용해서 콘텐츠를 추가할 수 있습니다.
콘텐츠를 추가할 때는 `ListCellContent`로 래핑해서 사용합니다.

Cell을 클릭했을 때 자동으로 leadingContent, trailingContent 내부의 컨트롤 요소를 클릭 처리합니다.
콘텐츠 영역이 클릭되지 않게 하려면 `e.stopPropagation` 을 사용해서 방지할 수 있습니다.
<br/>

> 단, `Switch` 컴포넌트는 클릭 처리하지 않습니다.

### Label trailing

`labelTrailing`을 사용해서 레이블 우측에 콘텐츠를 추가할 수 있습니다.
콘텐츠를 추가할 때는 `ListCellLabelTrailing`으로 래핑해서 사용합니다.

아래 variant들을 사용합니다.
- verified-check
- content-badge
- custom

<Demo code={`import { List, ListCell, ListCellLabelTrailing, ContentBadge } from '@montage-ui/core';

const Demo = () => {
  return (
    <List gap="16px" sx={{ width: '80%' }}>
      <ListCell
        textProps={{ caption: 'Caption' }}
        labelTrailing={
          <ListCellLabelTrailing variant="verified-check" />
        }
      >
        Label, with verified check
      </ListCell>
      <ListCell
        textProps={{ caption: 'Caption' }}
        labelTrailing={
          <ListCellLabelTrailing variant="content-badge">
            <ContentBadge color="neutral" size="small">Badge</ContentBadge>
          </ListCellLabelTrailing>
        }
      >
        Label, with content badge
      </ListCell>
    </List>
  )
}

export default Demo;`}
/>

## Text ellipsis

`ellipsis` 속성을 사용하여 Content가 넘치는 경우 말줄임표로 표시할 수 있습니다.

<Demo code={`import { List, ListCell, ListCellContent } from '@montage-ui/core';
import { IconBlank } from '@montage-ui/icon';

const TITLE = '동해물과 백두산이 마르고 닳도록 하느님이 보우하사 우리나라 만세 무궁화 삼천리 화려 강산 대한사람 대한으로 길이 보전하세.';
const CAPTION = '남산위에 저 소나무 철갑을 두른 듯 바람서리 불변함은 우리 기상일세 무궁화 삼천리 화려 강산 대한사람 대한으로 길이 보전하세.';

const Demo = () => {
  return (
    <List gap="16px" sx={{ width: '25ch' }}>
      <ListCell
        textProps={{ caption: CAPTION }}
        leadingContent={
          <ListCellContent variant="large-icon">
            <IconBlank />
          </ListCellContent>
        }
        trailingContent={
          <ListCellContent variant="value" chevron>
            값
          </ListCellContent>
        }
      >
        {TITLE}
      </ListCell>
      <ListCell
        ellipsis
        textProps={{ caption: CAPTION }}
        leadingContent={
          <ListCellContent variant="large-icon">
            <IconBlank />
          </ListCellContent>
        }
        trailingContent={
          <ListCellContent variant="value" chevron>
            값
          </ListCellContent>
        }
      >
        {TITLE}
      </ListCell>
    </List>
  )
}

export default Demo;`}
/>
