## WantedCard
기본 카드 컴포넌트로, 로딩 상태(isLoading)에 따라 Skeleton 또는 실제 콘텐츠를 렌더링합니다.

썸네일, 오버레이 캡션, 타이틀, 캡션, 서브 캡션, 추가 캡션, 상/하단 커스텀 콘텐츠를 지원합니다.

```kotlin
WantedCard(
    title = "제목",
    caption = "캡션",
    overlayCaption = "Overlay",
    overlayToggleIcon = {
        Icon(painter = painterResource(id = R.drawable.icon_normal_bookmark), contentDescription = null)
    },
    onClick = { /* 클릭 이벤트 */ }
)
```

### Parameters
| 이름 | 타입 | 설명 |
|:---|:---|:---|
| modifier | Modifier | 카드 최외곽 노드에 적용됩니다. 배경·테두리는 이 노드 기준이고, 클릭·리플 영역은 이 노드보다 상하좌우 8dp 넓게 잡히므로 카드 사이 간격이 8dp 보다 좁으면 터치 영역이 겹칩니다. |
| thumbnail | (@Composable () -> Unit) | 썸네일 이미지 영역입니다. |
| overlayCaption | String | 썸네일 위에 오버레이로 표시할 텍스트입니다. 1줄까지 표시하고 넘치면 말줄임(…) 처리됩니다. |
| title | String | 카드 타이틀 텍스트입니다. 최대 2줄까지 표시하고 넘치면 말줄임(…) 처리됩니다. |
| caption | String | 보조 캡션 텍스트입니다. 1줄까지 표시하고 넘치면 말줄임(…) 처리됩니다. |
| subCaption | String | 추가 보조 캡션 텍스트입니다. 1줄까지 표시하고 넘치면 말줄임(…) 처리됩니다. |
| extraCaption | String | 하단 추가 설명 텍스트입니다. 1줄까지 표시하고 넘치면 말줄임(…) 처리됩니다. |
| isLoading | Boolean | 로딩 상태 여부입니다. true이면 skeleton UI가 렌더링됩니다. |
| cardDefault | WantedCardDefault | 스켈레톤 표시 여부와 카드 표면(배경색·모양·테두리·안쪽 여백) 설정을 담는 객체입니다. |
| overlayToggleIcon | (@Composable () -> Unit)? | 썸네일 오버레이에 포함될 토글 아이콘입니다. |
| topContent | (@Composable () -> Unit)? | 카드 상단 타이틀 위에 추가 표시할 컴포넌트입니다. |
| bottomContent | (@Composable () -> Unit)? | 카드 하단에 추가 표시할 컴포넌트입니다. |
| onClick | (() -> Unit)? | 카드 전체 클릭 시 호출되는 콜백입니다. null일 경우 클릭이 비활성화됩니다. clickOnce 를 쓰는 디자인 시스템 컴포넌트의 직전 클릭(다른 컴포넌트 포함)으로부터 200ms 안의 클릭은 무시됩니다. |


## Advanced
### WantedCardDefault
카드의 표시 스펙을 지정하는 데이터 클래스입니다.

스켈레톤 표시 여부와 카드 표면(배경·모양·여백) 설정을 함께 담습니다.

<details>
  <summary>Properties</summary>

  | 이름 | 타입 | 설명 |
  |:---|:---|:---|
  | topContentSkeleton | Boolean | 상단 콘텐츠 영역에 스켈레톤을 표시할지 여부입니다. |
  | captionSkeleton | Boolean | 메인 캡션에 스켈레톤을 표시할지 여부입니다. |
  | extraCaptionSkeleton | Boolean | 추가 캡션에 스켈레톤을 표시할지 여부입니다. |
  | bottomContentSkeleton | Boolean | 하단 콘텐츠 영역에 스켈레톤을 표시할지 여부입니다. |
  | ratio | Float | 썸네일 자리 비율입니다. WantedCard 는 로딩 스켈레톤 썸네일에, WantedListCard 는 thumbnail 이 null 일 때의 기본 배경 박스(높이 64dp)에 적용합니다. WantedListCard 로딩 스켈레톤은 이 값을 무시하고 4:3 을 씁니다. |
  | backgroundColor | Color | 카드 표면 배경색입니다. 기본값 Transparent 는 배경을 그리지 않는 것과 같습니다. |
  | shape | Shape | 배경 모양입니다. |
  | border | BorderStroke? | 카드 표면 테두리입니다. null 이면 테두리를 그리지 않습니다. 배경 위에 그려지므로 modifier 에 직접 border 를 주면 배경에 가려집니다. |
  | interactionShape | Shape | 클릭·리플 모양입니다. WantedListCard 에만 적용되며, WantedCard 는 고유 모양(상단 20dp·하단 12dp)을 써서 이 값을 무시합니다. |
  | contentPadding | PaddingValues | 카드 표면 안쪽 여백입니다. modifier 의 padding 은 표면 바깥 여백이 되므로(8dp 보다 좁으면 넘치는 클릭 영역 안에 들어감) 안쪽 여백은 이 값으로 줍니다. |

</details>

### WantedCardDefaults
WantedCard·WantedListCard 에 넘길 WantedCardDefault 를 만드는 기본값 함수를 제공하는 객체입니다.

### getDefault
기본 스켈레톤 설정값을 반환하는 Compose 함수입니다.

각 항목에 대해 스켈레톤 UI 표시 여부를 설정할 수 있습니다.

```kotlin
val config = WantedCardDefaults.getDefault(
    topContentSkeleton = true,
    bottomContentSkeleton = true
)
```
