## WantedAvatar
사용자, 회사, 학력 등 다양한 유형의 아바타를 표시하는 컴포넌트입니다.

이미지, 아이콘, 그룹 아바타, 알림 뱃지 등 다양한 스타일을 지원합니다.
클릭 이벤트 및 플레이스 홀더 이미지를 설정할 수 있습니다.

```kotlin
WantedAvatar(
    modifier = Modifier,
    model = R.drawable.icon_normal_person_fill,
    placeHolder = R.drawable.icon_normal_person_fill,
    size = WantedAvatarSize.Medium,
    type = WantedAvatarType.Person,
    isDrawableRes = true,
    pushBadge = true,
    onClick = { /* 클릭 동작 */ }
)
```

### Parameters
| 이름 | 타입 | 설명 |
|:---|:---|:---|
| type | WantedAvatarType | 아바타의 유형(Person, Company, Academy)을 지정합니다. Person 은 원형이고 Company·Academy 는 size 의 코너 반경을 가진 둥근 사각형입니다. |
| modifier | Modifier | 아바타의 크기, 외형, 배치를 조정하는 Modifier입니다. |
| size | WantedAvatarSize | 아바타의 크기와 코너 반경을 결정합니다. Person 은 항상 원형이라 코너 반경이 적용되지 않습니다. 기본값은 Small입니다. |
| model | Any? | 표시할 이미지 모델입니다 (URL 또는 Drawable ID). |
| placeHolder | Int? | 이미지가 없을 때와 로딩 중·로딩 실패 시 표시할 이미지 리소스 ID입니다. 지정하면 그 리소스를 아바타 전체 크기에 원본 색 그대로 그립니다. null이면 type별 기본 placeholder(backgroundNeutralPrimary 배경 위에 아이콘 실루엣이 뚫린 surfaceNeutralStrong 면, 그 위에 아바타 한 변의 2/3 크기로 줄인 28% 투명도 흰색 글리프)가 대신 노출됩니다. model 이 Drawable 리소스 ID(isDrawableRes = true)이면 placeholder 를 쓰지 않습니다. |
| isDrawableRes | Boolean | model이 Drawable 리소스 ID일 경우 true로 설정합니다. |
| isGroup | Boolean | 그룹 아바타 스타일을 적용할지 여부를 설정합니다. |
| pushBadge | Boolean | 아바타에 푸시 알림 뱃지를 표시할지 여부를 설정합니다. |
| borderColor | Color | 그룹 겹침 분리 테두리(1.5dp) 색상입니다. isGroup = true 일 때만 그려지며, 기본값은 backgroundNeutralPrimary 입니다. |
| alignment | Alignment | 이미지의 정렬 방식입니다. URL 등 Glide 로 불러오는 이미지에만 적용되고, Drawable 리소스(isDrawableRes = true)에는 적용되지 않습니다. |
| contentScale | ContentScale | 이미지의 크기 조정 방식입니다. URL 등 Glide 로 불러오는 이미지에만 적용되고, Drawable 리소스(isDrawableRes = true)에는 적용되지 않습니다. |
| contentDescription | String? | 접근성 콘텐츠 설명입니다. 기본값은 null입니다. |
| onClick | (() -> Unit)? | 아바타 클릭 시 호출될 콜백 함수입니다. 넘기면 클릭·리플 영역이 아바타보다 상하좌우 8dp 넓게 잡힙니다. clickOnce 를 쓰는 디자인 시스템 컴포넌트의 직전 클릭(다른 컴포넌트 포함)으로부터 200ms 안의 클릭은 무시됩니다. |


## Advanced
### WantedAvatarDefaults
Avatar에 사용되는 크기와 유형 관련 설정을 정의하는 객체입니다.

다양한 사이즈와 타입을 설정하여 아바타 UI 요소를 유연하게 구성할 수 있도록 지원합니다.

<details>
  <summary>Properties</summary>

  | 이름 | 타입 | 설명 |
  |:---|:---|:---|
  | MAX_GROUP_VISIBLE_COUNT | Int | WantedAvatarGroup이 한 번에 표시하는 최대 아바타 수입니다. 초과 인원은 렌더링하지 않으므로 호출부가 `trailingContent`로 처리합니다(예: "외 N명"). |

</details>

## Enum
### WantedAvatarType
| 값 | 설명 |
|:---|:---|
| Person | 사람(개인)입니다. |
| Company | 회사입니다. |
| Academy | 학력/학교입니다. |

## Sealed Class
### WantedAvatarSize
Avatar의 크기 및 모서리 반경 정보를 포함하는 sealed 클래스입니다.

각 사이즈는 data object로 구체화되어 있으며, 아바타의 가로/세로 크기와 모서리 반경이 함께 정의됩니다.

| 값 | 설명 |
|:---|:---|
| XSmall | 24dp 크기, 8dp 모서리 반경의 가장 작은 아바타 크기입니다. |
| Small | 32dp 크기, 10dp 모서리 반경의 작은 아바타 크기입니다. |
| Medium | 40dp 크기, 12dp 모서리 반경의 중간 아바타 크기입니다. |
| Large | 48dp 크기, 14dp 모서리 반경의 큰 아바타 크기입니다. |
| XLarge | 56dp 크기, 16dp 모서리 반경의 가장 큰 아바타 크기입니다. |
| Custom | 크기, 모서리 반경, 뱃지 크기를 커스텀 할 수 있는 아바타 크기입니다. cornerRadius를 지정하지 않으면 `ceil((size × 0.25) / 2) × 2 + 2` 공식으로 계산합니다. |
