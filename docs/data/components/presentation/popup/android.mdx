## WantedPopup
상단 앱바와 Main Action 버튼을 포함한 기본 Popup 컴포넌트입니다.

```kotlin
var showModal by remember { mutableStateOf(true) }

if (showModal) {
    WantedPopup(
        title = "제목",
        positive = "확인",
        onClickPositive = { showModal = false },
        onDismissRequest = { showModal = false },
        content = { Text("내용") }
    )
}
```

### Parameters
| 이름 | 타입 | 설명 |
|:---|:---|:---|
| onDismissRequest | () -> Unit | 모달 외부 클릭 등으로 닫힐 때 호출되는 콜백입니다. |
| modifier | Modifier | 컴포넌트에 적용할 Modifier입니다. |
| resize | Resize | Popup 의 높이 결정 방식입니다. 기본값은 Hug 입니다. |
| properties | DialogProperties | Dialog 속성입니다. |
| popupDefault | WantedPopupDefault | Popup 의 모양·여백 설정입니다. |
| title | String? | Navigation 의 제목입니다. null 이면 제목 없이 Close Button 만 노출합니다. Close Button 은 `onDismissRequest` 로 Popup 을 닫습니다. |
| positive | String? | Main Action 의 텍스트입니다. onClickPositive 를 함께 넘겨야 Main Action 이 표시됩니다. |
| onClickPositive | (() -> Unit)? | Main Action 클릭 시 호출되는 콜백입니다. null 이면 Main Action 을 표시하지 않습니다. |
| content | (@Composable BoxScope.() -> Unit) | 본문 콘텐츠 슬롯입니다. |

## Overload
커스텀 하단 바를 포함한 모달 컴포넌트입니다.

Main Action 버튼 대신 커스텀 bottomBar를 사용할 수 있습니다.

```kotlin
var showModal by remember { mutableStateOf(true) }

if (showModal) {
    WantedPopup(
        topBar = { WantedDialogTopAppBar(title = "제목", variant = WantedDialogTopAppBarContract.Variant.Emphasized) },
        bottomBar = {
            Button(onClick = { showModal = false }) {
                Text("닫기")
            }
        },
        onDismissRequest = { showModal = false },
        content = { Text("내용") }
    )
}
```

LazyColumn 기반의 스크롤 가능한 모달 컴포넌트입니다.

많은 양의 콘텐츠를 스크롤하여 표시할 수 있습니다.

```kotlin
var showModal by remember { mutableStateOf(true) }

if (showModal) {
    WantedPopup(
        topBar = { WantedDialogTopAppBar(title = "제목", variant = WantedDialogTopAppBarContract.Variant.Emphasized) },
        onDismissRequest = { showModal = false },
        lazyContent = {
            items(20) { index ->
                Text("아이템 $index")
            }
        }
    )
}
```

## Advanced
### WantedPopupContract
Popup 컴포넌트에서 사용하는 설정값을 정의하는 객체입니다.

### WantedPopupDefault
Popup 의 모양과 여백을 정의하는 데이터 클래스입니다.

값을 바꿔 쓸 때는 `WantedPopupDefaults.getDefault` 의 인자로 넘기거나 `copy` 를 사용합니다.

Popup 의 여백은 디자인 4.0.0 기준으로 ModalSize 와 무관하게 통일되어 있고,
모바일 Popup 은 Medium 한 가지만 사용하므로 `width` 도 하나로 고정입니다.

<details>
  <summary>Properties</summary>

  | 이름 | 타입 | 설명 |
  |:---|:---|:---|
  | shape | RoundedCornerShape | Popup 의 모서리 둥글기입니다. |
  | width | Dp | Popup 의 최대 너비입니다. 실제 너비는 Dialog 창 너비로 한 번 더 제한되므로, 폰에서는 창 너비를 그대로 따르고 큰 화면에서만 이 값으로 잘립니다. |
  | navigationPadding | Dp | Navigation 영역에 Popup 이 추가로 얹는 여백입니다. 여백 자체는 Navigation 컴포넌트가 소유하므로 기본값은 0dp 입니다. |
  | contentHorizontalPadding | Dp | Content 영역의 좌우 여백입니다. |
  | contentVerticalPadding | Dp | Content 영역의 상하 여백입니다. |
  | actionHorizontalPadding | Dp | Action Area 의 좌우 여백입니다. |
  | actionVerticalPadding | Dp | Action Area 의 상하 여백입니다. |
  | actionBottomPadding | Dp | Action Area 하단에 추가로 붙는 여백입니다. |
  | actionAreaType | ActionAreaType | Action Area 의 타입입니다. |

</details>

### WantedPopupDefaults
`WantedPopupDefault` 의 기본값을 제공하는 객체입니다.

### getDefault
Popup 의 기본 설정을 생성합니다.

```kotlin
// 본문 좌우 여백만 없애고 나머지는 기본값을 쓴다
WantedPopup(
    onDismissRequest = { },
    popupDefault = WantedPopupDefaults.getDefault(contentHorizontalPadding = 0.dp),
    content = { }
)
```

## Enum
### ModalSize
| 값 | 설명 |
|:---|:---|
| Small | (Deprecated) 콘텐츠 여백 20dp, 하단 영역 여백 16dp 입니다. Medium 을 사용합니다. |
| Medium | 콘텐츠 여백 20dp, 하단 영역 여백 20dp, 제목 상하 여백 4dp 입니다. |
| Large | 콘텐츠 여백 24dp, 하단 영역 여백 24dp, 제목 상하 여백 4dp 입니다. |
| XLarge | 콘텐츠 여백 32dp, 하단 영역 여백 32dp, 제목 상하 8dp·좌우 4dp 여백입니다. |
| Custom | 커스텀 크기의 Modal 입니다. 모든 패딩이 0dp로 설정되어 사용자가 직접 정의 할 수 있습니다. |

## Sealed Class
### Resize
Popup 의 높이 결정 방식을 정의하는 sealed 클래스입니다.
Hug, Fixed 두 가지를 제공합니다.

| 값 | 설명 |
|:---|:---|
| Hug | 콘텐츠 높이에 맞춰 Popup 높이가 결정됩니다. 기본값입니다. 최대 높이는 화면 높이에서 상단 inset 과 하단 여백을 뺀 값이며, 760dp 를 넘지 않습니다. |
| Fixed | height 로 지정한 높이로 Popup 높이가 고정됩니다. 최대 760dp 로 제한됩니다. |


### ModalType
Modal의 형태를 정의하는 sealed 클래스입니다.
Flexible, FixedWrapContent, Fixed, FixedFullScreen, FixedRatio 형태를 제공합니다.

| 값 | 설명 |
|:---|:---|
| Flexible | 콘텐츠 크기에 따라 자동으로 조정되는 유동형 Modal 입니다. 항상 시스템 BottomSheet 로 그려지고 닫을 수 있습니다. 부분 펼침(중간 높이)을 허용하지만, 콘텐츠가 충분히 높을 때만 그 상태가 생기며 짧은 콘텐츠는 바로 펼쳐진(Expanded) 상태로 표시됩니다. |
| FixedWrapContent | 콘텐츠 높이에 맞게 조정되는 고정형 Modal 입니다. 기본은 커스텀 시트(isSystemBottomSheet = false)입니다. isCloseable(기본 true)이 false 면 드래그 핸들을 숨기고, 시스템 시트에서는 스와이프·바깥 탭으로 닫히지 않습니다. 뒤로가기는 시스템·커스텀 시트 모두 onDismissRequest 를 호출하고(커스텀 시트는 바깥 탭(dismissOnClickOutside)도 호출), 실제로 닫을지는 호출부가 표시 상태로 정합니다. |
| Fixed | height 로 지정한 높이를 갖는 고정형 Modal 입니다. 기본은 커스텀 시트(isSystemBottomSheet = false)입니다. isCloseable(기본 true)이 false 면 드래그 핸들을 숨기고, 시스템 시트에서는 스와이프·바깥 탭으로 닫히지 않습니다. 뒤로가기는 시스템·커스텀 시트 모두 onDismissRequest 를 호출하고(커스텀 시트는 바깥 탭(dismissOnClickOutside)도 호출), 실제로 닫을지는 호출부가 표시 상태로 정합니다. |
| FixedFullScreen | 화면 전체를 덮는 고정형 Modal 입니다. 기본은 커스텀 시트(isSystemBottomSheet = false)입니다. isCloseable(기본 true)이 false 면 드래그 핸들을 숨기고, 시스템 시트에서는 스와이프·바깥 탭으로 닫히지 않습니다. 뒤로가기는 시스템·커스텀 시트 모두 onDismissRequest 를 호출하고(커스텀 시트는 바깥 탭(dismissOnClickOutside)도 호출), 실제로 닫을지는 호출부가 표시 상태로 정합니다. |
| FixedRatio | 화면 높이 × ratio(0.0 ~ 1.0)로 높이가 정해지는 고정형 Modal입니다. 다만 화면 높이에서 상단 inset·10dp·드래그 핸들(19dp)을 뺀 값을 넘지 않으므로 ratio 가 1f 여도 화면 전체 높이가 되지 않습니다. 기본은 커스텀 시트(isSystemBottomSheet = false)입니다. isCloseable(기본 true)이 false 면 드래그 핸들을 숨기고, 시스템 시트에서는 스와이프·바깥 탭으로 닫히지 않습니다. 뒤로가기는 시스템·커스텀 시트 모두 onDismissRequest 를 호출하고(커스텀 시트는 바깥 탭(dismissOnClickOutside)도 호출), 실제로 닫을지는 호출부가 표시 상태로 정합니다. |
