## Basic Bottom sheet

Bottom sheet를 표시합니다.

breakpoint에 따라 variant를 override 하여 [Popup](/components/presentation/popup/web) 과 쉽게 통합할 수 있습니다.

<Demo code={`import {
  Button,
  Modal,
  ActionArea,

  ModalHeading,

  ModalSummary,
  ModalTrigger,
} from '@montage-ui/core';

const Demo = () => {
  return (
    <Modal>
      <ModalTrigger>
        <Button>Open</Button>
      </ModalTrigger>

      <ModalContainer variant="bottom">
        <ModalContent>

            Main action

export default Demo;`}
/>

## Anatomy

Bottom sheet 는 여러 컴포넌트를 조합해서 사용합니다.

`ModalTrigger`, `ModalNavigation` 은 선택적으로 사용할 수 있습니다.

기본 구성은 아래와 같습니다.

```tsx
<Modal>
  <ModalTrigger>
    <Button />
  </ModalTrigger>

  <ModalContainer>
    <ModalNavigation />

    <ModalContent>
      <ModalContentItem>
        <ModalHeading />
        <ModalSummary />
        <ModalDescription />
      </ModalContentItem>
    </ModalContent>

    <ActionArea>
      <ActionAreaButton />
    </ActionArea>
  </ModalContainer>
</Modal>
```

## Resize

resize 옵션을 사용하면 Bottom sheet가 차지하는 높이를 조정할 수 있습니다.

- `hug` (default) — 컨텐츠 크기에 맞춥니다.
- `fixed` — `size` 별 고정 높이를 사용합니다.
- `fill` — 화면이 허용하는 최대 높이까지 시트를 채웁니다.
- `flexible` — 최대 높이의 절반(half)만 노출되며, 위로 끌어올리면 최대 높이(full)까지 확장됩니다. [Flexible usage](#Flexible snap)

### Flexible

`resize="flexible"` 옵션은 처음에는 최대 높이의 50%(`half`)만 노출되었다가, 핸들을 위로 끌어올리거나 시트 내부에서 위로 스와이프하면 최대 높이(`full`)까지 확장되는 동작을 제공합니다.

- 해당 옵션을 사용하면 자동으로 `handle={true}`로 간주합니다.
- 초기 스냅을 `full`로 시작하려면 `defaultSnap="full"` 을 사용합니다.
- 스냅이 변경될 때마다 `onSnapChange(snap)` 콜백이 호출됩니다. (`'peek' (peekHeight가 있을 때만) | 'half' | 'full'`)

### Peek height

`peekHeight` 옵션을 0보다 큰 값으로 설정하면 handle로 조작 혹은 dimmer 영역 클릭 시 닫히지 않고 아래로 숨겨집니다.

이 때 숨겨지는 영역의 높이는 `peekHeight` 값을 사용합니다.

## Snap change

`resize="flexible"` 인 시트에서 스냅(`'peek' | 'half' | 'full'`)이 변경될 때마다 `onSnapChange` 콜백이 호출됩니다.

현재 스냅에 따라 외부 상태를 동기화하거나, 특정 스냅에서 부가 UI를 표시할 때 사용합니다.

`defaultSnap` 으로 초기 스냅을 지정할 수 있으며 (`'half'` 가 기본값), `peekHeight` 와 함께 사용하면 `peek ↔ half ↔ full` 3단 스냅이 활성화됩니다.

### Largest undimmed snap

`largestUndimmedSnap` 은 dimmer가 꺼지는 스냅을 지정합니다. 지정한 스냅 **이하의** 모든 스냅에서는 dimmer가 표시되지 않고, 시트 뒤 콘텐츠로 포인터 이벤트가 통과합니다.

iOS의 `largestUndimmedDetentIdentifier` 와 같은 역할을 합니다.

- `'peek'` (기본값): `peek` 만 undimmed. `half` / `full` 에서는 dimmer가 표시됩니다.
- `'half'`: `peek` 과 `half` 모두 undimmed. `full` 에서만 dimmer가 표시됩니다. (`resize="flexible"` 에서만 유효)

지도 위에 시트를 띄우고 half 상태에서도 지도를 조작 가능하게 하는 등의 UX 에 사용합니다.

### Half snap scroll

`enableHalfSnapScroll` 은 half 스냅 + 스크롤 가능한 콘텐츠가 함께 있을 때의 제스처 라우팅 정책을 토글합니다.

- `false` (default): half 에서의 viewport 드래그는 항상 시트를 움직입니다. 시트가 정책상 우선이므로 본문 스크롤은 발생하지 않습니다. 짧은 콘텐츠 또는 시트 자체가 주된 인터랙션인 경우 적합합니다.
- `true`: half 상태에서 스크롤 가능한 콘텐츠가 있으면 본문 스크롤이 먼저 동작합니다.

`full` 스냅에서는 이 옵션과 무관하게 항상 본문 스크롤이 우선으로 동작합니다.
