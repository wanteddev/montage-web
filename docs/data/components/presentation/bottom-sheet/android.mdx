## WantedModalBottomSheet
Bottom sheet 형태의 모달 컴포넌트입니다.

시스템 Bottom sheet 또는 커스텀 드래그가 가능한 Bottom sheet를 사용할 수 있습니다.

```kotlin
var showSheet by remember { mutableStateOf(false) }
val listState = rememberLazyListState()
// Foundation 1.8.x부터 anchoredDraggable이 nestedScroll 체인에 참여하면서, LazyColumn 스크롤 잔여값이 시트로 전달되어 튕김 버그가 발생할 수 있습니다.
val scrollPolicy = rememberBottomSheetScrollPolicy(listState)

WantedModalBottomSheet(
    isShow = showSheet,
    onDismissRequest = { showSheet = false },
    content = {
        // 목록 스크롤은 LazyColumn이 담당하고, 위로 남는 잔여 스크롤만 정책으로 차단합니다.
        // LazyColumn 에서만 Modifier.nestedScroll(scrollPolicy.connection) 추가 합니다.
        Column(modifier = Modifier.nestedScroll(scrollPolicy.connection)) {
            LazyColumn(state = listState) {
                // items(...)
            }
        }
    }
)
```

### Parameters
| 이름 | 타입 | 설명 |
|:---|:---|:---|
| isShow | Boolean | 모달 표시 여부입니다. |
| onDismissRequest | () -> Unit | 모달이 닫힐 때 호출되는 콜백입니다. |
| modifier | Modifier | 컴포넌트에 적용할 Modifier입니다. 시스템 Bottom Sheet(type.isSystemBottomSheet = true)에만 적용되고, 커스텀 드래그 Bottom Sheet 에는 적용되지 않습니다. |
| background | Color | 배경 색상입니다. |
| type | ModalType | 모달의 형태입니다. |
| sheetDefault | WantedBottomSheetDefault | Bottom Sheet 의 모양·여백 설정입니다. 기본값은 `type` 에 맞춰 골라집니다 (Full 만 별도 값). |
| dismissOnClickOutside | Boolean | 외부 클릭 시 닫힘 여부입니다. |
| topBar | (@Composable () -> Unit)? | 상단 바 슬롯입니다. |
| bottomBar | (@Composable () -> Unit)? | 하단 바 슬롯입니다. |
| content | (@Composable () -> Unit) | 본문 콘텐츠 슬롯입니다. |


## Advanced
### rememberBottomSheetScrollPolicy
Bottom Sheet 안의 LazyColumn 스크롤 잔여값이 시트로 전달되어 튕기는 현상을 막는 NestedScrollConnection 정책을 만듭니다.

내용이 위쪽으로 더 스크롤될 수 없을 때 남는 위 방향(음수) 잔여 스크롤·플링만 소비하고, 아래 방향은 시트로 넘깁니다. 결과의 connection 을 LazyColumn 의 부모에 Modifier.nestedScroll 로 붙입니다.

```kotlin
val listState = rememberLazyListState()
val scrollPolicy = rememberBottomSheetScrollPolicy(listState)

Column(modifier = Modifier.nestedScroll(scrollPolicy.connection)) {
    LazyColumn(state = listState) {
        // items(...)
    }
}
```

<details>
  <summary>Parameters</summary>

  | 이름 | 타입 | 설명 |
  |:---|:---|:---|
  | listState | LazyListState | 정책을 연결할 LazyColumn 의 상태입니다. 값이 바뀔 때 정책을 새로 만드는 remember 키로만 쓰이며 스크롤 판정에는 사용되지 않습니다. |

</details>

  |:---|:---|
  | BottomSheetScrollPolicy | nestedScroll 에 연결할 connection 을 담은 정책입니다. |

</details>

### WantedBottomSheetDefault
Bottom Sheet / Full 의 모양과 여백을 정의하는 데이터 클래스입니다.

값을 바꿔 쓸 때는 `WantedBottomSheetDefaults.getDefault` · `WantedBottomSheetDefaults.getFullDefault` 의 인자로 넘기거나 `copy` 를 사용합니다.

여백은 디자인 4.0.0 기준으로 ModalSize 와 무관하게 통일되어 있고, Full 만 별도 값을 사용합니다.

<details>
  <summary>Properties</summary>

  | 이름 | 타입 | 설명 |
  |:---|:---|:---|
  | shape | RoundedCornerShape | Bottom Sheet 의 모서리 둥글기입니다. getDefault·getFullDefault 모두 위쪽 두 모서리 32dp 가 기본값입니다. |
  | navigationPadding | Dp | Navigation 영역에 Bottom Sheet 가 추가로 얹는 여백입니다. 여백 자체는 Navigation 컴포넌트가 소유하므로 기본값은 0dp 입니다. |
  | contentHorizontalPadding | Dp | Content 영역의 좌우 여백입니다. |
  | contentVerticalPadding | Dp | Content 영역의 상하 여백입니다. |
  | actionHorizontalPadding | Dp | Action Area 의 좌우 여백입니다. |
  | actionVerticalPadding | Dp | Action Area 의 상하 여백입니다. |

</details>

### getDefault
Bottom Sheet 의 기본 설정을 생성합니다. (디자인 4.0.0)

```kotlin
// 본문 상하 여백까지 켠다 (좌우는 기본값 28)
WantedModalBottomSheet(
    isShow = true,
    onDismissRequest = { },
    sheetDefault = WantedBottomSheetDefaults.getDefault(
        contentVerticalPadding = WantedBottomSheetDefaults.CONTENT_VERTICAL_PADDING
    ),
```

### getFullDefault
Full(전체화면) 의 기본 설정을 생성합니다. 여백은 Bottom Sheet 와 다른 값을 쓰고, 모서리는 Bottom Sheet 와 같은 Sheet Radius(32) 를 씁니다. (디자인 4.0.0)

```kotlin
WantedModalBottomSheet(
    isShow = true,
    onDismissRequest = { },
    type = WantedModalContract.ModalType.FixedFullScreen(),
    sheetDefault = WantedBottomSheetDefaults.getFullDefault(),
    content = { }
)
```

<details>
  <summary>Parameters</summary>

  | 이름 | 타입 | 설명 |
  |:---|:---|:---|
  | shape | RoundedCornerShape | Full 의 모서리 둥글기입니다. Android 의 Full 은 상태바 아래에서 시작해 상단 모서리가 보이므로 Bottom Sheet 와 같은 값을 씁니다. |
  | navigationPadding | Dp | Navigation 영역에 추가로 얹는 여백입니다. |
  | contentHorizontalPadding | Dp | Content 영역의 좌우 여백입니다. |
  | contentVerticalPadding | Dp | Content 영역의 상하 여백입니다. |
  | actionHorizontalPadding | Dp | Action Area 의 좌우 여백입니다. |
  | actionVerticalPadding | Dp | Action Area 의 상하 여백입니다. |

</details>
<br />
<details>

</details>

### getWithoutContentPadding
Content 여백만 0 으로 지운 설정을 생성합니다. Navigation · Action Area 여백은 스펙 값을 그대로 씁니다.

호출부가 본문 여백을 직접 주고 있는 화면에서 이중 패딩을 피하려고 씁니다. 신규 화면은 `getDefault` · `getFullDefault` 를 그대로 쓰세요.

```kotlin
WantedModalBottomSheet(
    isShow = true,
    onDismissRequest = { },
    sheetDefault = WantedBottomSheetDefaults.getWithoutContentPadding(),
    content = { Column(modifier = Modifier.padding(horizontal = 20.dp)) { } }
)
```

  <summary>Parameters</summary>

  | 이름 | 타입 | 설명 |
  |:---|:---|:---|
  | type | ModalType | 모달의 형태입니다. Full 만 별도 여백 값을 씁니다. |

</details>
<br />
<details>
  <summary>Return</summary>

  | 타입 | 설명 |
  |:---|:---|
  | WantedBottomSheetDefault | Content 여백이 0 인 WantedBottomSheetDefault 인스턴스를 반환합니다. |

</details>

## Enum
### ModalSize
| 값 | 설명 |
|:---|:---|
| Small | (Deprecated) 콘텐츠 여백 20dp, 하단 영역 여백 16dp 입니다. Medium 을 사용합니다. |
| Medium | 콘텐츠 여백 20dp, 하단 영역 여백 20dp, 제목 상하 여백 4dp 입니다. |
| Large | 콘텐츠 여백 24dp, 하단 영역 여백 24dp, 제목 상하 여백 4dp 입니다. |
| XLarge | 콘텐츠 여백 32dp, 하단 영역 여백 32dp, 제목 상하 8dp·좌우 4dp 여백입니다. |
| Custom | 커스텀 크기의 Modal 입니다. 모든 패딩이 0dp로 설정되어 사용자가 직접 정의 할 수 있습니다. |

## Sealed Class
### ModalType
Modal의 형태를 정의하는 sealed 클래스입니다.
Flexible, FixedWrapContent, Fixed, FixedFullScreen, FixedRatio 형태를 제공합니다.

| 값 | 설명 |
|:---|:---|
| Flexible | 콘텐츠 크기에 따라 자동으로 조정되는 유동형 Modal 입니다. 항상 시스템 BottomSheet 로 그려지고 닫을 수 있습니다. 부분 펼침(중간 높이)을 허용하지만, 콘텐츠가 충분히 높을 때만 그 상태가 생기며 짧은 콘텐츠는 바로 펼쳐진(Expanded) 상태로 표시됩니다. |
| FixedWrapContent | 콘텐츠 높이에 맞게 조정되는 고정형 Modal 입니다. 기본은 커스텀 시트(isSystemBottomSheet = false)입니다. isCloseable(기본 true)이 false 면 드래그 핸들을 숨기고, 시스템 시트에서는 스와이프·바깥 탭으로 닫히지 않습니다. 뒤로가기는 시스템·커스텀 시트 모두 onDismissRequest 를 호출하고(커스텀 시트는 바깥 탭(dismissOnClickOutside)도 호출), 실제로 닫을지는 호출부가 표시 상태로 정합니다. |
| Fixed | height 로 지정한 높이를 갖는 고정형 Modal 입니다. 기본은 커스텀 시트(isSystemBottomSheet = false)입니다. isCloseable(기본 true)이 false 면 드래그 핸들을 숨기고, 시스템 시트에서는 스와이프·바깥 탭으로 닫히지 않습니다. 뒤로가기는 시스템·커스텀 시트 모두 onDismissRequest 를 호출하고(커스텀 시트는 바깥 탭(dismissOnClickOutside)도 호출), 실제로 닫을지는 호출부가 표시 상태로 정합니다. |
| FixedFullScreen | 화면 전체를 덮는 고정형 Modal 입니다. 기본은 커스텀 시트(isSystemBottomSheet = false)입니다. isCloseable(기본 true)이 false 면 드래그 핸들을 숨기고, 시스템 시트에서는 스와이프·바깥 탭으로 닫히지 않습니다. 뒤로가기는 시스템·커스텀 시트 모두 onDismissRequest 를 호출하고(커스텀 시트는 바깥 탭(dismissOnClickOutside)도 호출), 실제로 닫을지는 호출부가 표시 상태로 정합니다. |
| FixedRatio | 화면 높이 × ratio(0.0 ~ 1.0)로 높이가 정해지는 고정형 Modal입니다. 다만 화면 높이에서 상단 inset·10dp·드래그 핸들(19dp)을 뺀 값을 넘지 않으므로 ratio 가 1f 여도 화면 전체 높이가 되지 않습니다. 기본은 커스텀 시트(isSystemBottomSheet = false)입니다. isCloseable(기본 true)이 false 면 드래그 핸들을 숨기고, 시스템 시트에서는 스와이프·바깥 탭으로 닫히지 않습니다. 뒤로가기는 시스템·커스텀 시트 모두 onDismissRequest 를 호출하고(커스텀 시트는 바깥 탭(dismissOnClickOutside)도 호출), 실제로 닫을지는 호출부가 표시 상태로 정합니다. |
