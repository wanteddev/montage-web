## Usage

floating ui 라이브러리를 사용하여 특정 요소를 기준으로 오버레이를 띄울 때 사용합니다.

<Demo code={`import { Popper, PopperAnchor, PopperContent, PopperArrow, Button } from '@wanteddev/wds';

const Demo = () => {
  return (
    <Popper>
      <PopperAnchor>
        <Button>클릭</Button>
      </PopperAnchor>
      <PopperContent>
        <PopperArrow />
        콘텐츠
      </PopperContent>
    </Popper>
  )
}

export default Demo;`}
/>

## Anatomy

Popper는 아래와 같은 구조를 가집니다.

```tsx
<Popper>
  <PopperAnchor>
    <Button />
  </PopperAnchor>

  <PopperContent>
    <PopperArrow />
  </PopperContent>
</Popper>
```
