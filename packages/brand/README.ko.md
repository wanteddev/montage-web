# `@montage-ui/brand`

[English](./README.md) | [한국어](./README.ko.md)

Montage의 브랜드 에셋 패키지입니다. 로고 등 브랜드 관련 리소스를 제공합니다.

## 설치

```sh
pnpm i @montage-ui/brand
```

> **주의:** `@montage-ui/brand`는 다른 `@montage-ui/*` 패키지(예: `@montage-ui/core`)와 **동일한 버전**으로 설치해야 합니다. 버전이 일치하지 않으면 theme context가 중복 생성되어 예기치 않은 스타일 문제가 발생할 수 있습니다.
