# `@montage-ui/brand`

[English](./README.md) | [한국어](./README.ko.md)

Brand asset components for the Montage design system. Provides brand-related resources such as logos.

## Installation

```sh
pnpm i @montage-ui/brand
```

> **Note:** `@montage-ui/brand` must be installed with the **same version** as other `@montage-ui/*` packages (e.g., `@montage-ui/core`). Mismatched versions can cause duplicate theme contexts and unexpected styling issues.
