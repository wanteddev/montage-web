# `@montage-ui/nextjs`

[English](./README.md) | [한국어](./README.ko.md)

Next.js integration for Montage. Provides `AppRouterCacheProvider`, `AppCacheProvider`, `DocumentHeadTags`, and SSR utilities for Emotion. Supports both App Router and Page Router.

## Installation

```sh
pnpm i @montage-ui/nextjs
```

> **Note:** `@montage-ui/nextjs` must be installed with the **same version** as other `@montage-ui/*` packages (e.g., `@montage-ui/core`). Mismatched versions can cause duplicate theme contexts and unexpected styling issues.

For setup instructions, see [`@montage-ui/core`](https://github.com/wanteddev/montage-web/blob/main/packages/core/README.md).
