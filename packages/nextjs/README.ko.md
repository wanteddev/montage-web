# `@montage-ui/nextjs`

[English](./README.md) | [한국어](./README.ko.md)

Montage의 Next.js 통합 패키지입니다. `AppRouterCacheProvider`, `AppCacheProvider`, `DocumentHeadTags` 및 Emotion SSR 유틸리티를 제공합니다. App Router와 Page Router 모두 지원합니다.

## 설치

```sh
pnpm i @montage-ui/nextjs
```

> **주의:** `@montage-ui/nextjs`는 다른 `@montage-ui/*` 패키지(예: `@montage-ui/core`)와 **동일한 버전**으로 설치해야 합니다. 버전이 일치하지 않으면 theme context가 중복 생성되어 예기치 않은 스타일 문제가 발생할 수 있습니다.

설정 방법은 [`@montage-ui/core`](https://github.com/wanteddev/montage-web/blob/main/packages/core/README.ko.md)를 참고해주세요.
