# `@montage-ui/lottie`

[English](./README.md) | [한국어](./README.ko.md)

Lottie animation components for the Montage design system. Built on top of [lottie-web](https://github.com/airbnb/lottie-web).

## Installation

```sh
pnpm i @montage-ui/lottie
```

> **Note:** `@montage-ui/lottie` must be installed with the **same version** as other `@montage-ui/*` packages (e.g., `@montage-ui/core`). Mismatched versions can cause duplicate theme contexts and unexpected styling issues.
