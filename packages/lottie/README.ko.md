# `@montage-ui/lottie`

[English](./README.md) | [한국어](./README.ko.md)

Montage 디자인 시스템의 Lottie 애니메이션 컴포넌트 패키지입니다. [lottie-web](https://github.com/airbnb/lottie-web) 기반으로 동작합니다.

## 설치

```sh
pnpm i @montage-ui/lottie lottie-web
```

> **주의:** `@montage-ui/lottie`는 다른 `@montage-ui/*` 패키지(예: `@montage-ui/core`)와 **동일한 버전**으로 설치해야 합니다. 버전이 일치하지 않으면 theme context가 중복 생성되어 예기치 않은 스타일 문제가 발생할 수 있습니다.
