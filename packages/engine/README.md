# `@montage-ui/engine`

[English](./README.md) | [한국어](./README.ko.md)

Internal styling engine for Montage. Provides `Box`, `ThemeProvider`, and polymorphic type utilities powered by [Emotion](https://github.com/emotion-js/emotion).

This package is not intended to be used directly. See [`@montage-ui/core`](https://github.com/wanteddev/montage-web/blob/main/packages/core/README.md) for usage instructions.
