# `@montage-ui/engine`

[English](./README.md) | [한국어](./README.ko.md)

Montage 내부 스타일링 엔진입니다. [Emotion](https://github.com/emotion-js/emotion) 기반으로 `Box`, `ThemeProvider`, polymorphic 타입 유틸리티를 제공합니다.

이 패키지는 직접 사용하기 위한 것이 아닙니다. 사용법은 [`@montage-ui/core`](https://github.com/wanteddev/montage-web/blob/main/packages/core/README.ko.md)를 참고해주세요.
