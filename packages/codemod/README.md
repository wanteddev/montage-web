# `@montage-ui/codemod`

[English](./README.md) | [한국어](./README.ko.md)

Codemod scripts for migrating between Montage major versions. Built on [jscodeshift](https://github.com/facebook/jscodeshift).

## Usage

```sh
npx @montage-ui/codemod <transform> <path>
```

For detailed migration steps, see the [Migration Guide](https://github.com/wanteddev/montage-web/blob/main/MIGRATION.md).
