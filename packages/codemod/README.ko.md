# `@montage-ui/codemod`

[English](./README.md) | [한국어](./README.ko.md)

Montage 메이저 버전 간 마이그레이션을 위한 코드모드 스크립트입니다. [jscodeshift](https://github.com/facebook/jscodeshift) 기반으로 동작합니다.

## 사용법

```sh
npx @montage-ui/codemod <transform> <path>
```

자세한 마이그레이션 방법은 [Migration Guide](https://github.com/wanteddev/montage-web/blob/main/MIGRATION.md)를 참고해주세요.
