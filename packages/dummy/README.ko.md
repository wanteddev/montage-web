# `@montage-ui/dummy`

[English](./README.md) | [한국어](./README.ko.md)

Montage의 시각적 참조용 컴포넌트 패키지입니다. POC 및 프로토타이핑 목적으로만 사용하며 **프로덕션 환경에서는 사용하지 마세요**.

## 설치

```sh
pnpm i @montage-ui/dummy
```

> **주의:** `@montage-ui/dummy`는 참조용 컴포넌트만 포함한 패키지입니다. 프로덕션 환경에 적합하지 않으며, POC 또는 프로토타입 환경에서만 사용해야 합니다. 프로덕션 빌드에 포함하지 마세요.
