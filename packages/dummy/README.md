# `@montage-ui/dummy`

[English](./README.md) | [한국어](./README.ko.md)

Presentational-only reference scaffold components for the Montage design system. Intended for POC and prototyping purposes only — **do not use in production**.

## Installation

```sh
pnpm i @montage-ui/dummy
```

> **Warning:** `@montage-ui/dummy` is a scaffold package containing reference components only. It is not production-ready and should be used exclusively in POC or prototype environments. Do not ship this package in production builds.
