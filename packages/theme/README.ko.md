# `@montage-ui/theme`

[English](./README.md) | [한국어](./README.ko.md)

Montage의 디자인 토큰 및 테마 정의 패키지입니다. atomic 토큰, semantic 토큰(light/dark), 디자인 토큰(spacing, opacity, breakpoint, zIndex)을 포함합니다.

이 패키지는 직접 사용하기 위한 것이 아닙니다. 사용법은 [`@montage-ui/core`](https://github.com/wanteddev/montage-web/blob/main/packages/core/README.ko.md)를 참고해주세요.
